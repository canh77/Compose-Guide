Tùy biến theme: màu thương hiệu, font, dark mode

Theme mặc định của Material 3 chỉ là điểm khởi đầu. Bài này hướng dẫn thay bằng màu thương hiệu, font riêng và bo góc riêng, thêm token màu của riêng bạn, cho người dùng chọn Sáng/Tối, rồi kiểm tra cả hai chế độ ngay trong Preview.

Định nghĩa

Tùy biến theme là thay các giá trị trong ba nhóm token của MaterialTheme (xem Material 3): ColorScheme (bảng màu), Typography (thang chữ) và Shapes (bo góc). Bạn gom chúng vào một hàm composable riêng, ví dụ AppTheme. Hàm này còn quyết định khi nào dùng bảng màu sáng, khi nào dùng bảng màu tối, và khi nào dùng màu động.

Dark mode (chế độ tối) không chỉ đơn giản là đảo ngược màu. Material 3 có hai bảng màu riêng, được tính từ cùng một màu gốc sao cho cặp nền/chữ luôn đủ tương phản. Màu động (dynamic color) có từ Android 12 (API 31): hệ thống tạo bảng màu từ hình nền của người dùng, và app có thể dùng bảng màu đó thay cho màu thương hiệu.

Hồi dùng XML, bạn khai báo hai file values/themes.xml và values-night/themes.xml. Trong Compose, cả hai chỉ là hai biến Kotlin, và một câu if chọn biến nào được dùng.

Cách dùng

1. Tạo bảng màu từ màu thương hiệu

Mỗi bảng màu có hơn 30 vai trò. Đừng tự chọn tay từng màu. Hãy dùng công cụ Material Theme Builder (bản web hoặc plugin Figma): nhập một màu gốc của thương hiệu, công cụ sẽ sinh đủ mọi vai trò cho cả sáng lẫn tối, rồi xuất ra file Color.kt và Theme.kt cho Jetpack Compose. Dưới đây là một bảng màu đã rút gọn cho quán trà "Lá Xanh":

// Color.kt
val Green40 = Color(0xFF2E6A47)
val Green90 = Color(0xFFB1F1C4)
val Green10 = Color(0xFF00210F)
val Green80 = Color(0xFF95D5A9)
val Green20 = Color(0xFF00391E)
val Green30 = Color(0xFF125131)

// Theme.kt
private val LightColors = lightColorScheme(
    primary = Green40,
    onPrimary = Color(0xFFFFFFFF),
    primaryContainer = Green90,
    onPrimaryContainer = Green10,
    // ... secondary, tertiary, surface... lấy từ Theme Builder
)

private val DarkColors = darkColorScheme(
    primary = Green80,
    onPrimary = Green20,
    primaryContainer = Green30,
    onPrimaryContainer = Green90,
    // ...
)
Cảnh báo: Vai trò nào bạn không truyền vào lightColorScheme/darkColorScheme sẽ giữ màu mặc định (tông tím) của Material 3. Nếu chỉ đặt primary, app sẽ là màu xanh pha tím. Đó là lý do nên sinh đủ bảng màu bằng Theme Builder.

2. Hàm AppTheme chọn bảng màu

@Composable
fun AppTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    dynamicColor: Boolean = true,
    content: @Composable () -> Unit
) {
    val colorScheme = when {
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S -> {
            val context = LocalContext.current
            if (darkTheme) dynamicDarkColorScheme(context) else dynamicLightColorScheme(context)
        }
        darkTheme -> DarkColors
        else -> LightColors
    }
    MaterialTheme(
        colorScheme = colorScheme,
        typography = AppTypography,
        shapes = AppShapes,
        content = content
    )
}

Trên Android 12 trở lên, nếu dynamicColor = true, app sẽ dùng màu lấy từ hình nền. Máy cũ hơn, hoặc khi bạn tắt cờ này, sẽ dùng bảng màu thương hiệu.

3. Font tùy chỉnh

Chép các file font (.ttf/.otf) vào res/font/. Tên file chỉ được có chữ thường, số và dấu gạch dưới. Sau đó khai báo một FontFamily và áp dụng vào các kiểu chữ cần đổi:

// Type.kt
val BeVietnamPro = FontFamily(
    Font(R.font.be_vietnam_pro_regular, FontWeight.Normal),
    Font(R.font.be_vietnam_pro_medium, FontWeight.Medium),
    Font(R.font.be_vietnam_pro_bold, FontWeight.Bold),
)

private val base = Typography()

// Tiêu đề dùng font thương hiệu, phần thân giữ font mặc định
val AppTypography = Typography(
    displayLarge = base.displayLarge.copy(fontFamily = BeVietnamPro),
    displayMedium = base.displayMedium.copy(fontFamily = BeVietnamPro),
    displaySmall = base.displaySmall.copy(fontFamily = BeVietnamPro),
    headlineLarge = base.headlineLarge.copy(fontFamily = BeVietnamPro),
    headlineMedium = base.headlineMedium.copy(fontFamily = BeVietnamPro),
    headlineSmall = base.headlineSmall.copy(fontFamily = BeVietnamPro),
    titleLarge = base.titleLarge.copy(fontFamily = BeVietnamPro, fontWeight = FontWeight.Bold),
    titleMedium = base.titleMedium.copy(fontFamily = BeVietnamPro),
    titleSmall = base.titleSmall.copy(fontFamily = BeVietnamPro),
)

4. Shapes tùy chỉnh

// Bo tròn hơn mặc định cho cảm giác mềm mại
val AppShapes = Shapes(
    extraSmall = RoundedCornerShape(6.dp),
    small = RoundedCornerShape(10.dp),
    medium = RoundedCornerShape(16.dp),
    large = RoundedCornerShape(24.dp),
    extraLarge = RoundedCornerShape(32.dp),
)

5. Thêm token riêng (extended colors)

ColorScheme không có sẵn vai trò "cảnh báo" hay "thành công". Để thêm, bạn tạo một data class, cung cấp nó qua staticCompositionLocalOf (xem CompositionLocal) và tạo một object AppTheme để truy cập cho gọn, giống cách MaterialTheme vừa là hàm vừa là object.

@Immutable
data class ExtendedColors(
    val warning: Color,
    val onWarning: Color,
    val warningContainer: Color,
    val onWarningContainer: Color,
)

val LightExtendedColors = ExtendedColors(
    warning = Color(0xFF7A5900),
    onWarning = Color(0xFFFFFFFF),
    warningContainer = Color(0xFFFFDEA0),
    onWarningContainer = Color(0xFF261900),
)

val DarkExtendedColors = ExtendedColors(
    warning = Color(0xFFF8BD2A),
    onWarning = Color(0xFF402D00),
    warningContainer = Color(0xFF5C4200),
    onWarningContainer = Color(0xFFFFDEA0),
)

val LocalExtendedColors = staticCompositionLocalOf { LightExtendedColors }

object AppTheme {
    val extendedColors: ExtendedColors
        @Composable
        @ReadOnlyComposable
        get() = LocalExtendedColors.current
}

Trong hàm AppTheme(...) ở bước 2, bọc MaterialTheme bằng CompositionLocalProvider:

val extended = if (darkTheme) DarkExtendedColors else LightExtendedColors
CompositionLocalProvider(LocalExtendedColors provides extended) {
    MaterialTheme(colorScheme = colorScheme, typography = AppTypography, shapes = AppShapes, content = content)
}

6. Lưu lựa chọn Sáng/Tối/Theo hệ thống

Cho người dùng chọn một trong ba chế độ và lưu lựa chọn lại, thường bằng DataStore (thư viện androidx.datastore:datastore-preferences). Sau đó đổi lựa chọn thành giá trị darkTheme và truyền vào AppTheme.

enum class ThemeMode(val label: String) { LIGHT("Sáng"), DARK("Tối"), SYSTEM("Theo hệ thống") }

private val Context.settingsStore by preferencesDataStore(name = "settings")
private val THEME_MODE = stringPreferencesKey("theme_mode")

class SettingsRepository(private val context: Context) {
    val themeMode: Flow<ThemeMode> = context.settingsStore.data.map { prefs ->
        ThemeMode.entries.firstOrNull { it.name == prefs[THEME_MODE] } ?: ThemeMode.SYSTEM
    }

    suspend fun setThemeMode(mode: ThemeMode) {
        context.settingsStore.edit { prefs -> prefs[THEME_MODE] = mode.name }
    }
}

7. Màu thanh hệ thống và Preview

  • Gọi enableEdgeToEdge() trong onCreate thì thanh trạng thái và thanh điều hướng sẽ trong suốt, và icon trên đó tự sáng/tối theo chế độ của hệ thống (xem Edge-to-edge). Nếu app cho phép chọn chế độ khác với hệ thống, hãy gọi lại hàm này với SystemBarStyle phù hợp, như trong Ví dụ 2.
  • Thêm @PreviewLightDark lên hàm preview để Android Studio vẽ một bản sáng và một bản tối cạnh nhau.

Ví dụ

Ví dụ 1: Banner "sắp hết hàng" dùng token mở rộng

@Composable
fun LowStockBanner(itemName: String, remaining: Int, modifier: Modifier = Modifier) {
    val colors = AppTheme.extendedColors
    Surface(
        color = colors.warningContainer,
        contentColor = colors.onWarningContainer, // contentColorFor() không biết màu tự thêm
        shape = MaterialTheme.shapes.medium,
        modifier = modifier.fillMaxWidth()
    ) {
        Row(Modifier.padding(16.dp), verticalAlignment = Alignment.CenterVertically) {
            Icon(painterResource(R.drawable.ic_warning), contentDescription = null)
            Spacer(Modifier.width(12.dp))
            Column {
                Text("Sắp hết hàng", style = MaterialTheme.typography.titleMedium)
                Text(
                    "$itemName chỉ còn $remaining phần",
                    style = MaterialTheme.typography.bodyMedium
                )
            }
        }
    }
}

@PreviewLightDark
@Composable
private fun LowStockBannerPreview() {
    AppTheme(dynamicColor = false) {
        Surface {
            LowStockBanner("Trà ô long", remaining = 3, modifier = Modifier.padding(16.dp))
        }
    }
}

Kết quả: Preview hiện hai bản. Bản sáng có banner nền vàng nhạt, chữ nâu sẫm. Bản tối có nền vàng nâu đậm, chữ vàng nhạt. Tiêu đề "Sắp hết hàng" dùng font Be Vietnam Pro của theme, và góc bo 16.dp lấy từ AppShapes.medium.

Ví dụ 2: Màn cài đặt chọn chế độ giao diện

@Composable
fun ThemeModePicker(
    selected: ThemeMode,
    onSelect: (ThemeMode) -> Unit,
    modifier: Modifier = Modifier
) {
    Column(modifier.selectableGroup()) {
        Text(
            "Giao diện",
            style = MaterialTheme.typography.titleMedium,
            modifier = Modifier.padding(16.dp)
        )
        ThemeMode.entries.forEach { mode ->
            Row(
                modifier = Modifier
                    .fillMaxWidth()
                    .selectable(
                        selected = mode == selected,
                        onClick = { onSelect(mode) },
                        role = Role.RadioButton
                    )
                    .padding(horizontal = 16.dp, vertical = 12.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                RadioButton(selected = mode == selected, onClick = null)
                Spacer(Modifier.width(16.dp))
                Text(mode.label, style = MaterialTheme.typography.bodyLarge)
            }
        }
    }
}

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            // Bản demo: giữ lựa chọn qua lần xoay màn hình.
            // App thật: đọc/ghi qua SettingsRepository trong ViewModel.
            var themeMode by rememberSaveable { mutableStateOf(ThemeMode.SYSTEM) }
            val darkTheme = when (themeMode) {
                ThemeMode.LIGHT -> false
                ThemeMode.DARK -> true
                ThemeMode.SYSTEM -> isSystemInDarkTheme()
            }

            // Icon thanh hệ thống theo lựa chọn trong app, không theo hệ thống
            LaunchedEffect(darkTheme) {
                val transparent = android.graphics.Color.TRANSPARENT
                enableEdgeToEdge(
                    statusBarStyle = SystemBarStyle.auto(transparent, transparent) { darkTheme },
                    navigationBarStyle = SystemBarStyle.auto(transparent, transparent) { darkTheme },
                )
            }

            AppTheme(darkTheme = darkTheme) {
                Scaffold { innerPadding ->
                    ThemeModePicker(
                        selected = themeMode,
                        onSelect = { themeMode = it },
                        modifier = Modifier.padding(innerPadding)
                    )
                }
            }
        }
    }
}

Kết quả: Màn hình có ba lựa chọn dạng radio. Chọn "Tối" thì cả app chuyển sang nền tối ngay lập tức, kể cả khi điện thoại đang ở chế độ sáng, và icon trên thanh trạng thái đổi sang màu sáng cho dễ nhìn. Chọn "Theo hệ thống" thì app đi theo cài đặt của máy.

Chú ý

  • Đừng gõ cứng Color.White/Color.Black trong giao diện. Chữ đen trên nền tối sẽ biến mất. Mã màu chỉ nên xuất hiện trong Color.kt, còn ở mọi chỗ khác hãy đọc qua MaterialTheme.colorScheme hoặc AppTheme.extendedColors.
  • Kiểm tra độ tương phản: chữ thường cần tỉ lệ tương phản tối thiểu 4.5:1 so với nền, chữ lớn cần 3:1. Cặp xxx/onXxx do Theme Builder sinh ra thường đã đạt mức này. Rủi ro nằm ở những màu bạn tự chỉnh tay hoặc ghép sai cặp, nên hãy kiểm tra lại bằng công cụ đo tương phản.
  • Màu động sẽ thay màu thương hiệu: khi dynamicColor = true, nút chính có thể thành màu hồng hay xanh dương tùy hình nền. Nếu nhận diện thương hiệu quan trọng, đặt mặc định false hoặc cho người dùng tự bật. Token tự thêm như warning sẽ không đổi theo hình nền.
  • Preview: dùng AppTheme(dynamicColor = false) trong Preview để thấy đúng màu thương hiệu, và dùng @PreviewLightDark để phát hiện sớm lỗi ở chế độ tối.
  • Font tiếng Việt: chọn font hỗ trợ đầy đủ dấu tiếng Việt, ví dụ Be Vietnam Pro hay Inter. Font thiếu ký tự có dấu sẽ bị hệ thống thay bằng font khác ngay giữa chữ, trông rất lệch.
  • staticCompositionLocalOf hợp với dữ liệu hiếm khi đổi như màu theme. Khi giá trị đổi (chuyển sáng/tối), cả cây giao diện bên dưới sẽ được vẽ lại, và điều đó chấp nhận được với theme.
Lưu ý: isSystemInDarkTheme() chỉ đọc cài đặt của máy. Muốn app có lựa chọn riêng thì phải tự lưu lựa chọn và truyền darkTheme vào theme, như Ví dụ 2.
