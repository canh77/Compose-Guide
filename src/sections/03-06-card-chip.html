Card, ListItem, Chip, Badge và Divider

Đây là nhóm thành phần "đóng gói" và "trang trí" nội dung: Card gom thông tin về một đối tượng, ListItem tạo hàng danh sách chuẩn, Chip thể hiện bộ lọc hay hành động nhỏ, Badge báo số lượng mới và Divider chia tách các nhóm.

Định nghĩa

Card là một khối chứa có nền, bo góc và (tùy loại) đổ bóng hoặc viền, dùng để gom các nội dung nói về cùng một đối tượng — một sản phẩm, một bài viết, một cuộc hẹn. Nó tương đương CardView/MaterialCardView của hệ View, nhưng nội dung bên trong được xếp theo cột như Column. ListItem là một hàng danh sách dựng sẵn theo chuẩn Material: bạn chỉ cần điền các "khe" (slot — chỗ trống nhận một composable) như dòng tiêu đề, dòng phụ, icon đầu, icon cuối; khoảng cách, chiều cao và kiểu chữ đã được canh sẵn.

Chip là phần tử nhỏ gọn dạng viên thuốc, đại diện cho một hành động, một bộ lọc, một thông tin người dùng đã nhập hoặc một gợi ý. Badge là chấm nhỏ hoặc con số đặt ở góc một icon để báo "có cái mới" (tin nhắn chưa đọc, món trong giỏ hàng). Divider là đường kẻ mảnh phân tách các nhóm nội dung; trong Material 3 có HorizontalDivider và VerticalDivider (thay cho Divider cũ đã ngừng khuyến nghị).

Cách dùng

1. Ba loại Card

ComponentHình thứcKhi nào dùng
CardNền màu tách nhẹ khỏi nền màn hình, không viềnMặc định cho phần lớn trường hợp, lưới thẻ dày đặc
ElevatedCardCó đổ bóng, trông "nổi" lênCần tách thẻ khỏi nền rõ hơn, ví dụ thẻ sản phẩm nổi bật
OutlinedCardViền mảnh, nền trùng nền màn hìnhGiao diện tối giản, nhiều thẻ cạnh nhau cần ranh giới rõ nhưng nhẹ

Cả ba có hai dạng: không bấm được và bấm được (truyền tham số onClick). Dạng bấm được tự có hiệu ứng gợn sóng (ripple) đúng theo góc bo, vai trò "nút" cho trình đọc màn hình và trạng thái enabled. Tùy biến qua shape, colors = CardDefaults.cardColors(containerColor = …) và elevation = CardDefaults.cardElevation(defaultElevation = …).

OutlinedCard(
    onClick = { /* mở chi tiết cuộc hẹn */ },
    modifier = Modifier.fillMaxWidth()
) {
    Column(Modifier.padding(16.dp)) {
        Text("Khám răng định kỳ", style = MaterialTheme.typography.titleMedium)
        Text("Thứ Bảy, 9:30 – Nha khoa Hòa Bình")
    }
}

2. ListItem

SlotVị trí và công dụng
headlineContentBắt buộc. Dòng chính, ví dụ tên liên hệ.
supportingContentDòng phụ bên dưới, ví dụ số điện thoại.
overlineContentDòng chữ nhỏ phía trên dòng chính, ví dụ nhóm "Gia đình".
leadingContentĐầu hàng: avatar, icon, checkbox.
trailingContentCuối hàng: icon hành động, chữ "2 phút trước", Switch.

ListItem tự đổi chiều cao cho 1, 2 hoặc 3 dòng. Nó không tự bấm được: thêm Modifier.clickable { … } nếu cần. Đây là cách nhanh nhất để có một hàng đẹp trong LazyColumn:

ListItem(
    overlineContent = { Text("Gia đình") },
    headlineContent = { Text("Nguyễn Thị Hoa") },
    supportingContent = { Text("0912 345 678") },
    leadingContent = {
        Icon(painterResource(R.drawable.ic_person), contentDescription = null)
    },
    trailingContent = {
        IconButton(onClick = { /* gọi điện */ }) {
            Icon(painterResource(R.drawable.ic_call), contentDescription = "Gọi Hoa")
        }
    },
    modifier = Modifier.clickable { /* mở hồ sơ liên hệ */ }
)

3. Bốn loại Chip

ComponentÝ nghĩaVí dụ
AssistChipGợi ý một hành động liên quan đến nội dung đang xem"Thêm vào lịch", "Chỉ đường"
FilterChipBật/tắt một bộ lọc; có tham số selected"Còn hàng", "Giảm giá", "Giao nhanh"
InputChipĐại diện một thông tin người dùng đã nhập, thường có nút xóa ở cuốiNgười nhận email, thẻ (tag) của ghi chú
SuggestionChipGợi ý được tạo động để người dùng chọn nhanhTrả lời nhanh "Cảm ơn bạn!", từ khóa tìm kiếm

Mọi chip đều có onClick và label; FilterChip/InputChip có thêm selected. Các slot icon: leadingIcon, trailingIcon (riêng SuggestionChip dùng icon, InputChip có thêm avatar). Khi chip nằm trên ảnh hoặc nền phức tạp, dùng biến thể có bóng: ElevatedAssistChip, ElevatedFilterChip, ElevatedSuggestionChip.

4. Badge

Bọc icon trong BadgedBox, truyền Badge vào tham số badge. Badge() không có nội dung là một chấm nhỏ; Badge { Text("5") } hiển thị con số.

5. Divider

HorizontalDivider() kẻ ngang hết chiều rộng; tùy chỉnh bằng thickness và color. VerticalDivider() lấp đầy chiều cao cha, nên đặt trong Row có Modifier.height(IntrinsicSize.Min) (hoặc chiều cao cố định) để đường kẻ không bị kéo dài vô hạn — xem Kích thước và ràng buộc.

Ví dụ

Ví dụ 1: Thẻ sản phẩm

@Composable
fun ProductCard(
    name: String,
    price: String,
    onClick: () -> Unit,
    onAddToCart: () -> Unit,
    modifier: Modifier = Modifier
) {
    ElevatedCard(onClick = onClick, modifier = modifier.width(180.dp)) {
        Image(
            painter = painterResource(R.drawable.product_sneaker),
            contentDescription = null,
            contentScale = ContentScale.Crop,
            modifier = Modifier.fillMaxWidth().height(140.dp)
        )
        Column(Modifier.padding(12.dp)) {
            Text(
                name,
                style = MaterialTheme.typography.titleMedium,
                maxLines = 2,
                overflow = TextOverflow.Ellipsis
            )
            Text(
                price,
                style = MaterialTheme.typography.bodyLarge,
                color = MaterialTheme.colorScheme.primary
            )
            Spacer(Modifier.height(8.dp))
            FilledTonalButton(onClick = onAddToCart, modifier = Modifier.fillMaxWidth()) {
                Text("Thêm vào giỏ")
            }
        }
    }
}

Ví dụ 2: Thanh lọc danh mục bằng FilterChip

@Composable
fun CategoryFilter() {
    val categories = listOf("Áo", "Quần", "Giày", "Túi xách", "Phụ kiện")
    var selected by remember { mutableStateOf(setOf("Giày")) }

    Column {
        Row(
            modifier = Modifier
                .horizontalScroll(rememberScrollState())
                .padding(horizontal = 16.dp),
            horizontalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            categories.forEach { category ->
                val isSelected = category in selected
                FilterChip(
                    selected = isSelected,
                    onClick = {
                        selected = if (isSelected) selected - category else selected + category
                    },
                    label = { Text(category) },
                    leadingIcon = if (isSelected) {
                        {
                            Icon(
                                painter = painterResource(R.drawable.ic_check),
                                contentDescription = null,
                                modifier = Modifier.size(FilterChipDefaults.IconSize)
                            )
                        }
                    } else {
                        null
                    }
                )
            }
        }
        Text(
            text = if (selected.isEmpty()) "Đang hiện tất cả sản phẩm"
                   else "Đang lọc: ${selected.joinToString()}",
            modifier = Modifier.padding(16.dp)
        )
    }
}

Kết quả: Một hàng chip cuộn ngang. Chip "Giày" đang được chọn (nền đậm, có dấu tích). Bấm thêm "Túi xách" thì dòng bên dưới đổi thành "Đang lọc: Giày, Túi xách"; bỏ chọn hết thì hiện "Đang hiện tất cả sản phẩm".

Ví dụ 3: Icon giỏ hàng có số lượng

@Composable
fun CartButton(itemCount: Int, onClick: () -> Unit) {
    IconButton(onClick = onClick) {
        BadgedBox(
            badge = {
                if (itemCount > 0) {
                    Badge(
                        // Đọc "3 sản phẩm" thay vì chỉ đọc số "3"
                        modifier = Modifier.clearAndSetSemantics {
                            contentDescription = "$itemCount sản phẩm"
                        }
                    ) {
                        Text(if (itemCount > 99) "99+" else itemCount.toString())
                    }
                }
            }
        ) {
            Icon(
                painter = painterResource(R.drawable.ic_shopping_cart),
                contentDescription = "Giỏ hàng"
            )
        }
    }
}

@Composable
fun ShopHeader() {
    var count by remember { mutableIntStateOf(0) }

    Row(
        modifier = Modifier
            .fillMaxWidth()
            .height(IntrinsicSize.Min)
            .padding(16.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Text(
            "Cửa hàng Mộc",
            style = MaterialTheme.typography.titleLarge,
            modifier = Modifier.weight(1f)
        )
        TextButton(onClick = { count++ }) { Text("Thêm 1 món") }
        VerticalDivider(Modifier.padding(vertical = 8.dp))
        CartButton(itemCount = count, onClick = { /* mở giỏ hàng */ })
    }
}

Kết quả: Thanh đầu trang có tên cửa hàng, nút "Thêm 1 món", một đường kẻ dọc mảnh và icon giỏ hàng. Ban đầu không có badge; mỗi lần bấm "Thêm 1 món", một nhãn tròn màu đỏ ở góc icon tăng lên 1, 2, 3… và từ 100 trở đi hiện "99+".

Chú ý

  • Card bấm được: dùng tham số onClick, đừng gắn Modifier.clickable lên Card. Gắn modifier sẽ cho hiệu ứng gợn sóng hình chữ nhật tràn ra ngoài góc bo và thiếu vai trò "nút" cho trình đọc màn hình.
  • Không lồng Card trong Card và không lạm dụng bóng đổ: quá nhiều lớp nổi làm giao diện rối. Danh sách đơn giản thường chỉ cần ListItem + Divider.
  • ListItem có màu nền riêng (surface). Khi đặt nó trong Card hoặc bottom sheet có màu nền khác, truyền colors = ListItemDefaults.colors(containerColor = Color.Transparent) để khỏi bị "vá" màu.
  • Chip là stateless như mọi control khác: FilterChip chỉ hiện "đã chọn" khi bạn truyền selected = true. Quy ước Material là chỉ hiện dấu tích ở leadingIcon khi chip đang được chọn.
  • Nhiều chip nằm ngang: dùng horizontalScroll hoặc LazyRow; muốn tự xuống dòng thì dùng FlowRow — xem Pager và Flow layout.
  • Badge: ẩn hẳn khi số lượng bằng 0, rút gọn số lớn ("99+") và đảm bảo trình đọc màn hình đọc được ý nghĩa (ví dụ "Giỏ hàng, 3 sản phẩm"), không chỉ đọc một con số trơ trọi.
  • Divider cũ không còn được khuyến nghị — dùng HorizontalDivider/VerticalDivider. Icon trong ví dụ là drawable giả định (Material Symbols tải về dạng XML) — xem Image và Icon.
