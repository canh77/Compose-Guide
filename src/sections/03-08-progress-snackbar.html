Chỉ báo tiến trình, Snackbar và kéo để làm mới

Ba thành phần này giúp app "nói chuyện" với người dùng trong lúc làm việc: chỉ báo tiến trình cho biết đang chờ gì, Snackbar thông báo kết quả ngắn gọn (kèm nút "Hoàn tác"), còn kéo để làm mới cho phép người dùng chủ động tải lại dữ liệu.

Định nghĩa

Chỉ báo tiến trình (progress indicator) có hai hình dạng: vòng tròn CircularProgressIndicator và thanh ngang LinearProgressIndicator. Mỗi loại có hai chế độ: không xác định (indeterminate — chạy liên tục vì chưa biết còn bao lâu) và xác định (determinate — hiển thị đúng phần trăm đã xong). Chúng tương ứng với ProgressBar trong XML.

Snackbar là thanh thông báo ngắn hiện ở cạnh dưới màn hình rồi tự ẩn, có thể kèm một nút hành động. Khác Toast cũ, Snackbar nằm trong giao diện của bạn, theo theme và cho phép người dùng phản hồi (ví dụ "Hoàn tác"). Trong Compose, Snackbar được quản lý bởi một SnackbarHostState — đối tượng giữ hàng đợi thông báo — và hiển thị qua SnackbarHost đặt trong Scaffold.

Kéo để làm mới (pull to refresh) là cử chỉ kéo danh sách xuống từ đầu để tải lại dữ liệu, tương tự SwipeRefreshLayout của hệ View. Material 3 cung cấp sẵn PullToRefreshBox.

Cách dùng

1. Progress indicator

Không xác địnhXác định
Vòng trònCircularProgressIndicator()CircularProgressIndicator(progress = { 0.6f })
Thanh ngangLinearProgressIndicator()LinearProgressIndicator(progress = { 0.6f })
  • Xác định khi bạn biết tỷ lệ hoàn thành: tải/tải lên file, cài đặt nhiều bước, "bước 2 trên 5". Giá trị nằm trong khoảng 0f..1f.
  • Không xác định khi không biết sẽ mất bao lâu: gọi API, đăng nhập, tải trang đầu tiên.
  • Vòng tròn hợp với chỗ nhỏ hoặc giữa vùng nội dung đang tải; thanh ngang hợp với đầu màn hình, dưới thanh tiêu đề hoặc trong một thẻ tải file.

progress là một lambda chứ không phải số trực tiếp: giá trị chỉ được đọc khi vẽ, nên khi tiến trình thay đổi, Compose chỉ cần vẽ lại thanh mà không phải chạy lại cả hàm composable (xem Vòng đời và các giai đoạn). Các tham số tùy biến hay dùng: color, trackColor (màu rãnh nền), strokeWidth (độ dày vòng tròn), modifier (ví dụ Modifier.fillMaxWidth() cho thanh ngang).

2. Snackbar từng bước

  1. Tạo host state một lần: val snackbarHostState = remember { SnackbarHostState() }.
  2. Gắn vào Scaffold: Scaffold(snackbarHost = { SnackbarHost(snackbarHostState) }) { … }.
  3. Lấy coroutine scope: val scope = rememberCoroutineScope(), vì showSnackbar là hàm suspend (xem Side effects).
  4. Trong sự kiện (ví dụ onClick): scope.launch { val result = snackbarHostState.showSnackbar(...) }.
  5. Kiểm tra result: SnackbarResult.ActionPerformed (người dùng bấm nút hành động) hoặc SnackbarResult.Dismissed (tự ẩn hoặc bị vuốt đi).
Tham số của showSnackbarÝ nghĩa
messageNội dung thông báo, nên ngắn gọn một dòng.
actionLabelChữ trên nút hành động, ví dụ "Hoàn tác"; null thì không có nút.
withDismissActiontrue để thêm nút X cho người dùng tự đóng.
durationSnackbarDuration.Short, Long hoặc Indefinite (hiện đến khi bị đóng). Mặc định là Short nếu không có nút hành động, và Indefinite nếu có.

showSnackbar "treo" (suspend) cho đến khi snackbar biến mất rồi mới trả kết quả, nên code xử lý "Hoàn tác" chỉ cần viết ngay bên dưới.

3. Kéo để làm mới với PullToRefreshBox

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun RefreshableList(rows: List<String>, isRefreshing: Boolean, onRefresh: () -> Unit) {
    PullToRefreshBox(
        isRefreshing = isRefreshing,
        onRefresh = onRefresh,
        modifier = Modifier.fillMaxSize()
    ) {
        LazyColumn(Modifier.fillMaxSize()) {
            items(rows) { Text(it, Modifier.padding(16.dp)) }
        }
    }
}

@OptIn(ExperimentalMaterial3Api::class) xác nhận bạn dùng một API Material 3 còn được đánh dấu là có thể thay đổi. PullToRefreshBox không tự tải gì cả: nó gọi onRefresh khi người dùng kéo đủ xa, còn bạn chịu trách nhiệm đặt isRefreshing = true, tải dữ liệu, rồi đặt lại false để vòng xoay biến mất.

Ví dụ

Ví dụ 1: Thanh tiến trình tải file

import kotlin.math.roundToInt

@Composable
fun DownloadCard() {
    var progress by remember { mutableFloatStateOf(0f) }
    var isDownloading by remember { mutableStateOf(false) }
    val scope = rememberCoroutineScope()
    // Làm mượt bước nhảy giữa các lần cập nhật
    val animatedProgress by animateFloatAsState(targetValue = progress, label = "download")

    OutlinedCard(Modifier.fillMaxWidth().padding(16.dp)) {
        Column(Modifier.padding(16.dp)) {
            Text("bao-cao-thang-9.pdf", style = MaterialTheme.typography.titleMedium)
            Spacer(Modifier.height(12.dp))
            LinearProgressIndicator(
                progress = { animatedProgress },
                modifier = Modifier.fillMaxWidth()
            )
            Spacer(Modifier.height(8.dp))
            Row(verticalAlignment = Alignment.CenterVertically) {
                Text(
                    text = when {
                        progress >= 1f -> "Đã tải xong"
                        isDownloading -> "Đang tải... ${(progress * 100).roundToInt()}%"
                        else -> "Chưa tải"
                    },
                    modifier = Modifier.weight(1f)
                )
                Button(
                    enabled = !isDownloading,
                    onClick = {
                        scope.launch {
                            isDownloading = true
                            progress = 0f
                            for (step in 1..20) {
                                delay(150) // giả lập nhận thêm một phần dữ liệu
                                progress = step / 20f
                            }
                            isDownloading = false
                        }
                    }
                ) {
                    Text(if (progress >= 1f) "Tải lại" else "Tải xuống")
                }
            }
        }
    }
}

Kết quả: Một thẻ có tên file, thanh tiến trình trống và dòng "Chưa tải". Bấm "Tải xuống", thanh đầy dần trong khoảng 3 giây, chữ chạy từ "Đang tải... 5%" đến 100% rồi đổi thành "Đã tải xong"; nút bị mờ trong lúc tải và sau đó thành "Tải lại".

Ví dụ 2: Xóa ghi chú với Snackbar "Hoàn tác"

data class Note(val id: Int, val title: String)

@Composable
fun NotesWithUndo() {
    val notes = remember {
        mutableStateListOf(
            Note(1, "Mua sữa cho bé"),
            Note(2, "Gọi điện cho chủ nhà"),
            Note(3, "Nộp báo cáo tuần"),
            Note(4, "Đặt lịch khám răng")
        )
    }
    val snackbarHostState = remember { SnackbarHostState() }
    val scope = rememberCoroutineScope()

    Scaffold(
        snackbarHost = { SnackbarHost(hostState = snackbarHostState) }
    ) { innerPadding ->
        LazyColumn(contentPadding = innerPadding) {
            items(notes, key = { it.id }) { note ->
                ListItem(
                    headlineContent = { Text(note.title) },
                    trailingContent = {
                        IconButton(onClick = {
                            val index = notes.indexOf(note)
                            notes.removeAt(index)
                            scope.launch {
                                // Đóng snackbar cũ (nếu có) để thông báo mới hiện ngay
                                snackbarHostState.currentSnackbarData?.dismiss()
                                val result = snackbarHostState.showSnackbar(
                                    message = "Đã xóa \"${note.title}\"",
                                    actionLabel = "Hoàn tác",
                                    duration = SnackbarDuration.Short
                                )
                                if (result == SnackbarResult.ActionPerformed) {
                                    notes.add(index.coerceAtMost(notes.size), note)
                                }
                            }
                        }) {
                            Icon(
                                painter = painterResource(R.drawable.ic_delete),
                                contentDescription = "Xóa ${note.title}"
                            )
                        }
                    }
                )
            }
        }
    }
}

Kết quả: Bấm thùng rác ở một ghi chú, ghi chú biến mất khỏi danh sách và một thanh thông báo (ví dụ: Đã xóa "Nộp báo cáo tuần") kèm nút "Hoàn tác" trượt lên ở đáy màn hình. Bấm "Hoàn tác" trong vài giây, ghi chú quay lại đúng vị trí cũ; không bấm thì thanh tự ẩn.

Ví dụ 3: Danh sách thời tiết kéo để làm mới

data class CityWeather(val city: String, val tempC: Int)

// Giả lập gọi API thời tiết
suspend fun fakeFetchWeather(): List<CityWeather> {
    delay(1500)
    return listOf("Hà Nội", "Đà Nẵng", "TP. Hồ Chí Minh", "Cần Thơ", "Đà Lạt")
        .map { CityWeather(it, (16..36).random()) }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun WeatherScreen() {
    var cities by remember { mutableStateOf(emptyList<CityWeather>()) }
    var isLoading by remember { mutableStateOf(true) }
    var isRefreshing by remember { mutableStateOf(false) }
    val scope = rememberCoroutineScope()

    // Lần tải đầu tiên khi màn hình xuất hiện
    LaunchedEffect(Unit) {
        cities = fakeFetchWeather()
        isLoading = false
    }

    if (isLoading) {
        Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
            CircularProgressIndicator()
        }
    } else {
        PullToRefreshBox(
            isRefreshing = isRefreshing,
            onRefresh = {
                isRefreshing = true
                scope.launch {
                    cities = fakeFetchWeather()
                    isRefreshing = false
                }
            },
            modifier = Modifier.fillMaxSize()
        ) {
            LazyColumn(Modifier.fillMaxSize()) {
                items(cities, key = { it.city }) { item ->
                    ListItem(
                        headlineContent = { Text(item.city) },
                        trailingContent = {
                            Text("${item.tempC}°C", style = MaterialTheme.typography.titleMedium)
                        }
                    )
                    HorizontalDivider()
                }
            }
        }
    }
}

Kết quả: Mở màn hình, một vòng tròn xoay ở giữa khoảng 1,5 giây, sau đó hiện danh sách 5 thành phố kèm nhiệt độ. Kéo danh sách xuống từ đầu, một vòng xoay nhỏ xuất hiện ở mép trên; khi dữ liệu mới về, vòng xoay thu lại và nhiệt độ các thành phố được cập nhật.

Mẹo: Trong app thật, phần gọi API và các cờ isLoading/isRefreshing nên nằm trong ViewModel, màn hình chỉ đọc state và gọi hàm — xem ViewModel.

Chú ý

  • Dạng xác định hiện tại nhận lambda: viết progress = { value }. Dạng cũ truyền thẳng Float đã ngừng khuyến nghị và khiến hàm composable chạy lại mỗi lần giá trị đổi.
  • Đừng để chỉ báo quay mãi: mọi nhánh kết thúc (thành công, lỗi, hủy) đều phải tắt cờ đang tải. Với PullToRefreshBox, quên đặt isRefreshing = false là vòng xoay treo vĩnh viễn.
  • SnackbarHostState phải được tạo trong remember, một lần cho mỗi màn hình. Viết SnackbarHostState() trần trong thân hàm sẽ tạo đối tượng mới mỗi lần recompose và làm mất thông báo đang hiện. Nếu thông báo xuất phát từ ViewModel, hãy để ViewModel phát sự kiện còn UI gọi showSnackbar.
  • Không gọi showSnackbar trực tiếp trong thân hàm composable. Dùng scope.launch trong callback, hoặc LaunchedEffect khi phản ứng với một state/sự kiện — xem Side effects.
  • Có actionLabel mà không truyền duration thì snackbar mặc định là Indefinite — nó sẽ đứng đó đến khi người dùng bấm. Muốn tự ẩn, truyền rõ SnackbarDuration.Short hoặc Long.
  • Snackbar xếp hàng: gọi liên tiếp thì cái sau chờ cái trước ẩn. Muốn thay ngay, gọi snackbarHostState.currentSnackbarData?.dismiss() trước. Lỗi nghiêm trọng cần quyết định thì dùng dialog thay vì snackbar — xem Dialog, Sheet, Menu.
  • Nội dung bên trong PullToRefreshBox phải là thành phần cuộn được (LazyColumn hoặc Column có verticalScroll) và nên fillMaxSize(); một Column thường không nhận cử chỉ kéo.
