Cử chỉ chạm và cuộn

Chạm, nhấn giữ, nhấn đúp, kéo, chụm hai ngón, cuộn — đó là cách người dùng "nói chuyện" với ứng dụng. Compose cung cấp các modifier từ đơn giản đến cấp thấp để bạn bắt được mọi cử chỉ này mà không cần viết lớp xử lý sự kiện riêng.

Định nghĩa

Cử chỉ (gesture) là một chuỗi sự kiện con trỏ (pointer — ngón tay, chuột hoặc bút) được diễn giải thành một ý định: chạm nhanh là "chọn", giữ lâu là "mở menu", di chuyển là "kéo", hai ngón tách ra là "phóng to". Trong hệ View cũ, bạn phải ghi đè onTouchEvent, dùng GestureDetector, ScaleGestureDetector hoặc bọc nội dung trong ScrollView. Trong Compose, mọi thứ là modifier gắn vào phần tử cần nhận cử chỉ.

Các API được xếp theo tầng: tầng càng cao càng ít code và tự lo luôn phản hồi thị giác, hỗ trợ tiếp cận; tầng càng thấp càng linh hoạt nhưng bạn phải tự làm nhiều hơn. Nguyên tắc: luôn bắt đầu từ tầng cao nhất đáp ứng được nhu cầu.

TầngAPIKhi nào dùng
1. Component có sẵnButton, Slider, Switch, LazyColumn, HorizontalPager, SwipeToDismissBoxKhi đã có component làm đúng việc: đủ hiệu ứng, semantics, kiểm thử sẵn.
2. Modifier cấp caoclickable, combinedClickable, toggleable, draggable, scrollable, verticalScroll, transformableBiến một phần tử bất kỳ thành thứ chạm/kéo/cuộn/phóng to được.
3. Bộ nhận diện trong pointerInputdetectTapGestures, detectDragGestures, detectTransformGesturesCần vị trí chạm, nhấn đúp, kéo tự do hai chiều.
4. Cấp thấp nhấtawaitEachGesture, awaitPointerEvent trong pointerInputTự định nghĩa một cử chỉ hoàn toàn mới (hiếm khi cần).

Cách dùng

Chạm: clickable và combinedClickable

Modifier.clickable(onClick = { … }) biến phần tử thành vùng bấm được. Khi nằm trong MaterialTheme, nó tự hiện hiệu ứng gợn (ripple — vòng sóng lan ra từ chỗ chạm), tự gộp nội dung con cho TalkBack và hỗ trợ bàn phím. Có thể truyền onClickLabel (mô tả hành động cho trình đọc màn hình) và role. Muốn thêm nhấn giữ hoặc nhấn đúp, dùng combinedClickable:

Text(
    text = "Ghi chú: Mua sữa",
    modifier = Modifier
        .combinedClickable(
            onClick = { moGhiChu() },
            onLongClick = { hienMenuXoa() },
            onDoubleClick = { danhDauQuanTrong() }
        )
        .padding(16.dp)
)

Ở các phiên bản Compose cũ, combinedClickable cần @OptIn(ExperimentalFoundationApi::class). Thứ tự modifier quan trọng: đặt clickable trước padding để cả phần đệm cũng bấm được.

Nhận diện chạm chi tiết: pointerInput + detectTapGestures

Khi cần tọa độ chỗ chạm hoặc muốn tự xử lý mà không có ripple, dùng Modifier.pointerInput(key) { detectTapGestures(onTap = …, onDoubleTap = …, onLongPress = …, onPress = …) }. Mỗi callback nhận một Offset là vị trí chạm (px, tính từ góc trên trái phần tử). Tham số key quyết định khi nào khối xử lý bị khởi động lại — xem phần Chú ý.

Kéo: detectDragGestures và draggable

  • Kéo tự do hai chiều: trong pointerInput, gọi detectDragGestures { change, dragAmount -> … }, cộng dragAmount vào một state Offset rồi dịch phần tử bằng Modifier.offset { IntOffset(…) }.
  • Kéo một chiều: Modifier.draggable(state = rememberDraggableState { delta -> … }, orientation = Orientation.Horizontal). Có thêm onDragStarted, onDragStopped (nhận vận tốc lúc buông tay).
var dichX by remember { mutableFloatStateOf(0f) }
Box(
    Modifier
        .offset { IntOffset(dichX.roundToInt(), 0) }
        .size(56.dp)
        .background(Color(0xFF26A69A), CircleShape)
        .draggable(
            orientation = Orientation.Horizontal,
            state = rememberDraggableState { delta -> dichX += delta }
        )
)

Lưu ý draggable chỉ báo khoảng kéo; việc di chuyển phần tử là do bạn cập nhật state. Muốn thả ra có hiệu ứng bật về, kết hợp với Animatable (xem Animation nâng cao).

Phóng to, xoay, di chuyển: transformable

Modifier.transformable(state = rememberTransformableState { zoomChange, panChange, rotationChange -> … }) nhận cử chỉ nhiều ngón: tỉ lệ phóng (nhân dồn), độ dịch (Offset) và góc xoay (độ). Áp các giá trị vào graphicsLayer để hiển thị. Nếu cần tâm của cử chỉ, dùng bản cấp thấp detectTransformGestures { centroid, pan, zoom, rotation -> … } trong pointerInput.

Cuộn nội dung

  • Column(Modifier.verticalScroll(rememberScrollState())) cuộn dọc; Row(Modifier.horizontalScroll(…)) cuộn ngang. Hợp với nội dung ngắn, số phần tử biết trước; danh sách dài thì dùng LazyColumn.
  • ScrollState cho biết vị trí hiện tại (value, maxValue) và cuộn bằng code: scrollTo(px) (nhảy ngay) hoặc animateScrollTo(px) (cuộn mượt) — cả hai là hàm suspend, gọi trong coroutine.
  • Modifier.scrollable là bản cấp thấp: chỉ báo khoảng cuộn (kể cả quán tính khi hất tay) mà không tự dịch nội dung.
@Composable
fun DieuKhoanSuDung() {
    val trangThaiCuon = rememberScrollState()
    val scope = rememberCoroutineScope()
    Column(Modifier.fillMaxSize()) {
        Column(
            Modifier
                .weight(1f)
                .verticalScroll(trangThaiCuon)
                .padding(16.dp)
        ) {
            repeat(40) { Text("Điều khoản số ${it + 1}: nội dung mẫu…") }
        }
        Button(
            onClick = { scope.launch { trangThaiCuon.animateScrollTo(0) } },
            modifier = Modifier.padding(16.dp)
        ) {
            Text("Về đầu trang")
        }
    }
}

Cuộn lồng nhau (nested scroll)

Khi một vùng cuộn nằm trong vùng cuộn khác hoặc cạnh thành phần phản ứng theo cuộn, Compose chuyển khoảng cuộn qua một chuỗi "cha – con": con cuộn trước, phần thừa đẩy lên cha (hoặc ngược lại). Ví dụ phổ biến nhất là thanh tiêu đề thu gọn khi cuộn danh sách: nối scrollBehavior.nestedScrollConnection vào Modifier.nestedScroll của Scaffold.

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun HopThu() {
    val scrollBehavior = TopAppBarDefaults.exitUntilCollapsedScrollBehavior()
    Scaffold(
        modifier = Modifier.nestedScroll(scrollBehavior.nestedScrollConnection),
        topBar = {
            LargeTopAppBar(title = { Text("Hộp thư") }, scrollBehavior = scrollBehavior)
        }
    ) { innerPadding ->
        LazyColumn(contentPadding = innerPadding) {
            items(50) { Text("Thư số ${it + 1}", Modifier.padding(16.dp)) }
        }
    }
}

Vuốt để xóa

Material 3 có sẵn SwipeToDismissBox cho cử chỉ vuốt ngang một hàng để xóa/lưu trữ. Bạn tạo trạng thái bằng rememberSwipeToDismissBoxState(), truyền nội dung chính (hàng danh sách) và nội dung nền hiện ra phía sau khi vuốt (thường là màu đỏ và biểu tượng thùng rác). Trạng thái cho biết hàng đang ở SwipeToDismissBoxValue.Settled, StartToEnd hay EndToStart để bạn xử lý xóa. Tham số chi tiết thay đổi giữa các phiên bản Material 3 — hãy tra trang tài liệu của SwipeToDismissBox trước khi dùng.

Ví dụ

Ví dụ 1: Ảnh nhấn đúp để thích

@Composable
fun BaiDangNhanDup() {
    var daThich by remember { mutableStateOf(false) }
    var hienTimLon by remember { mutableStateOf(false) }

    LaunchedEffect(hienTimLon) {
        if (hienTimLon) {
            delay(700)
            hienTimLon = false
        }
    }

    Column {
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .aspectRatio(1f)
                .background(Color(0xFF81D4FA))
                .pointerInput(Unit) {
                    detectTapGestures(
                        onDoubleTap = {
                            daThich = true
                            hienTimLon = true
                        }
                    )
                },
            contentAlignment = Alignment.Center
        ) {
            Text("Ảnh bài đăng", color = Color.White)
            AnimatedVisibility(visible = hienTimLon, enter = scaleIn() + fadeIn(), exit = fadeOut()) {
                // ic_favorite_filled / ic_favorite: Material Symbols XML tải từ Google Fonts (tên giả định)
                Icon(
                    painterResource(R.drawable.ic_favorite_filled),
                    contentDescription = null,
                    tint = Color.White,
                    modifier = Modifier.size(96.dp)
                )
            }
        }
        // Nút thường vẫn cần có: người dùng TalkBack không thực hiện được "nhấn đúp lên ảnh"
        IconButton(onClick = { daThich = !daThich }) {
            Icon(
                painter = painterResource(if (daThich) R.drawable.ic_favorite_filled else R.drawable.ic_favorite),
                contentDescription = if (daThich) "Bỏ thích" else "Thích",
                tint = if (daThich) Color(0xFFE53935) else LocalContentColor.current
            )
        }
    }
}

Kết quả: Nhấn đúp vào khung ảnh xanh: một trái tim trắng lớn phóng ra giữa ảnh rồi mờ đi sau khoảng 0,7 giây, đồng thời nút trái tim bên dưới chuyển sang màu đỏ. Chạm vào nút để bật/tắt thích như bình thường.

Ví dụ 2: Hình tròn kéo thả tự do

@Composable
fun HinhTronKeoTha() {
    var viTri by remember { mutableStateOf(Offset.Zero) }

    Box(
        Modifier
            .fillMaxWidth()
            .height(320.dp)
            .clipToBounds()
            .background(MaterialTheme.colorScheme.surfaceVariant)
    ) {
        Box(
            Modifier
                .offset { IntOffset(viTri.x.roundToInt(), viTri.y.roundToInt()) }
                .size(64.dp)
                .background(MaterialTheme.colorScheme.primary, CircleShape)
                .pointerInput(Unit) {
                    detectDragGestures { change, luongKeo ->
                        change.consume()      // báo rằng sự kiện đã được xử lý
                        viTri += luongKeo
                    }
                }
        )
    }
}

Kết quả: Một hình tròn màu chủ đạo ở góc trên trái vùng xám. Đặt ngón tay lên và kéo, hình tròn đi theo mọi hướng; kéo ra ngoài vùng xám thì phần vượt ra bị cắt khuất.

Ví dụ 3: Ảnh phóng to, xoay bằng hai ngón, nhấn đúp để đặt lại

Thay R.drawable.phong_canh bằng một ảnh có trong thư mục res/drawable của bạn.

@Composable
fun AnhPhongTo() {
    var tiLe by remember { mutableFloatStateOf(1f) }
    var gocXoay by remember { mutableFloatStateOf(0f) }
    var dich by remember { mutableStateOf(Offset.Zero) }

    val trangThai = rememberTransformableState { thayDoiTiLe, thayDoiViTri, thayDoiGoc ->
        tiLe = (tiLe * thayDoiTiLe).coerceIn(1f, 5f)
        gocXoay += thayDoiGoc
        dich += thayDoiViTri
    }

    // Gắn cử chỉ vào khung đứng yên, chỉ biến đổi ảnh bên trong
    Box(
        Modifier
            .fillMaxWidth()
            .aspectRatio(4f / 3f)
            .clipToBounds()
            .pointerInput(Unit) {
                detectTapGestures(onDoubleTap = {
                    tiLe = 1f
                    gocXoay = 0f
                    dich = Offset.Zero
                })
            }
            .transformable(state = trangThai)
    ) {
        Image(
            painter = painterResource(R.drawable.phong_canh),
            contentDescription = "Ảnh phong cảnh hồ trên núi",
            contentScale = ContentScale.Crop,
            modifier = Modifier
                .fillMaxSize()
                .graphicsLayer {
                    scaleX = tiLe
                    scaleY = tiLe
                    rotationZ = gocXoay
                    translationX = dich.x
                    translationY = dich.y
                }
        )
    }
}

Kết quả: Đặt hai ngón lên ảnh rồi tách ra để phóng to (tối đa 5 lần), xoay hai ngón để xoay ảnh, di chuyển để dời ảnh. Nhấn đúp bất kỳ lúc nào, ảnh trở về kích thước và vị trí ban đầu.

Chú ý

  • Key của pointerInput. Khối lệnh bên trong chỉ khởi động lại khi key đổi. Nếu nó dùng một tham số từ bên ngoài (ví dụ lambda onThich hay biến choPhepKeo), hãy đưa tham số đó vào key, hoặc bọc bằng rememberUpdatedState; nếu không, khối sẽ giữ giá trị cũ mãi. Ghi/đọc state by remember như trong các ví dụ thì an toàn với Unit.
  • Không lồng hai vùng cuộn cùng chiều. Đặt LazyColumn bên trong Column(Modifier.verticalScroll(…)) sẽ gây lỗi đo chiều cao vô hạn. Hãy gộp tất cả vào một LazyColumn (dùng nhiều item { }) hoặc cho danh sách bên trong chiều cao cố định.
  • Gọi change.consume() khi đã xử lý kéo để phần tử cha (ví dụ vùng cuộn) không xử lý thêm lần nữa.
  • Dùng offset { } dạng lambda cho vị trí thay đổi liên tục: giá trị được đọc ở giai đoạn bố cục nên không gây recompose mỗi khung hình.
  • Cử chỉ tùy chỉnh không tự có semantics. pointerInput không báo gì cho TalkBack; luôn cung cấp cách thay thế bằng nút hoặc customActions (xem Hỗ trợ tiếp cận).
  • Cẩn thận khi đặt transformable/kéo ngang bên trong HorizontalPager hoặc vùng cuộn ngang: hai bên tranh nhau cùng một cử chỉ, gây cảm giác "kẹt".
Cảnh báo: Bỏ ripple bằng clickable(interactionSource = remember { MutableInteractionSource() }, indication = null) { … } chỉ nên làm khi bạn có phản hồi thị giác khác. Phần tử bấm được mà không phản hồi gì khiến người dùng không biết thao tác đã có tác dụng.
