Thiết lập dự án Compose

Trước khi viết dòng giao diện đầu tiên, project cần đúng plugin, đúng SDK và đúng bộ thư viện. Mục này đi từ việc tạo project mới bằng Android Studio, giải thích từng file cấu hình, đến cách thêm Compose vào một app View có sẵn.

Định nghĩa

Một project Compose về bản chất vẫn là project Android dùng Gradle, chỉ thêm ba thứ: Compose Compiler (plugin Gradle org.jetbrains.kotlin.plugin.compose, biến hàm @Composable thành mã chạy được), cờ buildFeatures { compose = true }, và các thư viện Compose (ui, foundation, material3…).

Để các thư viện Compose luôn tương thích với nhau, Google phát hành BOM (Bill of Materials — "bảng kê vật tư"): một artifact đặc biệt chỉ chứa danh sách version đã được kiểm thử chung. Bạn khai báo version cho BOM một lần, các thư viện Compose còn lại không cần ghi version. Ngoài ra, project hiện đại dùng version catalog (gradle/libs.versions.toml) để gom tên và version thư viện vào một chỗ.

Lưu ý: Từ Compose 1.12, project phải dùng compileSdk 37 và Android Gradle Plugin (AGP) 9. Plugin Compose Compiler chỉ có từ Kotlin 2.0 trở lên và luôn mang cùng version với Kotlin (ví dụ Kotlin 2.4.10 thì plugin cũng là 2.4.10).

Cách dùng

Bước 1: Tạo project bằng template

  1. Mở Android Studio, chọn New Project.
  2. Ở nhóm Phone and Tablet, chọn template Empty Activity (template có biểu tượng Compose; đừng nhầm với Empty Views Activity dùng XML).
  3. Điền Name (ví dụ MyNotes), Package name (ví dụ com.example.mynotes), chọn Minimum SDK và ngôn ngữ cấu hình build là Kotlin DSL (build.gradle.kts).
  4. Bấm Finish và chờ Gradle sync xong (lần đầu có thể mất vài phút để tải thư viện).
  5. Bấm Run để chạy app mẫu trên máy ảo hoặc điện thoại thật.

Bước 3: BOM và cách ghi đè version

Khai báo BOM bằng platform(…), sau đó các thư viện Compose không ghi version. Nếu cần một thư viện mới hơn bản trong BOM (ví dụ để thử tính năng mới), chỉ cần ghi version tường minh cho riêng thư viện đó — version bạn ghi sẽ được ưu tiên, các thư viện khác vẫn theo BOM.

dependencies {
    implementation(platform("androidx.compose:compose-bom:2026.09.00"))
    implementation("androidx.compose.material3:material3")       // theo BOM: 1.4.0
    implementation("androidx.compose.foundation:foundation")     // theo BOM: 1.12.1

    // Ghi đè: ghi version cụ thể cho riêng một thư viện (số version chỉ minh họa)
    // implementation("androidx.compose.animation:animation:1.13.0-alpha01")
}

BOM chỉ quản lý thư viện trong nhóm androidx.compose.*. Các thư viện khác như activity-compose, lifecycle-*, navigation-compose vẫn phải ghi version riêng.

Bước 4: Thêm Compose vào project View có sẵn

  1. Đảm bảo project dùng Kotlin 2.0+, AGP 9 và compileSdk = 37.
  2. Thêm plugin org.jetbrains.kotlin.plugin.compose (cùng version Kotlin) vào file build gốc với apply false và vào module app.
  3. Bật buildFeatures { compose = true } trong khối android của module.
  4. Thêm BOM và các thư viện Compose (xem ví dụ 1).
  5. Dùng Compose ở nơi cần: cả màn hình bằng setContent trong Activity, hoặc một phần màn hình bằng ComposeView (ví dụ 3). Chi tiết ở Tương thích View.

Kết quả: Gradle sync thành công; trong code bạn dùng được MaterialTheme, Text, @Preview… Gạch nối trong tên catalog (androidx-compose-bom) trở thành dấu chấm khi dùng (libs.androidx.compose.bom).

Lưu ý: AGP 9 đã tích hợp sẵn Kotlin (built-in Kotlin), nên module không còn áp dụng plugin org.jetbrains.kotlin.android. Project cũ nâng lên AGP 9 cần gỡ plugin này và chuyển khối kotlinOptions sang kotlin { compilerOptions { … } }. Plugin Compose Compiler thì vẫn phải khai báo như trên.

Ví dụ 2: MainActivity và theme

MainActivity.kt

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge() // gọi trước setContent
        setContent {
            MyNotesTheme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    Greeting(
                        name = "Compose",
                        modifier = Modifier.padding(innerPadding)
                    )
                }
            }
        }
    }
}

@Composable
fun Greeting(name: String, modifier: Modifier = Modifier) {
    Text(text = "Xin chào $name!", modifier = modifier)
}

ui/theme/Theme.kt (rút gọn)

@Composable
fun MyNotesTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colorScheme = if (darkTheme) darkColorScheme() else lightColorScheme()
    MaterialTheme(
        colorScheme = colorScheme,
        content = content
    )
}

Kết quả: App vẽ tràn viền (nội dung nằm sau thanh trạng thái và thanh điều hướng), nhưng nhờ innerPadding của Scaffold nên dòng "Xin chào Compose!" không bị che. Màu tự đổi theo chế độ sáng/tối của máy. Xem thêm Tràn viền và Tùy biến theme.

Ví dụ 3: Nhúng Compose vào layout XML cũ

res/layout/activity_profile.xml (một phần)

<androidx.compose.ui.platform.ComposeView
    android:id="@+id/compose_banner"
    android:layout_width="match_parent"
    android:layout_height="wrap_content" />

ProfileActivity.kt

class ProfileActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_profile)

        findViewById<ComposeView>(R.id.compose_banner).setContent {
            MaterialTheme {
                Text(
                    text = "Phần này được viết bằng Compose",
                    modifier = Modifier.padding(16.dp)
                )
            }
        }
    }
}

Kết quả: Màn hình XML cũ vẫn giữ nguyên, riêng vị trí của ComposeView hiển thị dòng chữ do Compose vẽ. Đây là cách chuyển đổi dần từng phần.

Chú ý

  • Plugin Compose lệch version Kotlin: org.jetbrains.kotlin.plugin.compose phải trùng version với Kotlin mà project dùng. Dùng chung một biến kotlin trong version catalog để không bao giờ lệch.
  • Dùng Kotlin 2.x mà không khai báo plugin Compose: build sẽ báo lỗi yêu cầu Compose Compiler Gradle plugin. Cách cũ composeOptions { kotlinCompilerExtensionVersion = … } chỉ dành cho Kotlin 1.x, không dùng nữa.
  • Quên buildFeatures { compose = true }: luôn bật cờ này trong module có dùng Compose, nếu không dễ gặp lỗi build hoặc preview không hoạt động.
  • compileSdk thấp: với BOM 2026.09.00 (Compose 1.12), compileSdk dưới 37 sẽ làm bước kiểm tra AAR metadata báo lỗi yêu cầu biên dịch với API 37. Nâng compileSdk (không bắt buộc nâng targetSdk cùng lúc).
  • Trộn version thủ công: đừng ghi version cho từng thư viện Compose khi đã có BOM, trừ khi cố ý ghi đè. Ghi lẫn lộn dễ gây xung đột khó tìm.
  • ui-tooling chỉ cần ở debugImplementation; ui-tooling-preview ở implementation vì annotation @Preview nằm trong code chính. Xem @Preview.
Cảnh báo: AGP 9 cần JDK 17 trở lên để chạy Gradle. Nếu sync báo lỗi về phiên bản Java, vào Settings → Build, Execution, Deployment → Build Tools → Gradle và chọn Gradle JDK phù hợp (bản JDK đi kèm Android Studio là lựa chọn an toàn).
