Điều hướng với Navigation Compose

Hầu hết ứng dụng có nhiều màn hình: danh sách, chi tiết, chỉnh sửa, cài đặt. Navigation Compose quản lý việc chuyển giữa các màn hình, truyền tham số và nút Back một cách nhất quán, với route kiểm tra kiểu ngay lúc biên dịch.

Định nghĩa

Trong hệ View cũ, mỗi màn hình thường là một Activity hoặc Fragment, chuyển màn bằng Intent hay FragmentTransaction. Với Compose, màn hình chỉ là hàm composable, nên cần một thành phần ghi nhớ "đang ở màn nào, trước đó là màn nào" và hiển thị đúng composable. Thư viện Navigation Compose (androidx.navigation:navigation-compose:2.10.2) làm việc đó. Từ bản 2.8, mỗi màn hình được định danh bằng một lớp Kotlin đánh dấu @Serializable, gọi là route type-safe, thay cho chuỗi đường dẫn dễ gõ sai.

Khái niệmÝ nghĩa
NavController"Bộ điều khiển" giữ back stack và thực hiện lệnh navigate, popBackStack. Tạo bằng rememberNavController().
NavHostComposable hiển thị màn hình ứng với đích hiện tại trong back stack.
Navigation graphTập hợp mọi đích và cách chúng nối với nhau, khai báo trong lambda của NavHost.
Destination (đích)Một màn hình trong graph, khai báo bằng composable<Route> { … }.
RouteLớp/object @Serializable định danh một đích, có thể mang tham số.
Back stackNgăn xếp các đích đã mở; đích trên cùng đang hiển thị. Mỗi phần tử là một NavBackStackEntry.

Cách dùng

Bước 1: Thiết lập Gradle

gradle/libs.versions.toml (dùng lại version kotlin đã có sẵn trong catalog)

[versions]
navigationCompose = "2.10.2"
kotlinxSerializationJson = "1.7.3"

[libraries]
androidx-navigation-compose = { group = "androidx.navigation", name = "navigation-compose", version.ref = "navigationCompose" }
kotlinx-serialization-json = { group = "org.jetbrains.kotlinx", name = "kotlinx-serialization-json", version.ref = "kotlinxSerializationJson" }

[plugins]
kotlin-serialization = { id = "org.jetbrains.kotlin.plugin.serialization", version.ref = "kotlin" }
// build.gradle.kts (cấp project)
plugins {
    alias(libs.plugins.kotlin.serialization) apply false
}

// app/build.gradle.kts
plugins {
    alias(libs.plugins.kotlin.serialization)
}
dependencies {
    implementation(libs.androidx.navigation.compose)
    implementation(libs.kotlinx.serialization.json)
}

Không dùng version catalog thì khai báo trực tiếp: plugin id("org.jetbrains.kotlin.plugin.serialization") với version bằng đúng version Kotlin của dự án, cùng implementation("androidx.navigation:navigation-compose:2.10.2") và implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.7.3").

Bước 2: Định nghĩa route

@Serializable object NoteList                          // không có tham số
@Serializable data class NoteDetail(val noteId: String) // có tham số
@Serializable data class NoteEdit(val noteId: String)

Bước 3: Tạo NavHost, điều hướng và nhận tham số

  • Đi tới màn khác: navController.navigate(NoteDetail(noteId = "42")).
  • Nhận tham số trong đích: val detail: NoteDetail = backStackEntry.toRoute().
  • Quay lại: navController.popBackStack() (bỏ đích trên cùng) hoặc navController.navigateUp() (nút mũi tên trên thanh tiêu đề). Nút Back hệ thống được NavHost xử lý tự động.
  • Chỉ truyền ID hoặc giá trị nhỏ, không truyền cả đối tượng lớn. Màn đích dùng ID để tự lấy dữ liệu từ repository/ViewModel.

Tùy chọn khi điều hướng

Sau khi đăng nhập thành công, người dùng không nên bấm Back mà quay lại màn đăng nhập:

navController.navigate(Home) {
    popUpTo<Login> { inclusive = true } // xóa mọi đích đến hết Login, kể cả Login
    launchSingleTop = true             // không tạo bản sao nếu Home đã ở trên cùng
}

Graph lồng nhau (nested graph)

Gom các màn hình liên quan thành một nhóm có đích bắt đầu riêng; từ bên ngoài chỉ cần navigate(SettingsGraph).

@Serializable object SettingsGraph
@Serializable object SettingsHome
@Serializable object AccountSettings

// bên trong NavHost { … }
navigation<SettingsGraph>(startDestination = SettingsHome) {
    composable<SettingsHome> { /* ... */ }
    composable<AccountSettings> { /* ... */ }
}

ViewModel theo từng đích

Gọi viewModel() (thư viện lifecycle-viewmodel-compose) bên trong composable<…> sẽ tạo ViewModel gắn với đích đó: sống khi đích còn trong back stack, bị hủy khi đích bị pop. SavedStateHandle của ViewModel chứa sẵn tham số route:

class NoteDetailViewModel(savedStateHandle: SavedStateHandle) : ViewModel() {
    private val route = savedStateHandle.toRoute<NoteDetail>()
    val note: Note? = NotesRepository.find(route.noteId)
}

Deep link

Cho phép mở thẳng một đích từ đường dẫn bên ngoài. Navigation tự ghép tham số của route vào sau basePath; bạn cần khai báo thêm intent-filter tương ứng cho Activity trong AndroidManifest.xml.

composable<NoteDetail>(
    deepLinks = listOf(navDeepLink<NoteDetail>(basePath = "https://example.com/note"))
) { /* ... */ }
Lưu ý: Google còn phát triển Navigation 3 (androidx.navigation3), thư viện mới hơn trong đó back stack là một danh sách do chính ứng dụng sở hữu và điều khiển. Khi đã vững Navigation Compose, bạn có thể tìm hiểu thêm hướng này.

Ví dụ

App ghi chú: danh sách → chi tiết → sửa

Dữ liệu và route. Repository lưu trong bộ nhớ cho gọn; ứng dụng thật nên dùng ViewModel và Room.

data class Note(val id: String, val title: String, val body: String)

object NotesRepository {
    private val notes = mutableStateListOf(
        Note("1", "Đi chợ", "Mua rau, trứng, sữa"),
        Note("2", "Học Compose", "Đọc phần Navigation")
    )
    fun all(): List<Note> = notes
    fun find(id: String): Note? = notes.firstOrNull { it.id == id }
    fun update(note: Note) {
        val index = notes.indexOfFirst { it.id == note.id }
        if (index >= 0) notes[index] = note
    }
}

@Serializable object NoteList
@Serializable data class NoteDetail(val noteId: String)
@Serializable data class NoteEdit(val noteId: String)

Graph điều hướng: chỉ nơi này biết đến NavController.

@Composable
fun NotesApp() {
    val navController = rememberNavController()
    NavHost(navController = navController, startDestination = NoteList) {
        composable<NoteList> {
            NoteListScreen(onOpenNote = { id -> navController.navigate(NoteDetail(noteId = id)) })
        }
        composable<NoteDetail> { backStackEntry ->
            val detail: NoteDetail = backStackEntry.toRoute()
            NoteDetailScreen(
                noteId = detail.noteId,
                onEdit = { id -> navController.navigate(NoteEdit(noteId = id)) },
                onBack = { navController.navigateUp() }
            )
        }
        composable<NoteEdit> { backStackEntry ->
            val edit: NoteEdit = backStackEntry.toRoute()
            NoteEditScreen(noteId = edit.noteId, onDone = { navController.popBackStack() })
        }
    }
}

Các màn hình chỉ nhận lambda, không nhận NavController. Icon mũi tên là file Material Symbols ic_arrow_back.xml tải từ Google Fonts (tên giả định); thêm android:autoMirrored="true" vào thẻ vector để mũi tên tự lật khi dùng ngôn ngữ RTL (xem Image & Icon).

@Composable
fun BackButton(onClick: () -> Unit) {
    IconButton(onClick = onClick) {
        Icon(painterResource(R.drawable.ic_arrow_back), contentDescription = "Quay lại")
    }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun NoteListScreen(onOpenNote: (String) -> Unit) {
    Scaffold(topBar = { TopAppBar(title = { Text("Ghi chú") }) }) { innerPadding ->
        LazyColumn(contentPadding = innerPadding) {
            items(NotesRepository.all(), key = { it.id }) { note ->
                ListItem(
                    headlineContent = { Text(note.title) },
                    supportingContent = { Text(note.body, maxLines = 1) },
                    modifier = Modifier.clickable { onOpenNote(note.id) }
                )
            }
        }
    }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun NoteDetailScreen(noteId: String, onEdit: (String) -> Unit, onBack: () -> Unit) {
    val note = NotesRepository.find(noteId)
    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text(note?.title ?: "Không tìm thấy") },
                navigationIcon = { BackButton(onBack) },
                actions = {
                    TextButton(onClick = { onEdit(noteId) }, enabled = note != null) { Text("Sửa") }
                }
            )
        }
    ) { innerPadding ->
        Text(
            text = note?.body ?: "Ghi chú không còn tồn tại.",
            modifier = Modifier.padding(innerPadding).padding(16.dp)
        )
    }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun NoteEditScreen(noteId: String, onDone: () -> Unit) {
    val note = NotesRepository.find(noteId) ?: return
    var title by rememberSaveable { mutableStateOf(note.title) }
    var body by rememberSaveable { mutableStateOf(note.body) }
    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text("Sửa ghi chú") },
                navigationIcon = { BackButton(onDone) },
                actions = {
                    TextButton(onClick = {
                        NotesRepository.update(note.copy(title = title, body = body))
                        onDone()
                    }) { Text("Lưu") }
                }
            )
        }
    ) { innerPadding ->
        Column(
            Modifier.padding(innerPadding).padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(12.dp)
        ) {
            OutlinedTextField(value = title, onValueChange = { title = it },
                label = { Text("Tiêu đề") }, modifier = Modifier.fillMaxWidth())
            OutlinedTextField(value = body, onValueChange = { body = it },
                label = { Text("Nội dung") }, minLines = 5, modifier = Modifier.fillMaxWidth())
        }
    }
}

Kết quả: Ứng dụng mở ở danh sách hai ghi chú. Chạm "Đi chợ" mở màn chi tiết có mũi tên quay lại và nút "Sửa". Ở màn sửa, đổi tiêu đề rồi bấm "Lưu": ứng dụng quay về màn chi tiết và tiêu đề mới hiển thị ngay. Nút Back hệ thống đi lùi đúng thứ tự sửa → chi tiết → danh sách.

Chú ý

  • Tạo NavController một lần ở cấp cao nhất (cạnh NavHost). Không truyền nó xuống các màn hình; hãy truyền lambda như onOpenDetail: (String) -> Unit để màn hình dễ Preview, dễ test và tái sử dụng.
  • Chỉ gọi navigate trong callback (onClick) hoặc effect, không gọi trong thân composable; nếu không, lệnh điều hướng chạy lại sau mỗi lần recompose.
  • Người dùng bấm nhanh hai lần có thể mở hai bản sao màn hình. Dùng launchSingleTop = true, hoặc bọc callback bằng dropUnlessResumed { … } của lifecycle-runtime-compose.
  • Route chỉ nên chứa ID và kiểu đơn giản (String, Int, Boolean…). Đối tượng lớn sẽ bị tuần tự hóa vào back stack, tốn bộ nhớ và dễ lỗi khi khôi phục.
  • navigateUp() không thoát ứng dụng khi đang ở đích bắt đầu, còn popBackStack() ở đích cuối cùng có thể để lại màn hình trống. Dùng navigateUp() cho nút mũi tên trên TopAppBar.
  • Quên áp dụng plugin kotlin.plugin.serialization sẽ gây lỗi khi chạy (không tìm thấy serializer cho route), dù code vẫn biên dịch được.
Mẹo: Kết hợp với thanh điều hướng dưới đáy màn hình ở mục Thanh điều hướng để chuyển giữa các tab chính.
