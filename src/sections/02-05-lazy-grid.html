Lưới: LazyVerticalGrid và lưới so le

Khi cần xếp nhiều phần tử thành nhiều cột, ví dụ sản phẩm trong cửa hàng, ảnh trong album hay biểu tượng ứng dụng, bạn dùng lưới lazy. Lưới lazy chỉ dựng những ô sắp hiện trên màn hình, nên vẫn cuộn mượt khi có hàng nghìn phần tử.

Định nghĩa

LazyVerticalGrid là một danh sách lazy (chỉ tạo phần tử khi nó sắp xuất hiện) nhưng xếp phần tử thành nhiều cột và cuộn theo chiều dọc. Bản ngược lại là LazyHorizontalGrid: xếp thành nhiều hàng và cuộn ngang. Cả hai dùng chung cách viết với LazyColumn/LazyRow: bạn mô tả nội dung bằng item { } và items(…) { }, còn Compose lo việc đo đạc, tái sử dụng và dọn dẹp những ô đã cuộn khỏi màn hình.

Trong hệ View cũ, để làm lưới bạn cần RecyclerView + GridLayoutManager + Adapter + ViewHolder, và phải viết SpanSizeLookup nếu muốn một ô chiếm nhiều cột. Compose gói tất cả vào một hàm; việc "chiếm nhiều cột" chỉ là một tham số span.

Khi các ô có chiều cao khác nhau (kiểu Pinterest), lưới thường sẽ để lại khoảng trống xấu vì mỗi hàng cao bằng ô cao nhất. Lúc đó bạn dùng LazyVerticalStaggeredGrid – lưới so le: mỗi cột tự xếp chồng phần tử của nó, ô mới luôn được đặt vào cột đang thấp nhất, nên các ô khít nhau.

Cách dùng

1. Chọn cách chia cột bằng GridCells

Tham số bắt buộc là columns (với lưới dọc) hoặc rows (với lưới ngang). Có ba kiểu:

KiểuCách hoạt độngKhi nào dùng
GridCells.Fixed(3)Luôn đúng 3 cột; chiều rộng màn hình được chia đều cho 3 cột.Số cột không đổi theo màn hình, ví dụ bàn phím số, lịch 7 cột.
GridCells.Adaptive(minSize = 150.dp)Tạo nhiều cột nhất có thể sao cho mỗi cột rộng ít nhất 150dp; phần dư chia đều cho các cột.Lưới sản phẩm, ảnh cần tự thích ứng điện thoại, máy tính bảng, xoay ngang. Thường là lựa chọn tốt nhất.
GridCells.FixedSize(size = 120.dp)Mỗi cột rộng đúng 120dp; vừa bao nhiêu cột thì tạo bấy nhiêu, phần thừa được phân bổ theo horizontalArrangement.Ô phải giữ kích thước chính xác, ví dụ ảnh đại diện, ô màu.

2. Khoảng cách và lề

  • contentPadding: lề bao quanh toàn bộ nội dung. Khác với Modifier.padding, phần lề này cuộn cùng nội dung nên ô không bị cắt ở mép.
  • verticalArrangement = Arrangement.spacedBy(12.dp): khoảng cách giữa các hàng.
  • horizontalArrangement = Arrangement.spacedBy(12.dp): khoảng cách giữa các cột.
  • state = rememberLazyGridState(): dùng khi cần đọc vị trí cuộn hoặc cuộn bằng code (giống LazyListState).

3. key, contentType và span

Hàm items của lưới nhận thêm tham số span để quyết định một ô chiếm bao nhiêu cột. Bên trong lambda span bạn có maxLineSpan (tổng số cột của một hàng) và maxCurrentLineSpan (số cột còn trống ở hàng hiện tại).

Tiêu đề chiếm trọn một hàng, sản phẩm nổi bật chiếm 2 cột:

LazyVerticalGrid(columns = GridCells.Fixed(2)) {
    item(span = { GridItemSpan(maxLineSpan) }) {
        Text("Bán chạy tuần này")
    }
    items(
        items = products,
        key = { it.id },
        span = { product -> GridItemSpan(if (product.featured) 2 else 1) }
    ) { product ->
        ProductTile(product)
    }
}

4. Lưới so le

LazyVerticalStaggeredGrid dùng StaggeredGridCells.Fixed, StaggeredGridCells.Adaptive hoặc StaggeredGridCells.FixedSize, ý nghĩa giống bảng trên. Lưu ý hai khác biệt:

  • Khoảng cách giữa các ô theo chiều dọc dùng verticalItemSpacing = 8.dp (kiểu Dp) thay vì verticalArrangement.
  • Để một ô chiếm cả hàng, dùng StaggeredGridItemSpan.FullLine. Với item bạn truyền thẳng giá trị (span = StaggeredGridItemSpan.FullLine); với items bạn truyền lambda nhận từng phần tử.

Bản cuộn ngang tương ứng là LazyHorizontalStaggeredGrid (dùng rows và horizontalItemSpacing).

Ví dụ

Ví dụ 1: Lưới sản phẩm tự thích ứng

data class Product(val id: Int, val name: String, val price: Int)

@Composable
fun ProductGrid(products: List<Product>, onProductClick: (Product) -> Unit) {
    LazyVerticalGrid(
        columns = GridCells.Adaptive(minSize = 150.dp),
        modifier = Modifier.fillMaxSize(),
        contentPadding = PaddingValues(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp),
        horizontalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        items(products, key = { it.id }) { product ->
            ProductCard(product, onClick = { onProductClick(product) })
        }
    }
}

@Composable
fun ProductCard(product: Product, onClick: () -> Unit) {
    Card(onClick = onClick) {
        // Ô vuông giữ chỗ cho ảnh sản phẩm
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .aspectRatio(1f)
                .background(MaterialTheme.colorScheme.secondaryContainer)
        )
        Column(Modifier.padding(12.dp)) {
            Text(
                text = product.name,
                style = MaterialTheme.typography.titleSmall,
                maxLines = 1,
                overflow = TextOverflow.Ellipsis
            )
            Text(
                text = "%,d đ".format(product.price),
                style = MaterialTheme.typography.bodyMedium,
                color = MaterialTheme.colorScheme.primary
            )
        }
    }
}

@Preview(widthDp = 360, heightDp = 640)
@Composable
fun ProductGridPreview() {
    val sample = List(12) { Product(id = it, name = "Sản phẩm số ${it + 1}", price = (it + 1) * 25_000) }
    MaterialTheme { ProductGrid(sample, onProductClick = {}) }
}

Kết quả: Trên điện thoại dọc thấy 2 cột thẻ sản phẩm vuông vức, mỗi thẻ có ô ảnh, tên và giá. Xoay ngang hoặc mở trên máy tính bảng, lưới tự tăng lên 4–6 cột mà không cần sửa code.

Ví dụ 2: Lưới chia theo danh mục, tiêu đề chiếm cả hàng

@Composable
fun CategorizedGrid(sections: Map<String, List<Product>>) {
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),
        contentPadding = PaddingValues(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp),
        horizontalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        sections.forEach { (category, products) ->
            item(
                key = "header-$category",
                span = { GridItemSpan(maxLineSpan) },
                contentType = "header"
            ) {
                Text(
                    text = category,
                    style = MaterialTheme.typography.titleLarge,
                    modifier = Modifier.padding(top = 8.dp)
                )
            }
            items(products, key = { it.id }, contentType = { "product" }) { product ->
                ProductCard(product, onClick = {})
            }
        }
    }
}

Kết quả: Mỗi danh mục ("Áo", "Giày", "Phụ kiện"…) có một dòng tiêu đề trải hết bề ngang, bên dưới là các sản phẩm xếp 2 cột. Tiêu đề cuộn cùng lưới như một ô bình thường.

Ví dụ 3: Thư viện ảnh so le kiểu Pinterest

data class Photo(val id: Int, val heightDp: Int, val color: Color)

@Composable
fun PhotoGallery(photos: List<Photo>) {
    LazyVerticalStaggeredGrid(
        columns = StaggeredGridCells.Adaptive(minSize = 140.dp),
        modifier = Modifier.fillMaxSize(),
        contentPadding = PaddingValues(12.dp),
        verticalItemSpacing = 8.dp,
        horizontalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        item(span = StaggeredGridItemSpan.FullLine) {
            Text("Album Đà Lạt", style = MaterialTheme.typography.headlineSmall)
        }
        items(photos, key = { it.id }) { photo ->
            Box(
                modifier = Modifier
                    .fillMaxWidth()
                    .height(photo.heightDp.dp)
                    .clip(RoundedCornerShape(12.dp))
                    .background(photo.color)
            )
        }
    }
}

@Preview
@Composable
fun PhotoGalleryPreview() {
    val colors = listOf(Color(0xFF90CAF9), Color(0xFFA5D6A7), Color(0xFFFFCC80), Color(0xFFCE93D8))
    val heights = listOf(120, 200, 160, 240, 140)
    val photos = List(20) { i -> Photo(id = i, heightDp = heights[i % heights.size], color = colors[i % colors.size]) }
    MaterialTheme { PhotoGallery(photos) }
}

Kết quả: Dòng tiêu đề "Album Đà Lạt" nằm trên cùng, bên dưới là các khối màu cao thấp khác nhau xếp khít vào 2 cột (hoặc nhiều hơn trên màn hình rộng), không có khoảng trống giữa các ô. Trong app thật, bạn thay Box bằng ảnh tải từ mạng (ví dụ thư viện Coil).

Chú ý

  • Không lồng lưới lazy cuộn dọc vào vùng cuộn dọc khác (Column có verticalScroll, hoặc bên trong LazyColumn). Lưới sẽ nhận chiều cao "vô hạn" và app bị crash. Muốn có phần đầu trang phía trên lưới, hãy đưa nó vào lưới dưới dạng item với span chiếm cả hàng.
  • Luôn truyền key ổn định và duy nhất trong toàn lưới, kể cả các dòng tiêu đề (như "header-$category" ở ví dụ 2). Key trùng nhau sẽ làm app crash; thiếu key thì trạng thái của ô có thể "nhảy" sang ô khác khi danh sách thay đổi.
  • Khi lưới có nhiều loại ô (tiêu đề, sản phẩm, quảng cáo…), khai báo contentType để Compose chỉ tái sử dụng ô cùng loại, giúp cuộn mượt hơn.
  • Ưu tiên GridCells.Adaptive thay cho Fixed để giao diện đẹp trên mọi kích thước màn hình. Xem thêm Giao diện thích ứng.
  • Với lưới so le, hãy biết trước tỉ lệ khung ảnh (thường server trả về chiều rộng/cao) và đặt Modifier.aspectRatio(…) cho ô. Nếu để ô tự co theo ảnh vừa tải xong, cả lưới sẽ bị nhảy vị trí khi người dùng đang cuộn.
  • Muốn ô có hiệu ứng khi thêm, xóa, đổi chỗ, gắn Modifier.animateItem() cho phần tử ngay trong items { }, giống như với LazyColumn.
Lưu ý: Nếu chỉ có vài chục phần tử cố định và không cần cuộn lazy, các bản Compose gần đây còn có layout không-lazy mới là Grid và FlexBox; xem mục riêng của chúng trong tài liệu Layouts.
