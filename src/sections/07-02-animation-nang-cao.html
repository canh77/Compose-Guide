Animation nâng cao: Transition, Animatable và lặp vô hạn

Khi một trạng thái làm đổi nhiều thuộc tính cùng lúc, khi cần hiệu ứng lặp mãi, hoặc khi chuyển động phải bám theo ngón tay, các API cơ bản như animate*AsState không còn đủ. Phần này giới thiệu bộ công cụ "điều khiển bằng tay" của Compose để làm những animation đó gọn và mượt.

Định nghĩa

Ở phần Animation cơ bản, mỗi giá trị được animate độc lập: trạng thái đổi, Compose tự chạy từ giá trị cũ sang giá trị mới. Ba API nâng cao sau đây cho bạn nhiều quyền kiểm soát hơn:

  • Transition (tạo bằng updateTransition): một "nhạc trưởng" gắn với một trạng thái. Mọi giá trị con (màu, kích thước, độ dày viền…) khai báo trên cùng một transition sẽ bắt đầu và kết thúc đồng bộ.
  • InfiniteTransition (tạo bằng rememberInfiniteTransition): chạy lặp đi lặp lại không ngừng chừng nào composable còn trên màn hình; hợp cho hiệu ứng nhấp nháy, xoay vòng, khung chờ tải (skeleton loading).
  • Animatable: một "giá trị biết tự chuyển động" mà bạn ra lệnh trực tiếp bằng các hàm suspend (animateTo, snapTo, animateDecay) bên trong coroutine. Đây là lựa chọn số một cho animation đi theo cử chỉ.

Cả ba đều nhận một AnimationSpec — "công thức chuyển động" mô tả giá trị đi từ đầu đến cuối ra sao: nảy như lò xo (spring), chạy trong thời lượng cố định (tween), đi qua các mốc (keyframes)… Nếu từng dùng hệ View, có thể hình dung Transition giống AnimatorSet chạy song song, InfiniteTransition giống ValueAnimator với số lần lặp vô hạn, còn Animatable giống SpringAnimation/FlingAnimation. Khác biệt lớn: trong Compose, animation tự dừng và dọn dẹp khi composable rời khỏi màn hình.

Cách dùng

1. updateTransition: nhiều giá trị, một nhịp

  1. Gọi updateTransition(targetState = …, label = "…") với state điều khiển (thường là Boolean hoặc một enum).
  2. Khai báo từng giá trị con bằng animateDp, animateFloat, animateColor, animateOffset… Lambda cuối nhận trạng thái và trả về giá trị tương ứng.
  3. Tùy chỉnh chuyển động riêng cho từng giá trị qua transitionSpec; dùng isTransitioningTo để chọn spec theo chiều chuyển.
val transition = updateTransition(targetState = dangMo, label = "ngan-keo")
val doCao by transition.animateDp(
    transitionSpec = {
        if (false isTransitioningTo true) spring(stiffness = Spring.StiffnessLow)
        else tween(durationMillis = 200)
    },
    label = "doCao"
) { mo -> if (mo) 240.dp else 0.dp }

Tham số label không ảnh hưởng tới hành vi, nhưng là tên hiển thị trong công cụ Animation Preview — hãy luôn đặt tên dễ hiểu.

2. rememberInfiniteTransition: lặp vô hạn

Tạo transition một lần, rồi khai báo giá trị bằng animateFloat/animateColor với initialValue, targetValue và một infiniteRepeatable(…). RepeatMode.Restart nhảy về đầu sau mỗi vòng; RepeatMode.Reverse chạy ngược lại (đi – về), hợp cho hiệu ứng "thở".

3. Animatable: điều khiển trực tiếp

  • Tạo trong remember { Animatable(0f) }. Với kiểu khác Float/Color, truyền thêm bộ chuyển đổi, ví dụ Animatable(Offset.Zero, Offset.VectorConverter).
  • animateTo(đích, spec): chạy tới đích; snapTo(giáTrị): đặt ngay không animation; animateDecay(vậnTốc, decaySpec): trượt chậm dần theo quán tính (dùng với rememberSplineBasedDecay() hoặc exponentialDecay()); stop(): dừng.
  • Đều là hàm suspend: gọi trong LaunchedEffect (chạy theo state) hoặc trong rememberCoroutineScope().launch { } (chạy theo sự kiện như chạm, kéo). Xem Side effects.
  • Gọi animateTo mới khi animation cũ đang chạy sẽ hủy animation cũ và tiếp tục từ vị trí, vận tốc hiện tại — nhờ vậy cử chỉ ngắt ngang vẫn mượt.
  • updateBounds(lowerBound, upperBound) giới hạn phạm vi; animation dừng khi chạm biên.
@Composable
fun HuyHieuThongBao(soThongBao: Int) {
    val tiLe = remember { Animatable(1f) }
    LaunchedEffect(soThongBao) {
        tiLe.snapTo(1.4f)          // phóng to tức thì
        tiLe.animateTo(            // rồi nảy về kích thước gốc
            targetValue = 1f,
            animationSpec = spring(dampingRatio = Spring.DampingRatioHighBouncy)
        )
    }
    Badge(Modifier.graphicsLayer { scaleX = tiLe.value; scaleY = tiLe.value }) {
        Text("$soThongBao")
    }
}

4. Bảng AnimationSpec

SpecĐặc điểmVí dụ
springMô phỏng lò xo, không có thời lượng cố định, giữ vận tốc khi bị ngắt giữa chừng nên mượt nhất cho tương tác. Mặc định của phần lớn API.spring(dampingRatio = Spring.DampingRatioMediumBouncy, stiffness = Spring.StiffnessLow)
tweenChạy đúng N mili giây theo một đường cong tốc độ (easing). Mặc định 300 ms với FastOutSlowInEasing.tween(durationMillis = 500, easing = LinearEasing)
keyframesĐặt giá trị tại từng mốc thời gian, Compose nội suy phần giữa.keyframes { durationMillis = 600; 1.3f at 150; 0.9f at 400 }
repeatableLặp một spec có thời lượng N lần.repeatable(iterations = 3, animation = tween(200), repeatMode = RepeatMode.Reverse)
infiniteRepeatableLặp mãi; dùng với rememberInfiniteTransition hoặc Animatable.infiniteRepeatable(tween(800), RepeatMode.Reverse)
snapNhảy ngay tới giá trị cuối (có thể kèm độ trễ).snap(delayMillis = 100)
  • Độ nảy dampingRatio: Spring.DampingRatioNoBouncy (mặc định, không nảy), DampingRatioLowBouncy, DampingRatioMediumBouncy, DampingRatioHighBouncy (nảy nhiều nhất).
  • Độ cứng stiffness: StiffnessHigh, StiffnessMedium (mặc định), StiffnessMediumLow, StiffnessLow, StiffnessVeryLow — càng thấp, về đích càng chậm.
  • Easing: FastOutSlowInEasing (tự nhiên cho vật di chuyển), LinearOutSlowInEasing (vật đi vào), FastOutLinearInEasing (vật rời đi), LinearEasing (đều, hợp xoay vòng hay đổi độ mờ), hoặc tự định nghĩa bằng CubicBezierEasing(a, b, c, d).

5. Shared element transitions (giới thiệu)

"Phần tử dùng chung" là kỹ thuật cho một phần tử — ảnh sản phẩm, ảnh đại diện — chuyển động liền mạch từ vị trí ở bố cục này sang vị trí ở bố cục kia (ví dụ từ danh sách sang trang chi tiết). Bọc nội dung trong SharedTransitionLayout, chuyển giữa hai bố cục bằng AnimatedContent (hoặc Navigation), rồi đánh dấu hai phần tử tương ứng bằng Modifier.sharedElement với cùng một key. API này có thể yêu cầu @OptIn(ExperimentalSharedTransitionApi::class) tùy phiên bản.

@OptIn(ExperimentalSharedTransitionApi::class)
@Composable
fun AnhDaiDienMoRong() {
    var moRong by remember { mutableStateOf(false) }
    SharedTransitionLayout {
        AnimatedContent(targetState = moRong, label = "anhDaiDien") { lon ->
            Box(
                Modifier
                    .sharedElement(
                        rememberSharedContentState(key = "anh-dai-dien"),
                        animatedVisibilityScope = this@AnimatedContent
                    )
                    .size(if (lon) 240.dp else 64.dp)
                    .background(MaterialTheme.colorScheme.tertiary, RoundedCornerShape(16.dp))
                    .clickable { moRong = !moRong }
            )
        }
    }
}

6. Animation Preview trong Android Studio

Khi một hàm @Preview chứa animation được hỗ trợ (chẳng hạn updateTransition, AnimatedVisibility, AnimatedContent, animate*AsState, rememberInfiniteTransition), khung preview hiện nút mở Animation Preview. Tại đây bạn phát/tạm dừng, kéo thanh thời gian từng khung hình, chọn trạng thái đầu – cuối và xem đường cong của từng giá trị theo label — rất tiện để tinh chỉnh spec mà không cần chạy app.

Ví dụ

Ví dụ 1: Ô chọn gói cước đổi viền, nền và kích thước cùng lúc

Ba giá trị dùng chung một Transition nên luôn khớp nhịp nhau.

@Composable
fun OGoiCuoc(
    tenGoi: String,
    gia: String,
    duocChon: Boolean,
    onChon: () -> Unit,
    modifier: Modifier = Modifier
) {
    val transition = updateTransition(targetState = duocChon, label = "goiCuoc")

    val doDayVien by transition.animateDp(label = "doDayVien") { chon ->
        if (chon) 3.dp else 1.dp
    }
    val mauVien by transition.animateColor(label = "mauVien") { chon ->
        if (chon) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.outlineVariant
    }
    val mauNen by transition.animateColor(
        transitionSpec = { tween(durationMillis = 400) },
        label = "mauNen"
    ) { chon ->
        if (chon) MaterialTheme.colorScheme.primaryContainer else MaterialTheme.colorScheme.surface
    }
    val tiLe by transition.animateFloat(
        transitionSpec = { spring(dampingRatio = Spring.DampingRatioMediumBouncy) },
        label = "tiLe"
    ) { chon ->
        if (chon) 1.05f else 1f
    }

    Surface(
        selected = duocChon,
        onClick = onChon,
        shape = RoundedCornerShape(16.dp),
        color = mauNen,
        border = BorderStroke(doDayVien, mauVien),
        modifier = modifier.graphicsLayer { scaleX = tiLe; scaleY = tiLe }
    ) {
        Column(Modifier.padding(16.dp)) {
            Text(tenGoi, style = MaterialTheme.typography.titleMedium)
            Text(gia, style = MaterialTheme.typography.bodyMedium)
        }
    }
}

Ví dụ 2: Khung chờ tải (skeleton) nhấp nháy

@Composable
fun DongSkeleton(modifier: Modifier = Modifier) {
    val vongLap = rememberInfiniteTransition(label = "skeleton")
    val doMo by vongLap.animateFloat(
        initialValue = 0.3f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(
            animation = tween(durationMillis = 800, easing = LinearEasing),
            repeatMode = RepeatMode.Reverse
        ),
        label = "doMo"
    )
    val mauKhoi = MaterialTheme.colorScheme.onSurface.copy(alpha = 0.12f)
    // Đọc doMo trong graphicsLayer: chỉ vẽ lại, không recompose mỗi khung hình
    val nhapNhay = Modifier.graphicsLayer { alpha = doMo }

    Row(modifier.padding(16.dp), verticalAlignment = Alignment.CenterVertically) {
        Box(nhapNhay.size(48.dp).background(mauKhoi, CircleShape))
        Spacer(Modifier.width(12.dp))
        Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
            Box(nhapNhay.fillMaxWidth(0.7f).height(14.dp).background(mauKhoi, RoundedCornerShape(4.dp)))
            Box(nhapNhay.fillMaxWidth(0.4f).height(14.dp).background(mauKhoi, RoundedCornerShape(4.dp)))
        }
    }
}

@Composable
fun DanhBaDangTai() {

    LaunchedEffect(Unit) {
        delay(2500)   // giả lập tải dữ liệu
        dangTai = false

        }

Ví dụ 3: Thẻ kéo được, thả ra thì bật về chỗ cũ

Cần import androidx.compose.animation.core.VectorConverter và kotlin.math.roundToInt.

@Composable
fun TheKeoBatVe() {
    val viTri = remember { Animatable(Offset.Zero, Offset.VectorConverter) }
    val scope = rememberCoroutineScope()
    val veChoCu: () -> Unit = {
        scope.launch {
            viTri.animateTo(
                targetValue = Offset.Zero,
                animationSpec = spring(
                    dampingRatio = Spring.DampingRatioMediumBouncy,
                    stiffness = Spring.StiffnessLow
                )
            )
        }
    }

    Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
        Card(
            modifier = Modifier
                .offset { IntOffset(viTri.value.x.roundToInt(), viTri.value.y.roundToInt()) }
                .size(width = 220.dp, height = 140.dp)
                .pointerInput(Unit) {
                    detectDragGestures(
                        onDragEnd = veChoCu,
                        onDragCancel = veChoCu,
                        onDrag = { change, luongKeo ->
                            change.consume()
                            // Bám theo ngón tay: đặt giá trị ngay, không animation
                            scope.launch { viTri.snapTo(viTri.value + luongKeo) }
                        }
                    )
                }
        ) {
            Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
                Text("Kéo tôi rồi thả ra")
            }
        }
    }
}

Kết quả: Thẻ đi theo ngón tay theo mọi hướng. Khi buông tay, thẻ lao về giữa màn hình, vượt quá một chút rồi nảy qua lại vài lần trước khi đứng yên. Nếu chạm lại giữa chừng, thẻ dừng ngay dưới ngón tay và tiếp tục kéo được.

Chú ý

  • Luôn remember Animatable. Viết val x = Animatable(0f) trực tiếp trong thân composable sẽ tạo đối tượng mới mỗi lần recompose, animation bị reset liên tục.
  • repeatable/infiniteRepeatable chỉ nhận spec có thời lượng (tween, keyframes, snap), không nhận spring.
  • Đọc giá trị animation càng muộn càng tốt. Đưa vào graphicsLayer { }, offset { } hay drawBehind { } để chỉ vẽ lại thay vì recompose mỗi khung hình (xem Hiệu năng).
  • Chọn đúng key cho LaunchedEffect chứa animateTo: key đổi thì animation cũ bị hủy và chạy lại; dùng Unit nếu chỉ muốn chạy một lần khi xuất hiện.
  • Ưu tiên spring cho thứ người dùng chạm vào: khi bị ngắt giữa chừng, nó giữ vận tốc nên không bị giật như tween.
  • Tôn trọng người dùng nhạy cảm với chuyển động. Android có tùy chọn tắt/giảm animation trong phần cài đặt Hỗ trợ tiếp cận; animation Compose nhìn chung tuân theo hệ số tốc độ animation của hệ thống. Đừng để chức năng phụ thuộc vào việc animation chạy xong, tránh nhấp nháy nhanh hoặc chuyển động lớn kéo dài, và cân nhắc thêm tùy chọn "giảm hiệu ứng" trong app (xem Hỗ trợ tiếp cận).
Mẹo: Đặt label cho mọi updateTransition, rememberInfiniteTransition và từng giá trị con. Khi mở Animation Preview, bạn sẽ thấy ngay tên từng đường cong thay vì những nhãn mặc định khó phân biệt.
