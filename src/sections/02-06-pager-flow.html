Pager và Flow layout

Pager cho phép người dùng vuốt qua từng "trang" nội dung, như màn giới thiệu app hay băng chuyền khuyến mãi. Flow layout (FlowRow, FlowColumn) xếp phần tử thành hàng và tự xuống dòng khi hết chỗ, rất hợp cho danh sách thẻ (tag).

Định nghĩa

HorizontalPager và VerticalPager là các layout cuộn theo từng trang: mỗi lần vuốt, nội dung "bắt dính" (snap) vào đúng một trang thay vì dừng ở vị trí bất kỳ như LazyRow. Bên dưới, Pager cũng là layout lazy nên chỉ dựng những trang đang hiển thị. Nó thay thế cho ViewPager2 + Adapter của hệ View cũ. Trạng thái của Pager (đang ở trang nào, đang cuộn hay không) nằm trong đối tượng PagerState.

FlowRow xếp các phần tử con lần lượt từ trái sang phải; khi hàng hiện tại không còn đủ chỗ, phần tử tiếp theo tự xuống hàng mới, giống chữ trong một đoạn văn. FlowColumn làm điều tương tự theo chiều dọc: hết chiều cao thì sang cột mới. Trước đây bạn phải dùng thư viện ngoài như FlexboxLayout hay ChipGroup để có hành vi này.

Cách dùng

Pager: ba bước cơ bản

  1. Tạo trạng thái: val pagerState = rememberPagerState(pageCount = { pages.size }). Số trang được truyền dưới dạng lambda để Pager tự cập nhật khi danh sách thay đổi.
  2. Gọi HorizontalPager(state = pagerState) { page -> … }. Lambda nhận chỉ số trang và vẽ nội dung trang đó.
  3. Muốn chuyển trang bằng code (nút "Tiếp"), dùng hàm suspend animateScrollToPage bên trong một coroutine từ rememberCoroutineScope().
Thuộc tính / hàm của PagerStateÝ nghĩa
currentPageTrang gần vị trí "bắt dính" nhất. Giá trị đổi ngay khi người dùng kéo quá nửa trang, kể cả khi chưa thả tay.
settledPageTrang mà Pager đã dừng hẳn. Chỉ đổi khi chuyển động cuộn kết thúc.
targetPageTrang mà Pager sẽ dừng lại nếu chuyển động hiện tại kết thúc.
currentPageOffsetFractionTrang hiện tại đang lệch bao nhiêu (từ -0.5 đến 0.5), hữu ích để làm hiệu ứng theo ngón tay.
animateScrollToPage(n)Cuộn có hiệu ứng tới trang n (hàm suspend).
scrollToPage(n)Nhảy ngay tới trang n, không hiệu ứng (hàm suspend).
Tham số của PagerDùng để
contentPaddingThêm lề hai bên; kết hợp với pageSpacing để lộ một phần trang bên cạnh, gợi ý người dùng còn trang để vuốt.
pageSpacingKhoảng cách giữa hai trang.

Lộ trang hai bên cho băng chuyền khuyến mãi:

HorizontalPager(
    state = pagerState,
    contentPadding = PaddingValues(horizontal = 32.dp),
    pageSpacing = 12.dp
) { page ->
    PromoCard(promos[page])
}

FlowRow và FlowColumn

  • horizontalArrangement: cách xếp và khoảng cách giữa các phần tử trong một hàng, ví dụ Arrangement.spacedBy(8.dp).
  • verticalArrangement: khoảng cách giữa các hàng với nhau.
  • maxItemsInEachRow: giới hạn số phần tử mỗi hàng; đủ số này thì xuống hàng dù vẫn còn chỗ. FlowColumn có tham số tương ứng là maxItemsInEachColumn.
  • Bên trong FlowRow vẫn dùng được Modifier.weight(1f) để các phần tử trong cùng hàng chia đều phần rộng còn lại.

Ví dụ

Ví dụ 1: Chỉ báo trang dạng chấm tròn

@Composable
fun PageIndicator(pageCount: Int, currentPage: Int, modifier: Modifier = Modifier) {
    Row(
        modifier = modifier,
        horizontalArrangement = Arrangement.spacedBy(8.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        repeat(pageCount) { index ->
            val selected = index == currentPage
            Box(
                modifier = Modifier
                    .size(if (selected) 10.dp else 8.dp)
                    .clip(CircleShape)
                    .background(
                        if (selected) MaterialTheme.colorScheme.primary
                        else MaterialTheme.colorScheme.outlineVariant
                    )
            )
        }
    }
}

Kết quả: Một hàng chấm tròn nhỏ; chấm ứng với trang hiện tại to hơn và có màu chủ đạo, các chấm còn lại màu xám nhạt.

Ví dụ 2: Màn giới thiệu (onboarding) 3 trang

data class IntroPage(val title: String, val description: String)

private val introPages = listOf(
    IntroPage("Ghi chú thật nhanh", "Lưu lại ý tưởng chỉ với một chạm, kể cả khi không có mạng."),
    IntroPage("Sắp xếp bằng thẻ", "Gắn thẻ cho ghi chú để tìm lại trong vài giây."),
    IntroPage("Đồng bộ mọi nơi", "Ghi chú tự có mặt trên điện thoại và máy tính bảng của bạn.")
)

@Composable
fun OnboardingScreen(onFinish: () -> Unit) {
    val pagerState = rememberPagerState(pageCount = { introPages.size })
    val scope = rememberCoroutineScope()
    val isLastPage = pagerState.currentPage == introPages.lastIndex

    Column(
        modifier = Modifier
            .fillMaxSize()
            .safeDrawingPadding()
            .padding(24.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        HorizontalPager(
            state = pagerState,
            modifier = Modifier.weight(1f)
        ) { page ->
            val item = introPages[page]
            Column(
                modifier = Modifier.fillMaxSize(),
                verticalArrangement = Arrangement.Center,
                horizontalAlignment = Alignment.CenterHorizontally
            ) {
                Text(item.title, style = MaterialTheme.typography.headlineMedium)
                Spacer(Modifier.height(12.dp))
                Text(
                    text = item.description,
                    style = MaterialTheme.typography.bodyLarge,
                    textAlign = TextAlign.Center
                )
            }
        }

        PageIndicator(pageCount = introPages.size, currentPage = pagerState.currentPage)
        Spacer(Modifier.height(24.dp))

        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            TextButton(onClick = onFinish) { Text("Bỏ qua") }
            Button(onClick = {
                if (isLastPage) {
                    onFinish()
                } else {
                    scope.launch { pagerState.animateScrollToPage(pagerState.currentPage + 1) }
                }
            }) {
                Text(if (isLastPage) "Bắt đầu" else "Tiếp")
            }
        }
    }
}

@Preview(showBackground = true)
@Composable
fun OnboardingPreview() {
    MaterialTheme { OnboardingScreen(onFinish = {}) }
}

Kết quả: Màn hình hiển thị trang "Ghi chú thật nhanh", bên dưới là 3 chấm tròn và hai nút "Bỏ qua" / "Tiếp". Vuốt ngang hoặc bấm "Tiếp" để sang trang sau với hiệu ứng trượt; chấm tròn đổi theo. Ở trang cuối, nút đổi thành "Bắt đầu" và gọi onFinish.

Ví dụ 3: Đám mây thẻ với FlowRow và FilterChip

@Composable
fun TagCloud(tags: List<String>, modifier: Modifier = Modifier) {
    var selected by remember { mutableStateOf(setOf<String>()) }

    FlowRow(
        modifier = modifier.padding(16.dp),
        horizontalArrangement = Arrangement.spacedBy(8.dp),
        verticalArrangement = Arrangement.spacedBy(4.dp)
    ) {
        tags.forEach { tag ->
            val isSelected = tag in selected
            FilterChip(
                selected = isSelected,
                onClick = { selected = if (isSelected) selected - tag else selected + tag },
                label = { Text(tag) },
                leadingIcon = if (isSelected) {
                    {
                        Icon(
                            painter = painterResource(R.drawable.ic_check),
                            contentDescription = null,
                            modifier = Modifier.size(FilterChipDefaults.IconSize)
                        )
                    }
                } else {
                    null
                }
            )
        }
    }
}

Kết quả: Các thẻ xếp thành hàng, hết chỗ thì tự xuống dòng. Chạm vào một thẻ sẽ tô màu nó và hiện dấu tích bên trái; chạm lần nữa để bỏ chọn. Có thể chọn nhiều thẻ cùng lúc.

Chú ý

  • animateScrollToPage là hàm suspend: chỉ gọi trong coroutine (từ rememberCoroutineScope trong sự kiện bấm, hoặc trong LaunchedEffect), không gọi trực tiếp trong thân hàm Composable.
  • Muốn làm việc gì đó mỗi khi đổi trang (ghi log, tải dữ liệu), hãy theo dõi settledPage thay vì currentPage, vì currentPage đổi ngay giữa lúc vuốt. Cách theo dõi: LaunchedEffect(pagerState) { snapshotFlow { pagerState.settledPage }.collect { … } } (xem Side effects).
  • rememberPagerState đã tự lưu trang hiện tại qua xoay màn hình, bạn không cần tự lưu thêm.
  • Đặt VerticalPager bên trong vùng cuộn dọc (như LazyColumn) thì phải cho nó một chiều cao cụ thể, nếu không sẽ lỗi đo "chiều cao vô hạn".
  • FlowRow/FlowColumn không phải layout lazy: mọi phần tử đều được dựng cùng lúc. Chỉ dùng cho vài chục phần tử; danh sách dài hãy dùng LazyVerticalGrid.
  • Ở các bản Compose cũ, FlowRow/FlowColumn cần @OptIn(ExperimentalLayoutApi::class). Nếu IDE báo API thử nghiệm với phiên bản bạn đang dùng, thêm annotation này vào hàm.
Mẹo: Đừng tăng beyondViewportPageCount chỉ để "cho mượt". Mỗi trang dựng sẵn đều tốn bộ nhớ và thời gian; Pager vốn đã tự tải trước (prefetch) trang kế tiếp khi bạn bắt đầu vuốt.
