Thanh điều hướng, NavigationRail và Drawer

Đây là các thành phần giúp người dùng chuyển nhanh giữa những khu vực chính của app như Trang chủ, Tìm kiếm, Hồ sơ. Chọn đúng mẫu điều hướng cho từng kích thước màn hình giúp app dễ dùng trên cả điện thoại lẫn tablet.

Định nghĩa

Điều hướng cấp cao (top-level navigation) là việc chuyển qua lại giữa các khu vực chính, ngang hàng nhau của app. Nó khác với kiểu điều hướng "đi sâu", ví dụ bấm vào một sản phẩm để xem chi tiết rồi bấm Back để quay lại. Người dùng luôn mở được một đích cấp cao trực tiếp từ một thanh hoặc menu cố định, dù đang ở màn nào.

Material 3 có sẵn ba nhóm composable cho việc này: NavigationBar (thanh nằm ở đáy màn hình), NavigationRail (cột dọc hẹp ở cạnh trái) và Navigation Drawer (ngăn kéo trượt ra từ cạnh trái: ModalNavigationDrawer, DismissibleNavigationDrawer, PermanentNavigationDrawer). Hồi còn dùng View/XML, bạn phải kết hợp BottomNavigationView, NavigationRailView, DrawerLayout với một file menu XML. Trong Compose, mỗi mục chỉ là một lời gọi hàm nằm trong vòng lặp forEach.

Các composable này chỉ lo phần hiển thị và báo cho bạn biết khi người dùng bấm. Chúng không tự đổi màn hình. Bạn tự viết phần đổi màn hình, thường bằng cách gọi navController.navigate(...) của Navigation Compose (xem Navigation Compose). Ngoài ra còn có NavigationSuiteScaffold, một bộ khung tự chọn thanh dưới, rail hoặc drawer dựa trên kích thước cửa sổ.

2. Khai báo danh sách đích cấp cao

Gom thông tin của mỗi tab (route, nhãn, icon) vào một enum class hoặc data class. Nhờ vậy thanh dưới, rail và drawer có thể dùng chung một danh sách, và khi thêm tab mới bạn chỉ phải sửa ở một chỗ.

@Serializable object HomeRoute
@Serializable object SearchRoute
@Serializable object ProfileRoute

enum class TopLevelDestination(
    val route: Any,
    val label: String,
    @DrawableRes val icon: Int,
) {
    HOME(HomeRoute, "Trang chủ", R.drawable.ic_home),
    SEARCH(SearchRoute, "Tìm kiếm", R.drawable.ic_search),
    PROFILE(ProfileRoute, "Hồ sơ", R.drawable.ic_person),
}

3. Đặt NavigationBar vào Scaffold

Truyền NavigationBar vào tham số bottomBar của Scaffold (xem Scaffold). Bên trong, gọi NavigationBarItem một lần cho mỗi đích. Các tham số chính:

Tham sốÝ nghĩa
selectedMục này có đang được chọn không. Mục đang chọn có một nền hình viên thuốc (indicator) phía sau icon.
onClickLambda chạy khi người dùng bấm, thường là nơi gọi navigate.
iconComposable vẽ icon, ví dụ { Icon(painterResource(...), null) }.
labelNhãn chữ bên dưới icon. Không bắt buộc nhưng nên có.
alwaysShowLabelMặc định là true. Đặt false nếu chỉ muốn mục đang chọn hiện nhãn.
enabled, colorsTắt mục; đổi màu qua NavigationBarItemDefaults.colors(...).

4. Kết nối với Navigation Compose

  • Biết tab nào đang chọn: đọc navController.currentBackStackEntryAsState() để lấy đích hiện tại, rồi kiểm tra destination.hierarchy.any { it.hasRoute(route::class) }. Dùng hierarchy thay vì so sánh trực tiếp vì một tab có thể là cả một graph lồng nhau gồm nhiều màn.
  • Chuyển tab mà vẫn giữ trạng thái: gọi navigate(route) với ba tùy chọn sau. popUpTo(startDestination) { saveState = true } gỡ các màn của tab cũ khỏi back stack nhưng lưu lại trạng thái của chúng. launchSingleTop = true tránh tạo màn trùng khi bấm lại tab đang mở. restoreState = true khôi phục trạng thái đã lưu khi người dùng quay lại tab đó.

5. NavigationRail cho màn rộng

NavigationRail nhận nội dung kiểu ColumnScope, nên bạn dùng được Spacer(Modifier.weight(1f)) để đẩy các mục vào giữa. Tham số header thường chứa một nút FAB. Hãy đặt rail cạnh nội dung bằng một Row.

@Composable
fun AppNavigationRail(
    current: TopLevelDestination,
    onSelect: (TopLevelDestination) -> Unit,
    modifier: Modifier = Modifier
) {
    NavigationRail(
        modifier = modifier,
        header = {
            FloatingActionButton(onClick = { /* tạo mục mới */ }) {
                Icon(painterResource(R.drawable.ic_add), contentDescription = "Tạo mới")
            }
        }
    ) {
        Spacer(Modifier.weight(1f))
        TopLevelDestination.entries.forEach { dest ->
            NavigationRailItem(
                selected = dest == current,
                onClick = { onSelect(dest) },
                icon = { Icon(painterResource(dest.icon), contentDescription = null) },
                label = { Text(dest.label) }
            )
        }
        Spacer(Modifier.weight(1f))
    }
}

6. Navigation Drawer

  • ModalNavigationDrawer(drawerState, drawerContent) { nộiDung }: drawer phủ lên trên nội dung, kèm một lớp nền mờ (scrim) phía sau.
  • Trạng thái đóng/mở nằm trong rememberDrawerState(DrawerValue.Closed). Hàm open() và close() là hàm suspend, vì vậy phải gọi trong coroutine: scope.launch { drawerState.open() }, với scope lấy từ rememberCoroutineScope().
  • Đặt nội dung drawer trong ModalDrawerSheet { … }. Mỗi mục là một NavigationDrawerItem(label, selected, onClick, icon, badge), thêm Modifier.padding(NavigationDrawerItemDefaults.ItemPadding) để có lề chuẩn.
  • DismissibleNavigationDrawer đẩy nội dung sang bên khi mở thay vì phủ lên. PermanentNavigationDrawer (đi kèm PermanentDrawerSheet) thì luôn hiển thị và không đóng được.

icon = {

8. NavigationSuiteScaffold tự thích ứng

Thêm thư viện (BOM quản lý phiên bản), sau đó khai báo các mục qua item(selected, onClick, icon, label). Khung này tự đổi giữa NavigationBar, NavigationRail và drawer theo kích thước cửa sổ. Thường thì cửa sổ hẹp sẽ có thanh dưới, cửa sổ rộng hơn sẽ có rail. Muốn chọn kiểu cố định thì truyền tham số layoutType.

dependencies {
    implementation(platform("androidx.compose:compose-bom:2026.09.00"))
    implementation("androidx.compose.material3:material3-adaptive-navigation-suite")
}

Ví dụ

Ví dụ 1: App cửa hàng 3 tab với Navigation Compose

Dùng lại TopLevelDestination ở mục 2. Ba dòng import dưới đây là các hàm mở rộng, Android Studio đôi khi không tự gợi ý.

import androidx.navigation.NavDestination.Companion.hasRoute
import androidx.navigation.NavDestination.Companion.hierarchy
import androidx.navigation.NavGraph.Companion.findStartDestination

@Composable
fun ShopApp() {
    val navController = rememberNavController()
    val backStackEntry by navController.currentBackStackEntryAsState()
    val currentDestination = backStackEntry?.destination

    Scaffold(
        bottomBar = {
            NavigationBar {
                TopLevelDestination.entries.forEach { dest ->
                    val selected = currentDestination?.hierarchy?.any {
                        it.hasRoute(dest.route::class)
                    } == true

                    NavigationBarItem(
                        selected = selected,
                        onClick = {
                            navController.navigate(dest.route) {
                                popUpTo(navController.graph.findStartDestination().id) {
                                    saveState = true
                                }
                                launchSingleTop = true
                                restoreState = true
                            }
                        },
                        icon = {
                            Icon(painterResource(dest.icon), contentDescription = null)
                        },
                        label = { Text(dest.label) }
                    )
                }
            }
        }
    ) { innerPadding ->
        NavHost(
            navController = navController,
            startDestination = HomeRoute,
            modifier = Modifier.padding(innerPadding)
        ) {
            composable<HomeRoute> { HomeScreen() }
            composable<SearchRoute> { SearchScreen() }
            composable<ProfileRoute> { ProfileScreen() }
        }
    }
}

@Composable
fun HomeScreen() {
    var likes by rememberSaveable { mutableIntStateOf(0) }
    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text("Trang chủ", style = MaterialTheme.typography.headlineSmall)
        Button(onClick = { likes++ }) { Text("Đã thích $likes lần") }
    }
}

@Composable
fun SearchScreen() {
    var query by rememberSaveable { mutableStateOf("") }
    OutlinedTextField(
        value = query,
        onValueChange = { query = it },
        label = { Text("Tìm sản phẩm") },
        modifier = Modifier.fillMaxWidth().padding(16.dp)
    )
}

@Composable
fun ProfileScreen() {
    Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
        Text("Hồ sơ của bạn", style = MaterialTheme.typography.headlineSmall)
    }
}

Kết quả: Đáy màn hình có thanh 3 tab, tab đang mở được đánh dấu bằng nền viên thuốc. Thử gõ "áo khoác" ở tab Tìm kiếm, chuyển sang Trang chủ rồi quay lại: chữ vẫn còn nguyên, vì saveState/restoreState đã giữ trạng thái của tab. Khi đang ở tab Hồ sơ, bấm Back sẽ về Trang chủ trước rồi mới thoát app.

Ví dụ 2: Drawer cho app ghi chú

enum class NoteFolder(val label: String, @DrawableRes val icon: Int) {
    ALL("Tất cả ghi chú", R.drawable.ic_notes),
    WORK("Công việc", R.drawable.ic_work),
    PERSONAL("Cá nhân", R.drawable.ic_person),
    TRASH("Thùng rác", R.drawable.ic_delete),
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun NotesApp() {
    val drawerState = rememberDrawerState(initialValue = DrawerValue.Closed)
    val scope = rememberCoroutineScope()
    var folder by rememberSaveable { mutableStateOf(NoteFolder.ALL) }

    ModalNavigationDrawer(
        drawerState = drawerState,
        drawerContent = {
            ModalDrawerSheet {
                Text(
                    text = "Sổ ghi chú",
                    style = MaterialTheme.typography.titleLarge,
                    modifier = Modifier.padding(horizontal = 28.dp, vertical = 20.dp)
                )
                NoteFolder.entries.forEach { item ->
                    NavigationDrawerItem(
                        label = { Text(item.label) },
                        selected = item == folder,
                        onClick = {
                            folder = item
                            scope.launch { drawerState.close() }
                        },
                        icon = { Icon(painterResource(item.icon), contentDescription = null) },
                        modifier = Modifier.padding(NavigationDrawerItemDefaults.ItemPadding)
                    )
                }
            }
        }
    ) {
        Scaffold(
            topBar = {
                TopAppBar(
                    title = { Text(folder.label) },
                    navigationIcon = {
                        IconButton(onClick = { scope.launch { drawerState.open() } }) {
                            Icon(painterResource(R.drawable.ic_menu), contentDescription = "Mở menu")
                        }
                    }
                )
            }
        ) { innerPadding ->
            Box(
                modifier = Modifier.fillMaxSize().padding(innerPadding),
                contentAlignment = Alignment.Center
            ) {
                Text("Các ghi chú trong mục \"${folder.label}\"")
            }
        }
    }
}

Kết quả: Thanh trên cùng có nút menu ba gạch. Bấm nút đó, hoặc vuốt từ cạnh trái, thì drawer trượt ra phủ lên nội dung, phía sau có lớp nền mờ. Chọn "Công việc" thì drawer tự đóng, tiêu đề đổi thành "Công việc".

Ví dụ 3: Một khung, tự thích ứng mọi màn hình

@Composable
fun AdaptiveShopApp() {
    var current by rememberSaveable { mutableStateOf(TopLevelDestination.HOME) }

    NavigationSuiteScaffold(
        navigationSuiteItems = {
            TopLevelDestination.entries.forEach { dest ->
                item(
                    selected = dest == current,
                    onClick = { current = dest },
                    icon = { Icon(painterResource(dest.icon), contentDescription = null) },
                    label = { Text(dest.label) }
                )
            }
        }
    ) {
        when (current) {
            TopLevelDestination.HOME -> HomeScreen()
            TopLevelDestination.SEARCH -> SearchScreen()
            TopLevelDestination.PROFILE -> ProfileScreen()
        }
    }
}

Kết quả: Khi điện thoại cầm dọc, các tab nằm trên thanh ở đáy màn hình. Xoay ngang hoặc mở trên tablet thì chúng tự chuyển sang rail bên trái, bạn không phải viết thêm dòng nào. Ở app thật, thay khối when bằng NavHost như Ví dụ 1. Xem thêm ở Giao diện thích ứng.

Chú ý

  • Đúng số lượng: NavigationBar chỉ hợp với 3–5 đích. Nếu chỉ có 2 đích, dùng tab (TabRow) sẽ hợp hơn. Từ 6 đích trở lên thì chuyển sang drawer.
  • Chỉ dùng một thanh chung: đặt NavigationBar trong Scaffold bao ngoài NavHost, đừng đặt riêng trong từng màn hình. Nếu muốn ẩn thanh ở màn chi tiết, tính một biến showBottomBar từ đích hiện tại, rồi chỉ vẽ thanh khi biến đó là true.
  • Thiếu tùy chọn navigate: nếu bỏ popUpTo, mỗi lần đổi tab back stack lại dài thêm, và bấm Back sẽ lùi qua từng tab. Nếu bỏ saveState/restoreState, tab sẽ mất vị trí cuộn và chữ đã nhập khi bạn quay lại.
  • Khả năng truy cập: khi mục đã có label, đặt contentDescription = null cho icon để TalkBack không đọc hai lần. Nếu không có nhãn chữ thì bắt buộc phải mô tả icon (xem Accessibility).
  • Insets: NavigationBar đã tự chừa chỗ cho thanh điều hướng hệ thống. Đừng thêm navigationBarsPadding() lần nữa, nhưng nhớ truyền innerPadding của Scaffold cho NavHost (xem Edge-to-edge).
  • Drawer: nếu có nhiều mục, bọc chúng trong Column(Modifier.verticalScroll(rememberScrollState())) bên trong ModalDrawerSheet. Hãy thử bấm Back khi drawer đang mở. Nếu drawer không tự đóng, thêm BackHandler(enabled = drawerState.isOpen) { scope.launch { drawerState.close() } }.
Mẹo: Nhãn tab nên ngắn, lý tưởng là một hai từ. Trong app thật, hãy lưu nhãn bằng @StringRes và đọc qua stringResource(...) để dễ dịch sang ngôn ngữ khác.
