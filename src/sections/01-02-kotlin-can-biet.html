Kotlin cần biết trước khi học Compose

Compose được thiết kế riêng cho Kotlin và tận dụng rất nhiều tính năng của ngôn ngữ này. Nắm chắc khoảng một chục tính năng dưới đây sẽ giúp bạn đọc hiểu code Compose thay vì chỉ chép theo.

Định nghĩa

Khác với hệ thống View (vốn được viết cho Java rồi mới có thêm Kotlin), API của Compose được thiết kế ngay từ đầu cho Kotlin. Cú pháp gọn gàng như Column { Text("Xin chào") } thực chất là sự kết hợp của nhiều tính năng: trailing lambda, tham số mặc định, lambda có receiver…

Bạn không cần thành thạo toàn bộ Kotlin, nhưng nếu chưa quen các khái niệm này, code Compose sẽ trông như "phép thuật". Mục này giải thích từng tính năng kèm một đoạn code mang hơi hướng Compose; cuối mục là bảng tổng hợp để tra nhanh.

Cách dùng

1. Lambda và trailing lambda

Lambda là một khối code được truyền đi như giá trị, viết trong { }. Khi tham số cuối cùng của hàm là lambda, Kotlin cho phép đưa nó ra sau cặp ngoặc tròn (trailing lambda); nếu đó là tham số duy nhất cần truyền, có thể bỏ luôn ngoặc tròn.

// Cách viết đầy đủ
Button(onClick = { println("Đã bấm") }, content = { Text("Gửi") })

// Trailing lambda: tham số content đưa ra ngoài ngoặc
Button(onClick = { println("Đã bấm") }) {
    Text("Gửi")
}

// Chỉ còn lambda: bỏ luôn ngoặc tròn
Column {
    Text("Dòng 1")
    Text("Dòng 2")
}

2. Tham số mặc định và tham số đặt tên

Hàm Kotlin có thể cho tham số giá trị mặc định, và khi gọi có thể ghi rõ tên tham số (named argument), không cần đúng thứ tự. Nhờ vậy Text có hơn chục tham số nhưng bạn chỉ truyền thứ mình cần.

Text("Tiêu đề") // mọi tham số khác dùng giá trị mặc định

Text(
    text = "Mô tả rất dài của sản phẩm…",
    maxLines = 2,
    overflow = TextOverflow.Ellipsis,
    color = Color.Gray
)

3. Hàm mở rộng (extension function)

Extension cho phép "gắn thêm" hàm hoặc thuộc tính vào một kiểu có sẵn mà không cần kế thừa. 16.dp, 18.sp là extension property của Int; Modifier.padding() là extension function của Modifier. Bạn cũng tự viết được:

fun Modifier.outlinedBox(): Modifier =
    this
        .border(1.dp, Color.LightGray, RoundedCornerShape(8.dp))
        .padding(12.dp)

// Dùng: Text("Ghi chú", modifier = Modifier.outlinedBox())

4. Hàm bậc cao (higher-order function)

Là hàm nhận hàm khác làm tham số (hoặc trả về hàm). Mọi sự kiện trong Compose đều là tham số kiểu hàm: onClick: () -> Unit, onCheckedChange: (Boolean) -> Unit. Các hàm xử lý danh sách như filter, map, forEach cũng là hàm bậc cao.

@Composable
fun QuantityStepper(quantity: Int, onQuantityChange: (Int) -> Unit) {
    Row(verticalAlignment = Alignment.CenterVertically) {
        TextButton(onClick = { onQuantityChange(quantity - 1) }) { Text("-") }
        Text("$quantity")
        TextButton(onClick = { onQuantityChange(quantity + 1) }) { Text("+") }
    }
}

5. Lambda có receiver và scope

Kiểu ColumnScope.() -> Unit nghĩa là: bên trong lambda, this là một ColumnScope. Tham số content của Column, Row, Box đều có dạng này, nên bên trong chúng bạn dùng được các modifier chỉ dành riêng cho layout đó, như Modifier.weight() (Row/Column) hay Modifier.align(). Ra ngoài scope thì không gọi được — trình biên dịch sẽ báo lỗi, giúp bạn không dùng sai chỗ.

Row(modifier = Modifier.fillMaxWidth()) {
    // this: RowScope -> có Modifier.weight
    Text("Tên sản phẩm", modifier = Modifier.weight(1f))
    Text("120.000đ")
}

Column(modifier = Modifier.fillMaxWidth()) {
    // this: ColumnScope -> align nhận Alignment.Horizontal
    Text("Căn giữa", modifier = Modifier.align(Alignment.CenterHorizontally))
}

6. Thuộc tính ủy quyền (by)

Từ khóa by giao việc đọc/ghi một biến cho đối tượng khác. Với state, nó giúp bỏ .value. Cần import hai hàm getValue/setValue, nếu thiếu IDE sẽ báo lỗi khó hiểu.

import androidx.compose.runtime.getValue
import androidx.compose.runtime.setValue

val nameState = remember { mutableStateOf("") } // kiểu MutableState<String>
nameState.value = "Lan"

var name by remember { mutableStateOf("") }      // kiểu String
name = "Lan"

7. Kiểu nullable, ?. và ?:

Kiểu có dấu ? (như String?) có thể bằng null. Toán tử ?. chỉ gọi tiếp khi khác null; toán tử Elvis ?: cung cấp giá trị thay thế. Rất hay dùng để hiển thị có điều kiện.

Text(contact.phone ?: "Chưa có số điện thoại")
contact.nickname?.let { Text("Biệt danh: $it") } // chỉ hiện khi có

8. Data class

data class tự sinh equals, hashCode, toString và copy. Compose so sánh tham số bằng equals để quyết định có cần vẽ lại hay không, nên data class với các thuộc tính val là lựa chọn tự nhiên cho dữ liệu giao diện. Muốn "sửa" thì tạo bản sao mới bằng copy.

data class Note(val id: Long, val title: String, val pinned: Boolean = false)

val pinnedNote = note.copy(pinned = true)

9. Sealed interface

sealed interface giới hạn tập con được phép, nên when có thể kiểm tra đủ mọi trường hợp mà không cần else. Đây là cách phổ biến để mô tả trạng thái màn hình: đang tải, thành công, lỗi (xem ví dụ 2 bên dưới).

10. object và companion object

object tạo ra một đối tượng duy nhất (singleton), tiện để gom hằng số. companion object là object gắn với một lớp. Thực tế, khi bạn viết Modifier trơn, đó là companion object của interface Modifier; Color.Red, Alignment.Center cũng là thành viên companion.

object Spacing {
    val Small = 8.dp
    val Medium = 16.dp
}

// Dùng: Modifier.padding(Spacing.Medium)

11. Scope function: let, apply

let chạy một khối với giá trị làm tham số it, thường đi cùng ?.. apply cấu hình một đối tượng rồi trả về chính nó, hay gặp khi nhúng View cũ vào Compose (xem Tương thích View).

selectedNote?.let { note -> NoteDetail(note) }

AndroidView(factory = { context ->
    TextView(context).apply {
        text = "View cũ bên trong Compose"
        textSize = 18f
    }
})

12. Coroutine cơ bản: suspend, launch

Coroutine là cách viết code bất đồng bộ (chờ mạng, chờ animation) trông như code tuần tự. Hàm suspend có thể "tạm dừng" mà không chặn luồng giao diện, và chỉ được gọi từ coroutine. Trong Compose, bạn khởi chạy coroutine bằng LaunchedEffect (khi composable xuất hiện) hoặc rememberCoroutineScope().launch (khi người dùng thao tác) — chi tiết ở Side effects.

val scope = rememberCoroutineScope()
Button(onClick = {
    scope.launch { listState.animateScrollToItem(0) } // hàm suspend
}) {
    Text("Lên đầu danh sách")
}

Ví dụ

Ví dụ 1: Dòng ghi chú kết hợp nhiều tính năng

Data class, nullable, extension, scope, hàm bậc cao, trailing lambda

data class Note(
    val id: Long,
    val title: String,
    val tag: String? = null,
    val done: Boolean = false
)

fun Modifier.noteCard(): Modifier =
    this
        .fillMaxWidth()
        .border(1.dp, Color.LightGray, RoundedCornerShape(12.dp))
        .padding(12.dp)

@Composable
fun NoteRow(
    note: Note,
    onToggleDone: (Note) -> Unit,
    modifier: Modifier = Modifier
) {
    Row(
        modifier = modifier.noteCard(),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Column(modifier = Modifier.weight(1f)) {
            Text(text = note.title, style = MaterialTheme.typography.titleMedium)
            note.tag?.let { Text(text = "#$it", color = Color.Gray) }
        }
        Checkbox(
            checked = note.done,
            onCheckedChange = { onToggleDone(note) }
        )
    }
}

@Preview(showBackground = true)
@Composable
private fun NoteRowPreview() {
    var note by remember { mutableStateOf(Note(id = 1, title = "Mua sữa", tag = "việc nhà")) }
    NoteRow(
        note = note,
        onToggleDone = { note = it.copy(done = !it.done) },
        modifier = Modifier.padding(8.dp)
    )
}

Kết quả: Một khung viền bo góc chứa tiêu đề "Mua sữa", bên dưới là "#việc nhà" màu xám, bên phải là ô checkbox. Bấm checkbox thì ô được đánh dấu/bỏ đánh dấu (ở chế độ Interactive của preview hoặc khi chạy app).

Ví dụ 2: Sealed interface và coroutine

sealed interface WeatherUiState {
    data object Loading : WeatherUiState
    data class Success(val city: String, val temperature: Int) : WeatherUiState
    data class Error(val message: String) : WeatherUiState
}

suspend fun loadWeather(city: String): WeatherUiState {
    delay(1_000) // giả lập gọi mạng mất 1 giây
    return if (city.isBlank()) {
        WeatherUiState.Error("Chưa chọn thành phố")
    } else {
        WeatherUiState.Success(city = city, temperature = 31)
    }
}

@Composable
fun WeatherScreen(city: String, modifier: Modifier = Modifier) {
    var state by remember { mutableStateOf<WeatherUiState>(WeatherUiState.Loading) }

    LaunchedEffect(city) {
        state = WeatherUiState.Loading
        state = loadWeather(city)
    }

    Box(modifier = modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
        when (val current = state) {
            WeatherUiState.Loading -> CircularProgressIndicator()
            is WeatherUiState.Success -> Text(
                text = "${current.city}: ${current.temperature}°C",
                style = MaterialTheme.typography.headlineMedium
            )
            is WeatherUiState.Error -> Text("Lỗi: ${current.message}")
        }
    }
}

Kết quả: Gọi WeatherScreen(city = "Đà Nẵng"): vòng tròn tải quay khoảng 1 giây, sau đó hiện chữ lớn "Đà Nẵng: 31°C" ở giữa màn hình. Nếu truyền chuỗi rỗng, màn hình hiện "Lỗi: Chưa chọn thành phố".

Chú ý

  • Quên import androidx.compose.runtime.getValue / setValue là lỗi rất phổ biến khi dùng by. Android Studio thường gợi ý import khi bạn nhấn Alt+Enter.
  • Biến khai báo bằng by không được Kotlin smart cast. Vì vậy ví dụ 2 dùng when (val current = state) để có một biến cục bộ ép kiểu được.
  • Ưu tiên val và kiểu bất biến (List thay vì MutableList) cho dữ liệu truyền vào composable. Sửa trực tiếp phần tử trong danh sách mutable sẽ không làm giao diện cập nhật.
  • Thứ tự trailing lambda quan trọng: chỉ tham số cuối cùng mới đưa ra ngoài ngoặc được. Vì thế các composable luôn đặt content ở cuối danh sách tham số.
  • Đừng gọi hàm suspend trực tiếp trong thân composable hay trong onClick; cần một coroutine scope (LaunchedEffect hoặc rememberCoroutineScope).
Mẹo: Trong Android Studio, nhấn Ctrl (Cmd trên macOS) và bấm vào tên một composable như Column để xem chữ ký hàm. Đọc chữ ký là cách nhanh nhất để biết lambda có receiver nào và tham số nào có giá trị mặc định.
