Dialog, Bottom sheet và Menu

Dialog, bottom sheet và menu là các lớp giao diện tạm thời hiện đè lên màn hình: hỏi xác nhận, đưa ra danh sách hành động hoặc vài tùy chọn nhanh. Trong Compose, chúng được bật/tắt hoàn toàn bằng state chứ không bằng lệnh show().

Định nghĩa

Dialog (hộp thoại) là cửa sổ nhỏ hiện giữa màn hình, chặn tương tác phía sau cho đến khi người dùng quyết định — ví dụ "Xóa ghi chú này?". Bottom sheet là tấm bảng trượt lên từ cạnh dưới, chứa nội dung hoặc hành động phụ như danh sách cách chia sẻ. Menu là danh sách tùy chọn ngắn bật ra ngay cạnh phần tử được bấm, điển hình là menu ba chấm.

Ở hệ View, bạn gọi AlertDialog.Builder(...).show() hay PopupMenu.show() — kiểu ra lệnh (imperative). Compose làm theo kiểu khai báo (declarative): dialog tồn tại khi nó nằm trong composition. Bạn giữ một biến Boolean; khi biến là true, đoạn code vẽ dialog chạy và dialog xuất hiện; khi về false, dialog biến mất. Nhờ vậy trạng thái "đang mở" là dữ liệu bình thường, có thể lưu, khôi phục và kiểm thử như mọi state khác (xem State và remember).

Cách dùng

1. Mẫu chung: điều khiển bằng state

var show by remember { mutableStateOf(false) }

Button(onClick = { show = true }) { Text("Mở") }

if (show) {
    AlertDialog(
        onDismissRequest = { show = false }, // bấm ra ngoài hoặc nút Back
        confirmButton = { TextButton(onClick = { show = false }) { Text("OK") } },
        text = { Text("Xin chào!") }
    )
}

2. AlertDialog

3. Dialog tùy biến với DialogProperties

Khi cần bố cục riêng (biểu mẫu đổi tên, ảnh lớn…), dùng Dialog từ androidx.compose.ui.window. Dialog chỉ cung cấp "cửa sổ" — nó không có nền, góc bo hay padding — nên bạn phải tự bọc nội dung trong Card hoặc Surface. DialogProperties điều chỉnh hành vi:

Dialog(
    onDismissRequest = { showRename = false },
    properties = DialogProperties(
        dismissOnBackPress = true,       // Back đóng dialog
        dismissOnClickOutside = false,   // bấm ra ngoài KHÔNG đóng (tránh mất dữ liệu đang gõ)
        usePlatformDefaultWidth = false  // tự quyết định chiều rộng
    )
) {
    Card(Modifier.fillMaxWidth().padding(24.dp)) {
        // TextField, nút Lưu/Hủy...
    }
}

4. ModalBottomSheet

ModalBottomSheet và rememberModalBottomSheetState cần @OptIn(ExperimentalMaterial3Api::class) — chú thích này xác nhận bạn chấp nhận dùng API mà Material 3 còn đánh dấu là có thể thay đổi. Các điểm chính:

  • rememberModalBottomSheetState(skipPartiallyExpanded = true): mở thẳng lên hết chiều cao nội dung. Để false (mặc định) thì với nội dung dài, sheet dừng ở khoảng nửa màn hình trước, người dùng kéo lên để xem tiếp.
  • Vuốt xuống, bấm vùng tối phía trên hoặc nhấn Back sẽ gọi onDismissRequest sau khi sheet đã trượt xuống xong.
  • Khi tự đóng bằng code (ví dụ sau khi chọn một mục), hãy chạy animation trước rồi mới bỏ sheet khỏi composition:
scope.launch { sheetState.hide() }.invokeOnCompletion {
    if (!sheetState.isVisible) showSheet = false
}

hide() là hàm suspend chạy animation trượt xuống, nên cần scope = rememberCoroutineScope(). invokeOnCompletion chạy khi animation kết thúc; nếu bạn đặt showSheet = false ngay lập tức, sheet sẽ biến mất "cụt" không có hiệu ứng.

5. DropdownMenu

DropdownMenu tự canh vị trí theo phần tử cha của nó, vì vậy hãy đặt nó cùng nút mở trong một Box. Mỗi mục là DropdownMenuItem(text, onClick, leadingIcon, trailingIcon, enabled). Có thể chèn HorizontalDivider() giữa các nhóm mục.

6. ExposedDropdownMenuBox

Dùng trong biểu mẫu khi muốn một ô nhập có mũi tên, bấm vào thì xổ danh sách để chọn (giống Spinner cũ). Cũng cần @OptIn(ExperimentalMaterial3Api::class).

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun SortPicker() {
    val options = listOf("Mới nhất", "Cũ nhất", "Tên A–Z")
    var expanded by remember { mutableStateOf(false) }
    var selected by remember { mutableStateOf(options[0]) }

    ExposedDropdownMenuBox(expanded = expanded, onExpandedChange = { expanded = it }) {
        OutlinedTextField(
            value = selected,
            onValueChange = {},
            readOnly = true,
            label = { Text("Sắp xếp theo") },
            trailingIcon = { ExposedDropdownMenuDefaults.TrailingIcon(expanded = expanded) },
            modifier = Modifier.menuAnchor(MenuAnchorType.PrimaryNotEditable)
        )
        ExposedDropdownMenu(expanded = expanded, onDismissRequest = { expanded = false }) {
            options.forEach { option ->
                DropdownMenuItem(
                    text = { Text(option) },
                    onClick = { selected = option; expanded = false }
                )
            }
        }
    }
}
Lưu ý: Modifier.menuAnchor(...) là bắt buộc để menu biết neo vào ô nhập nào. Tham số kiểu neo của nó đã đổi qua vài phiên bản Material 3; nếu Android Studio báo tên đang dùng đã lỗi thời, hãy làm theo gợi ý thay thế mà IDE đề xuất.

7. Chọn component nào?

Tình huốngNên dùng
Xác nhận hành động nguy hiểm, không hoàn tác được (xóa, đăng xuất)AlertDialog
Biểu mẫu nhỏ hoặc bố cục riêng (đổi tên, đánh giá sao)Dialog + Card
Nhiều hành động có icon, hoặc nội dung phụ dài (chia sẻ, bộ lọc nâng cao)ModalBottomSheet

Ví dụ

Ví dụ 1: Xác nhận xóa ghi chú

@Composable
fun NoteRow(title: String, onDelete: () -> Unit) {
    var showConfirm by remember { mutableStateOf(false) }

    ListItem(
        headlineContent = { Text(title) },
        trailingContent = {
            IconButton(onClick = { showConfirm = true }) {
                Icon(painterResource(R.drawable.ic_delete), contentDescription = "Xóa ghi chú")
            }
        }
    )

    if (showConfirm) {
        AlertDialog(
            onDismissRequest = { showConfirm = false },
            icon = { Icon(painterResource(R.drawable.ic_delete), contentDescription = null) },
            title = { Text("Xóa ghi chú?") },
            text = { Text("Ghi chú \"$title\" sẽ bị xóa vĩnh viễn và không thể khôi phục.") },
            confirmButton = {
                TextButton(onClick = {
                    showConfirm = false
                    onDelete()
                }) { Text("Xóa") }
            },
            dismissButton = {
                TextButton(onClick = { showConfirm = false }) { Text("Hủy") }
            }
        )
    }
}

Kết quả: Bấm icon thùng rác, một hộp thoại hiện giữa màn hình với icon, tiêu đề "Xóa ghi chú?", đoạn giải thích và hai nút "Hủy" / "Xóa". Bấm ra ngoài, nhấn Back hoặc "Hủy" đều đóng hộp thoại mà không xóa.

Ví dụ 2: Bottom sheet chọn cách chia sẻ

data class ShareTarget(val label: String, val iconRes: Int)

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun ShareNoteButton(onShare: (ShareTarget) -> Unit) {
    var showSheet by remember { mutableStateOf(false) }
    val sheetState = rememberModalBottomSheetState(skipPartiallyExpanded = true)
    val scope = rememberCoroutineScope()
    val targets = listOf(
        ShareTarget("Sao chép liên kết", R.drawable.ic_link),
        ShareTarget("Gửi qua email", R.drawable.ic_mail),
        ShareTarget("Gửi qua tin nhắn", R.drawable.ic_sms),
        ShareTarget("Xuất file PDF", R.drawable.ic_picture_as_pdf)
    )

    Button(onClick = { showSheet = true }) { Text("Chia sẻ") }

    if (showSheet) {
        ModalBottomSheet(
            onDismissRequest = { showSheet = false },
            sheetState = sheetState
        ) {
            Text(
                "Chia sẻ ghi chú",
                style = MaterialTheme.typography.titleMedium,
                modifier = Modifier.padding(horizontal = 24.dp, vertical = 8.dp)
            )
            targets.forEach { target ->
                ListItem(
                    headlineContent = { Text(target.label) },
                    leadingContent = { Icon(painterResource(target.iconRes), contentDescription = null) },
                    colors = ListItemDefaults.colors(containerColor = Color.Transparent),
                    modifier = Modifier.clickable {
                        onShare(target)
                        scope.launch { sheetState.hide() }.invokeOnCompletion {
                            if (!sheetState.isVisible) showSheet = false
                        }
                    }
                )
            }
            Spacer(Modifier.height(16.dp))
        }
    }
}

Kết quả: Bấm "Chia sẻ", màn hình phía sau tối lại và một tấm bảng bo góc trượt lên từ dưới, có thanh kéo nhỏ ở đầu, tiêu đề và bốn hàng có icon. Chọn một hàng thì tấm bảng trượt xuống mượt mà rồi biến mất.

Ví dụ 3: Menu ba chấm cho ghi chú

@Composable
fun NoteOptionsMenu(
    isPinned: Boolean,
    onEdit: () -> Unit,
    onTogglePin: () -> Unit,
    onDelete: () -> Unit
) {
    var expanded by remember { mutableStateOf(false) }

    Box {
        IconButton(onClick = { expanded = true }) {
            Icon(painterResource(R.drawable.ic_more_vert), contentDescription = "Tùy chọn khác")
        }
        DropdownMenu(expanded = expanded, onDismissRequest = { expanded = false }) {
            DropdownMenuItem(
                text = { Text("Sửa") },
                leadingIcon = { Icon(painterResource(R.drawable.ic_edit), contentDescription = null) },
                onClick = { expanded = false; onEdit() }
            )
            DropdownMenuItem(
                text = { Text(if (isPinned) "Bỏ ghim" else "Ghim lên đầu") },
                leadingIcon = { Icon(painterResource(R.drawable.ic_push_pin), contentDescription = null) },
                onClick = { expanded = false; onTogglePin() }
            )
            HorizontalDivider()
            DropdownMenuItem(
                text = { Text("Xóa", color = MaterialTheme.colorScheme.error) },
                leadingIcon = {
                    Icon(
                        painterResource(R.drawable.ic_delete),
                        contentDescription = null,
                        tint = MaterialTheme.colorScheme.error
                    )
                },
                onClick = { expanded = false; onDelete() }
            )
        }
    }
}

Kết quả: Bấm icon ba chấm, một menu nhỏ bật ra ngay cạnh nút với ba mục "Sửa", "Ghim lên đầu" và (sau đường kẻ) "Xóa" màu đỏ. Chọn một mục hoặc bấm ra ngoài thì menu đóng. Bạn có thể nối mục "Xóa" với hộp thoại ở Ví dụ 1.

Chú ý

  • Luôn đặt state về false trong onDismissRequest. Nếu để trống, người dùng bấm ra ngoài hay nhấn Back sẽ không đóng được dialog/sheet/menu — trông như app bị treo.
  • State tạo bằng remember mất khi xoay màn hình, nên dialog đang mở sẽ tự đóng. Nếu cần giữ, dùng rememberSaveable hoặc lưu trong ViewModel — xem Lưu trạng thái.
  • Dialog tùy biến không có nền: quên bọc Card/Surface thì chữ sẽ nằm trơ trên lớp nền tối. Nội dung dài trong dialog nên có verticalScroll.
  • Đóng ModalBottomSheet bằng code: gọi sheetState.hide() rồi mới đặt cờ về false trong invokeOnCompletion, để có animation trượt xuống.
  • DropdownMenu hiện sai chỗ (thường ở góc màn hình)? Kiểm tra xem nó có nằm chung Box với nút mở không.
  • Nút xác nhận nên là động từ cụ thể ("Xóa", "Đăng xuất") thay vì "OK"; đừng dùng dialog cho thông tin không cần quyết định — Snackbar nhẹ nhàng hơn.
  • Dialog phức tạp (có màn hình riêng, cần mở từ deep link) có thể khai báo thành một đích (destination) dạng dialog trong Navigation — xem Navigation.
