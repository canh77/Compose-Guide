Button và Floating Action Button

Nút bấm là cách chính để người dùng ra lệnh cho app: thanh toán, lưu, xóa, thêm mới. Material 3 có nhiều loại nút với mức "nổi bật" khác nhau, giúp người dùng nhận ra ngay đâu là hành động quan trọng nhất.

Định nghĩa

Trong Compose, nút là một composable nhận hàm onClick và một slot nội dung (slot là tham số kiểu hàm composable, cho phép bạn đặt bất kỳ giao diện nào vào bên trong: chữ, icon, hoặc cả hai). Nhờ vậy không còn cảnh Button, ImageButton, MaterialButton với hàng loạt thuộc tính XML như hệ View cũ: chỉ cần chọn đúng loại nút rồi tự sắp xếp nội dung.

Material 3 chia nút theo mức nhấn mạnh (emphasis). Một màn hình thường chỉ có một hành động chính, dùng nút nổi bật nhất; các hành động phụ dùng nút nhẹ hơn. Ngoài ra còn có IconButton (nút chỉ có icon) và FAB (Floating Action Button – nút tròn/bo góc nổi phía trên nội dung, dành cho hành động quan trọng nhất của cả màn hình như "Soạn thư", "Thêm ghi chú").

Cách dùng

Chọn loại nút theo mức nhấn mạnh

Tham số quan trọng

  • onClick: hàm chạy khi bấm (bắt buộc).
  • enabled: false thì nút mờ đi và không bấm được.
  • colors: đổi màu bằng ButtonDefaults.buttonColors(containerColor = …, contentColor = …). Mỗi loại nút có hàm tương ứng, ví dụ ButtonDefaults.outlinedButtonColors(…), ButtonDefaults.textButtonColors(…).
  • contentPadding: khoảng đệm bên trong nút. Khi có icon nên dùng ButtonDefaults.ButtonWithIconContentPadding.
  • shape, border, elevation: hình dạng, viền, độ nổi khi cần tùy biến.
  • Nội dung (lambda cuối): nằm trong một Row, nên đặt Icon và Text cạnh nhau là được. Dùng ButtonDefaults.IconSize cho cỡ icon và ButtonDefaults.IconSpacing cho khoảng cách icon–chữ để đúng chuẩn Material.
Button(
    onClick = { /* xóa ghi chú */ },
    colors = ButtonDefaults.buttonColors(
        containerColor = MaterialTheme.colorScheme.error,
        contentColor = MaterialTheme.colorScheme.onError
    ),
    contentPadding = ButtonDefaults.ButtonWithIconContentPadding
) {
    // ic_delete: icon Material Symbols tải về res/drawable (tên giả định)
    Icon(
        painter = painterResource(R.drawable.ic_delete),
        contentDescription = null,
        modifier = Modifier.size(ButtonDefaults.IconSize)
    )
    Spacer(Modifier.size(ButtonDefaults.IconSpacing))
    Text("Xóa ghi chú")
}

Nút chỉ có icon

  • IconButton: icon không nền, dùng trên thanh công cụ, trong ô nhập (nút xóa, nút hiện mật khẩu).
  • FilledIconButton, FilledTonalIconButton, OutlinedIconButton: có nền/viền, nổi bật hơn.
  • IconToggleButton(checked, onCheckedChange): nút bật/tắt như "Yêu thích", "Ghim". Bạn tự đổi icon theo checked.

Với IconButton, contentDescription của icon bắt buộc phải có nội dung vì đó là mô tả duy nhất cho trình đọc màn hình.

Floating Action Button

ComposableĐặc điểm

FAB thường được đặt qua tham số floatingActionButton của Scaffold để tự nằm đúng góc dưới, không bị Snackbar che.

Segmented button: chọn một trong vài lựa chọn

Khi cần chọn nhanh giữa 2–5 lựa chọn (ví dụ đơn vị nhiệt độ, chế độ xem), dùng SingleChoiceSegmentedButtonRow chứa các SegmentedButton. Hàm SegmentedButtonDefaults.itemShape(index, count) tự bo góc đúng cho nút đầu, giữa và cuối.

@Composable
fun TemperatureUnitPicker() {
    val options = listOf("°C", "°F")
    var selectedIndex by remember { mutableIntStateOf(0) }

    SingleChoiceSegmentedButtonRow {
        options.forEachIndexed { index, label ->
            SegmentedButton(
                selected = index == selectedIndex,
                onClick = { selectedIndex = index },
                shape = SegmentedButtonDefaults.itemShape(index = index, count = options.size)
            ) {
                Text(label)
            }
        }
    }
}
Lưu ý: Nếu trình biên dịch báo đây là API thử nghiệm (thường gặp ở bản Material 3 cũ), thêm @OptIn(ExperimentalMaterial3Api::class) lên hàm.

Ví dụ

Ví dụ 1: Thứ bậc nút trên màn hình xác nhận đơn hàng

@Composable
fun OrderConfirmActions(
    onConfirm: () -> Unit,
    onEdit: () -> Unit,
    onCancel: () -> Unit,
    modifier: Modifier = Modifier
) {
    Column(
        modifier = modifier
            .fillMaxWidth()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        Button(onClick = onConfirm, modifier = Modifier.fillMaxWidth()) {
            Text("Xác nhận đặt hàng")
        }
        OutlinedButton(onClick = onEdit, modifier = Modifier.fillMaxWidth()) {
            Text("Sửa địa chỉ giao hàng")
        }
        TextButton(onClick = onCancel, modifier = Modifier.align(Alignment.CenterHorizontally)) {
            Text("Hủy đơn")
        }
    }
}

@Preview(showBackground = true)
@Composable
fun OrderConfirmActionsPreview() {
    MaterialTheme { OrderConfirmActions(onConfirm = {}, onEdit = {}, onCancel = {}) }
}

Kết quả: Ba nút xếp dọc: nút "Xác nhận đặt hàng" nền màu chủ đạo, rộng hết màn hình; nút "Sửa địa chỉ giao hàng" chỉ có viền; dưới cùng là chữ "Hủy đơn" không nền, căn giữa. Người dùng nhìn là biết nên bấm nút nào trước.

Ví dụ 2: Thanh hành động giỏ hàng

@Composable
fun CartActionBar(
    totalPrice: String,
    itemCount: Int,
    isSaved: Boolean,
    onSavedChange: (Boolean) -> Unit,
    onCheckout: () -> Unit,
    modifier: Modifier = Modifier
) {
    Surface(tonalElevation = 3.dp, modifier = modifier.fillMaxWidth()) {
        Row(
            modifier = Modifier.padding(horizontal = 12.dp, vertical = 8.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            IconToggleButton(checked = isSaved, onCheckedChange = onSavedChange) {
                // ic_bookmark / ic_bookmark_filled: icon Material Symbols (tên giả định)
                Icon(
                    painter = painterResource(
                        if (isSaved) R.drawable.ic_bookmark_filled else R.drawable.ic_bookmark
                    ),
                    contentDescription = if (isSaved) "Bỏ lưu giỏ hàng" else "Lưu giỏ hàng"
                )
            }
            Column(modifier = Modifier.weight(1f)) {
                Text("Tổng cộng", style = MaterialTheme.typography.labelMedium)
                Text(
                    text = totalPrice,
                    style = MaterialTheme.typography.titleMedium,
                    color = MaterialTheme.colorScheme.primary
                )
            }
            Button(
                onClick = onCheckout,
                enabled = itemCount > 0,
                contentPadding = ButtonDefaults.ButtonWithIconContentPadding
            ) {
                Icon(
                    painter = painterResource(R.drawable.ic_shopping_bag),
                    contentDescription = null,
                    modifier = Modifier.size(ButtonDefaults.IconSize)
                )
                Spacer(Modifier.size(ButtonDefaults.IconSpacing))
                Text("Thanh toán ($itemCount)")
            }
        }
    }
}

fun CartActionBarPreview() {

        CartActionBar(
            totalPrice = "1.250.000 đ",

Kết quả: Một thanh ngang nền hơi đậm hơn nền màn hình: bên trái là icon dấu trang (bấm vào thì đổi sang dạng tô kín), ở giữa là "Tổng cộng 1.250.000 đ", bên phải là nút "Thanh toán (3)" có icon túi mua sắm. Khi giỏ trống (itemCount = 0), nút thanh toán bị mờ và không bấm được.

Ví dụ 3: FAB mở rộng tự thu gọn khi cuộn danh sách

Ý tưởng: khi danh sách đang ở đầu thì FAB hiện cả chữ "Ghi chú mới"; khi người dùng cuộn xuống, FAB thu lại chỉ còn icon để đỡ che nội dung. Trạng thái cuộn lấy từ LazyListState (xem Lazy list).

@Composable
fun NotesScreen(notes: List<String>, onAddNote: () -> Unit) {
    val listState = rememberLazyListState()
    // derivedStateOf: chỉ báo thay đổi khi kết quả true/false đổi,
    // không phải mỗi pixel cuộn
    val fabExpanded by remember {
        derivedStateOf { listState.firstVisibleItemIndex == 0 }
    }

    Scaffold(
        floatingActionButton = {
            ExtendedFloatingActionButton(
                onClick = onAddNote,
                expanded = fabExpanded,
                icon = {
                    Icon(
                        painter = painterResource(R.drawable.ic_add),
                        // Khi thu gọn không còn chữ, nên icon phải tự mô tả
                        contentDescription = if (fabExpanded) null else "Ghi chú mới"
                    )
                },
                text = { Text("Ghi chú mới") }
            )
        }
    ) { innerPadding ->
        LazyColumn(
            state = listState,
            contentPadding = innerPadding,
            modifier = Modifier.fillMaxSize()
        ) {
            items(notes) { note ->
                Text(
                    text = note,
                    style = MaterialTheme.typography.bodyLarge,
                    modifier = Modifier
                        .fillMaxWidth()
                        .padding(horizontal = 16.dp, vertical = 14.dp)
                )
            }
        }
    }
}

@Preview
@Composable
fun NotesScreenPreview() {
    MaterialTheme {
        NotesScreen(notes = List(40) { "Ghi chú số ${it + 1}" }, onAddNote = {})
    }
}

Kết quả: Góc dưới phải có FAB dạng viên thuốc với icon "+" và chữ "Ghi chú mới". Cuộn danh sách xuống, FAB co lại thành nút vuông bo góc chỉ có dấu "+" (có hiệu ứng chuyển động). Cuộn ngược lên đầu, chữ hiện trở lại.

Chú ý

  • Vùng chạm tối thiểu 48dp. Các nút Material 3 tự đảm bảo vùng chạm 48×48dp kể cả khi phần nhìn thấy nhỏ hơn (ví dụ Button chỉ cao 40dp). Nếu bạn tự làm nút bằng Modifier.clickable, hãy thêm Modifier.minimumInteractiveComponentSize() hoặc đặt kích thước đủ lớn.
  • Chống bấm hai lần. Người dùng hay bấm liên tục vào "Thanh toán" khi mạng chậm. Cách đơn giản nhất: có biến isSubmitting trong state và đặt enabled = !isSubmitting. Nếu không có trạng thái để dựa vào, có thể chặn theo thời gian: 
    var lastClickTime by remember { mutableLongStateOf(0L) }
Button(onClick = {
    val now = SystemClock.elapsedRealtime()
    if (now - lastClickTime > 800) {
        lastClickTime = now
        onCheckout()
    }
}) { Text("Thanh toán") }
  • Mỗi màn hình chỉ nên có một FAB và một nút Button chính. Quá nhiều nút nổi bật khiến người dùng không biết bấm gì.
  • Icon nằm cạnh chữ trong nút thì đặt contentDescription = null (chữ đã mô tả rồi); icon đứng một mình trong IconButton/FAB thì phải có mô tả (xem Accessibility).
  • Đọc thẳng listState.firstVisibleItemIndex trong thân hàm composable sẽ làm màn hình vẽ lại liên tục khi cuộn; bọc trong derivedStateOf như ví dụ 3 (xem Hiệu năng).
  • Hạn chế tự đặt màu cứng cho nút; dùng màu từ MaterialTheme.colorScheme để nút tự đổi đúng ở chế độ tối và với Dynamic Color.
