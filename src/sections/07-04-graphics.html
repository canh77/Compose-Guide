Canvas và đồ họa

Khi component có sẵn không vẽ được thứ bạn muốn — vòng tiến độ riêng, biểu đồ, nền trang trí — bạn có thể tự vẽ từng hình, từng nét. Phần này giới thiệu Canvas, các lệnh vẽ, modifier vẽ, Brush, Shape và graphicsLayer.

Định nghĩa

Mọi thứ Compose hiển thị cuối cùng đều được vẽ lên một "tấm vải" (canvas). Canvas(modifier) { … } là composable cho bạn tự tay vẽ lên tấm vải đó. Bên trong khối lệnh, bạn ở trong DrawScope — phạm vi vẽ cung cấp kích thước vùng vẽ (size), điểm giữa (center) và hàng loạt hàm drawXxx. Trong hệ View, việc này tương đương tạo một lớp con của View, ghi đè onDraw(Canvas) và tự quản lý các đối tượng Paint; Compose gọn hơn nhiều: không cần lớp mới, màu và kiểu nét truyền thẳng vào từng lệnh.

Hệ tọa độ tính bằng pixel (không phải dp), gốc (0, 0) ở góc trên trái, trục x hướng sang phải, trục y hướng xuống dưới. Ngoài Canvas, bạn cũng có thể vẽ thêm lên bất kỳ composable nào bằng modifier vẽ (drawBehind, drawWithContent, drawWithCache), cắt theo hình dạng bằng Shape và biến đổi cả phần tử bằng graphicsLayer.

Cách dùng

Canvas và DrawScope

  • Canvas không có kích thước nội tại: luôn đặt kích thước qua modifier (size, fillMaxWidth().height(…)…), nếu không vùng vẽ bằng 0 và chẳng thấy gì.
  • Trong DrawScope: size.width, size.height, size.minDimension, center (đều là px). Đổi dp sang px bằng 16.dp.toPx() — được vì DrawScope biết mật độ màn hình.
  • Các khối biến đổi bọc quanh lệnh vẽ: rotate(độ) { }, translate(left, top) { }, scale(tỉLệ) { }, inset(px) { }, clipRect { }.
  • Mỗi lệnh vẽ nhận color hoặc brush, và style: Fill (tô kín, mặc định) hoặc Stroke(width = …, cap = StrokeCap.Round) (chỉ vẽ nét viền, đầu nét bo tròn).
Lệnh vẽVẽ gìTham số chính
drawRectHình chữ nhậtcolor, topLeft, size, style
drawRoundRectChữ nhật bo gócnhư trên + cornerRadius = CornerRadius(px)
drawCircleHình tròncolor, radius, center
drawLineĐoạn thẳngstart, end, strokeWidth, cap
drawArcCung tròn / hình quạtstartAngle, sweepAngle, useCenter, topLeft, size
drawPathHình tự do từ Pathpath, color, style
drawImageẢnh bitmapimage (ImageBitmap), topLeft
drawTextChữtextMeasurer (từ rememberTextMeasurer()), text, topLeft, style

Với drawArc: góc 0° nằm ở hướng 3 giờ và tăng theo chiều kim đồng hồ, nên muốn bắt đầu từ đỉnh (12 giờ) dùng startAngle = -90f. Lệnh vẽ sau nằm đè lên lệnh vẽ trước.

Modifier vẽ

  • Modifier.drawBehind { }: vẽ phía sau nội dung của composable (nền tùy chỉnh, gạch chân).
  • Modifier.drawWithContent { }: tự quyết định thứ tự — gọi drawContent() để vẽ nội dung gốc, vẽ trước nó là "dưới", sau nó là "trên" (huy hiệu, lớp phủ).
  • Modifier.drawWithCache { }: tạo trước các đối tượng tốn kém (Brush, Path) và chỉ tạo lại khi kích thước hoặc state đọc bên trong thay đổi; trả về onDrawBehind { } hoặc onDrawWithContent { }.
// Lớp phủ tối dần phía dưới ảnh để chữ trắng dễ đọc
Modifier.drawWithCache {
    val lopPhu = Brush.verticalGradient(
        0.5f to Color.Transparent,
        1f to Color.Black.copy(alpha = 0.7f)
    )
    onDrawWithContent {
        drawContent()
        drawRect(lopPhu)
    }
}

// Chấm đỏ thông báo ở góc trên phải
Modifier.drawWithContent {
    drawContent()
    drawCircle(Color.Red, radius = 5.dp.toPx(), center = Offset(size.width, 0f))
}

Brush: tô màu chuyển sắc

BrushKiểu chuyển màu
Brush.horizontalGradient(colors)Trái sang phải
Brush.verticalGradient(colors)Trên xuống dưới
Brush.linearGradient(colors, start, end)Theo đường thẳng bất kỳ (mặc định chéo cả vùng)
Brush.radialGradient(colors, center, radius)Tỏa tròn từ tâm ra ngoài
Brush.sweepGradient(colors, center)Quét một vòng quanh tâm như kim đồng hồ

Có thể chỉ định vị trí từng màu bằng cặp 0.3f to Color.Blue. Brush dùng được trong lệnh vẽ (drawRect(brush = …)) và trong Modifier.background(brush, shape).

Shape và clip

Shape mô tả đường viền ngoài của phần tử: RoundedCornerShape(16.dp) (bo góc, có thể bo từng góc riêng bằng topStart, bottomEnd…), CircleShape, CutCornerShape(8.dp) (cắt vát góc) và GenericShape để tự vẽ bằng lệnh đường. Dùng shape với Modifier.clip(shape) (cắt nội dung), background(color, shape), border(width, color, shape).

val HinhTamGiac = GenericShape { size, _ ->
    moveTo(size.width / 2f, 0f)
    lineTo(size.width, size.height)
    lineTo(0f, size.height)
    close()
}

Box(Modifier.size(80.dp).clip(HinhTamGiac).background(Color(0xFFFFB300)))

graphicsLayer và shadow

Modifier.graphicsLayer { } biến đổi cả phần tử (và con của nó) khi vẽ, không làm thay đổi bố cục: scaleX/scaleY (phóng), rotationZ (xoay phẳng; rotationX/rotationY xoay 3D), alpha (độ mờ), translationX/translationY (dịch, px), transformOrigin (tâm biến đổi). Modifier.shadow(elevation = 8.dp, shape = …) đổ bóng theo hình dạng; đặt trước background trong chuỗi modifier.

Modifier.graphicsLayer {
    scaleX = 1.1f
    scaleY = 1.1f
    rotationZ = -8f
    alpha = 0.9f
    translationX = 12.dp.toPx()
}

Ví dụ

Ví dụ 1: Vòng tiến độ mục tiêu bước chân

@Composable
fun VongBuocChan(soBuoc: Int, mucTieu: Int, modifier: Modifier = Modifier) {
    val tienDo by animateFloatAsState(
        targetValue = (soBuoc.toFloat() / mucTieu).coerceIn(0f, 1f),
        label = "tienDo"
    )
    // Đọc màu, kiểu chữ ở ngoài Canvas: khối vẽ không phải hàm @Composable
    val mauNen = MaterialTheme.colorScheme.surfaceVariant
    val mauChinh = MaterialTheme.colorScheme.primary
    val kieuSo = MaterialTheme.typography.headlineMedium.copy(color = MaterialTheme.colorScheme.onSurface)
    val measurer = rememberTextMeasurer()

    Canvas(
        modifier
            .size(200.dp)
            .semantics { contentDescription = "Đã đi $soBuoc trên $mucTieu bước" }
    ) {
        val doDay = 16.dp.toPx()
        val gocTrenTrai = Offset(doDay / 2, doDay / 2)
        val vungCung = Size(size.width - doDay, size.height - doDay)

        drawArc(   // vòng nền đầy đủ
            color = mauNen, startAngle = 0f, sweepAngle = 360f, useCenter = false,
            topLeft = gocTrenTrai, size = vungCung, style = Stroke(width = doDay)
        )
        drawArc(   // phần đã đạt, bắt đầu từ đỉnh
            color = mauChinh, startAngle = -90f, sweepAngle = 360f * tienDo, useCenter = false,
            topLeft = gocTrenTrai, size = vungCung,
            style = Stroke(width = doDay, cap = StrokeCap.Round)
        )

        val chu = measurer.measure(text = "$soBuoc", style = kieuSo)
        drawText(
            chu,
            topLeft = Offset(center.x - chu.size.width / 2f, center.y - chu.size.height / 2f)
        )
    }
}

Ví dụ 2: Thẻ thành viên nền gradient

@Composable
fun TheThanhVien(ten: String, hang: String, modifier: Modifier = Modifier) {
    val hinhThe = RoundedCornerShape(20.dp)
    Box(
        modifier = modifier
            .fillMaxWidth()
            .height(180.dp)
            .shadow(elevation = 8.dp, shape = hinhThe)
            .background(
                brush = Brush.linearGradient(listOf(Color(0xFF5B2EBF), Color(0xFF1E88E5))),
                shape = hinhThe
            )
            .drawWithCache {
                // Quầng sáng góc trên phải, chỉ tạo lại khi kích thước đổi
                val quangSang = Brush.radialGradient(
                    colors = listOf(Color.White.copy(alpha = 0.35f), Color.Transparent),
                    center = Offset(size.width * 0.9f, 0f),
                    radius = size.height
                )
                onDrawBehind { drawRect(quangSang) }
            }
            .padding(20.dp)
    ) {
        Text("THẺ THÀNH VIÊN", color = Color.White.copy(alpha = 0.8f), style = MaterialTheme.typography.labelLarge)
        Column(Modifier.align(Alignment.BottomStart)) {
            Text(ten, color = Color.White, style = MaterialTheme.typography.titleLarge)
            Text("Hạng $hang", color = Color.White, style = MaterialTheme.typography.bodyMedium)
        }
    }
}

Kết quả: Một thẻ bo góc có bóng đổ, nền chuyển từ tím sang xanh dương theo đường chéo, góc trên phải có quầng sáng mờ; chữ trắng "THẺ THÀNH VIÊN" ở trên, tên và hạng ở góc dưới trái.

Ví dụ 3: Biểu đồ cột bước chân trong tuần

@Composable
fun BieuDoCot(duLieu: List<Pair<String, Float>>, modifier: Modifier = Modifier) {
    val measurer = rememberTextMeasurer()
    val mauCot = MaterialTheme.colorScheme.primary
    val mauTruc = MaterialTheme.colorScheme.outline
    val kieuNhan = MaterialTheme.typography.labelSmall.copy(color = MaterialTheme.colorScheme.onSurfaceVariant)

    Canvas(modifier.fillMaxWidth().height(200.dp)) {
        val giaTriLonNhat = duLieu.maxOf { it.second }
        val vungNhan = 20.dp.toPx()
        val dayBieuDo = size.height - vungNhan
        val oRong = size.width / duLieu.size
        val beRongCot = oRong * 0.6f

        drawLine(mauTruc, Offset(0f, dayBieuDo), Offset(size.width, dayBieuDo), strokeWidth = 1.dp.toPx())

        duLieu.forEachIndexed { i, (nhan, giaTri) ->
            val caoCot = dayBieuDo * (giaTri / giaTriLonNhat)
            val trai = i * oRong + (oRong - beRongCot) / 2
            drawRoundRect(
                color = mauCot,
                topLeft = Offset(trai, dayBieuDo - caoCot),
                size = Size(beRongCot, caoCot),
                cornerRadius = CornerRadius(6.dp.toPx())
            )
            val chu = measurer.measure(text = nhan, style = kieuNhan)
            drawText(chu, topLeft = Offset(trai + (beRongCot - chu.size.width) / 2, dayBieuDo + 4.dp.toPx()))
        }
    }
}

Chú ý

  • Px và dp. Mọi số trong DrawScope là pixel. Viết strokeWidth = 4f sẽ mảnh khác nhau trên từng máy; hãy dùng 4.dp.toPx().
  • Không tạo Path/Brush mới mỗi khung hình. Khối vẽ có thể chạy rất nhiều lần (nhất là khi có animation). Tạo trong drawWithCache hoặc remember để tái sử dụng.
  • Khối vẽ không phải @Composable. Không gọi được MaterialTheme.colorScheme hay stringResource bên trong; đọc ra biến ở ngoài Canvas như các ví dụ.
  • Đọc state trong khối vẽ là có lợi: khi giá trị đổi, Compose chỉ vẽ lại, bỏ qua recompose và bố cục — rất hợp để vẽ giá trị animation (xem Vòng đời và các giai đoạn).
  • Thứ tự modifier quyết định kết quả: shadow rồi background rồi padding; đặt clip sau background thì nền không bị cắt theo hình dạng.
  • Canvas "câm" với trình đọc màn hình. Hình vẽ không có semantics; thêm Modifier.semantics { contentDescription = … } tóm tắt ý nghĩa (xem Hỗ trợ tiếp cận).
Mẹo: Cần xoay, phóng hay làm mờ cả một phần tử? Dùng graphicsLayer (hoặc các modifier ngắn rotate, scale, alpha) thay vì vẽ lại bằng Canvas — nhanh hơn và giữ nguyên bố cục.
