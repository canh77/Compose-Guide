Animation cơ bản

Animation giúp người dùng thấy rõ điều gì vừa thay đổi trên màn hình: một nút đổi màu, một thẻ mở rộng, một con số tăng lên. Compose có sẵn các API cấp cao, thường chỉ cần một dòng code là có hiệu ứng mượt.

Định nghĩa

Trong Compose, animation thực chất là state thay đổi dần theo thời gian. Bình thường, khi state đổi từ A sang B, giao diện nhảy ngay sang B. API animation thì tạo ra một chuỗi giá trị trung gian giữa A và B trong vài trăm mili giây, và mỗi khung hình Compose vẽ lại với giá trị mới. Bạn chỉ khai báo giá trị đích, còn Compose lo phần chạy từ giá trị hiện tại đến đích. Nếu đích đổi giữa chừng, animation sẽ chuyển hướng mượt mà, không bị giật.

Với hệ View cũ, bạn phải tạo ValueAnimator/ObjectAnimator, gắn listener, nhớ hủy khi view bị gỡ, và dùng TransitionManager để làm hiệu ứng hiện/ẩn. Compose gói tất cả vào vài composable và hàm như animate*AsState, AnimatedVisibility, AnimatedContent, và chúng tự dừng khi composable rời khỏi màn hình.

Mỗi animation có một AnimationSpec, tức là "công thức chuyển động": chạy trong bao lâu, nhanh dần hay chậm dần, có nảy hay không. Nếu bạn không chỉ định, phần lớn API dùng spring(), một chuyển động mô phỏng lò xo cho cảm giác tự nhiên.

2. animate*AsState: đổi một giá trị

Truyền giá trị đích vào hàm, bạn nhận lại một State chạy dần đến đích. Đặt label để dễ nhận ra animation này trong công cụ Animation Preview của Android Studio.

var selected by remember { mutableStateOf(false) }

val corner by animateDpAsState(
    targetValue = if (selected) 28.dp else 8.dp,
    label = "corner"
)
val background by animateColorAsState(
    targetValue = if (selected) MaterialTheme.colorScheme.primaryContainer
                  else MaterialTheme.colorScheme.surfaceContainer,
    label = "background"
)
val alpha by animateFloatAsState(
    targetValue = if (selected) 1f else 0.6f,
    animationSpec = tween(durationMillis = 300),
    label = "alpha"
)

Có sẵn các phiên bản cho nhiều kiểu dữ liệu: animateIntAsState, animateOffsetAsState, animateSizeAsState… Kiểu tự định nghĩa thì dùng animateValueAsState.

3. AnimatedVisibility: hiện và ẩn

Hiệu ứng vào (enter) và ra (exit) được ghép bằng dấu +. Các hiệu ứng vào gồm fadeIn, slideInVertically, expandVertically, scaleIn… Mỗi hiệu ứng vào có một hiệu ứng ra tương ứng: fadeOut, slideOutVertically, shrinkVertically, scaleOut…

@Composable
fun OfflineBanner(isOffline: Boolean, modifier: Modifier = Modifier) {
    AnimatedVisibility(
        visible = isOffline,
        enter = fadeIn() + expandVertically(),
        exit = fadeOut() + shrinkVertically(),
        modifier = modifier
    ) {
        Surface(color = MaterialTheme.colorScheme.errorContainer) {
            Text(
                text = "Mất kết nối mạng",
                style = MaterialTheme.typography.labelLarge,
                modifier = Modifier.fillMaxWidth().padding(12.dp)
            )
        }
    }
}

4. AnimatedContent và Crossfade: đổi nội dung

AnimatedContent(targetState) { state -> … } vẽ lại nội dung mỗi khi targetState đổi, đồng thời chạy hiệu ứng chuyển giữa nội dung cũ và mới. Tham số transitionSpec mô tả hiệu ứng đó, ví dụ fadeIn() togetherWith fadeOut() (nội dung mới hiện dần cùng lúc nội dung cũ mờ đi). Crossfade là phiên bản đơn giản hơn, chỉ có hiệu ứng mờ chéo.

enum class Weather { SUNNY, RAINY, CLOUDY }

@Composable
fun WeatherIcon(weather: Weather) {
    Crossfade(targetState = weather, label = "weatherIcon") { current ->
        val icon = when (current) {
            Weather.SUNNY -> R.drawable.ic_sunny
            Weather.RAINY -> R.drawable.ic_rainy
            Weather.CLOUDY -> R.drawable.ic_cloudy
        }
        Icon(painterResource(icon), contentDescription = current.name, modifier = Modifier.size(48.dp))
    }
}

5. animateContentSize: tự co giãn

Gắn Modifier.animateContentSize() vào khung chứa. Khi nội dung bên trong làm khung to lên hay nhỏ lại, kích thước khung sẽ đổi mượt thay vì nhảy đột ngột.

6. AnimationSpec: chuyển động ra sao

SpecĐặc điểmVí dụ
spring(dampingRatio, stiffness)Mô phỏng lò xo, không cố định thời gian. dampingRatio quyết định độ nảy (Spring.DampingRatioMediumBouncy…), stiffness quyết định độ nhanh (Spring.StiffnessLow…). Khi bị ngắt giữa chừng, nó vẫn giữ quán tính nên trông tự nhiên nhất. Đây là spec mặc định.spring(dampingRatio = Spring.DampingRatioMediumBouncy)
tween(durationMillis, delayMillis, easing)Chạy đúng số mili giây bạn đặt (mặc định 300ms), theo một đường cong tốc độ (easing) như FastOutSlowInEasing, LinearEasing, LinearOutSlowInEasing.tween(250, easing = LinearEasing)
keyframes { … }Đặt giá trị cụ thể tại từng mốc thời gian, cú pháp giáTrị at mốcMs.keyframes { durationMillis = 400; 1.3f at 150 }
repeatable / infiniteRepeatableLặp một spec khác một số lần hoặc lặp mãi, có thể chạy ngược lại (RepeatMode.Reverse).infiniteRepeatable(tween(800), RepeatMode.Reverse)
snap()Nhảy ngay đến đích, không có chuyển động.snap()

7. rememberInfiniteTransition: lặp mãi

@Composable
fun LoadingPlaceholder(modifier: Modifier = Modifier) {
    val transition = rememberInfiniteTransition(label = "placeholder")
    val pulse by transition.animateFloat(
        initialValue = 0.3f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(animation = tween(800), repeatMode = RepeatMode.Reverse),
        label = "placeholderAlpha"
    )
    Box(
        modifier
            .fillMaxWidth()
            .height(80.dp)
            .graphicsLayer { alpha = pulse }
            .background(MaterialTheme.colorScheme.surfaceVariant, MaterialTheme.shapes.medium)
    )
}

Ví dụ

Ví dụ 1: Nút yêu thích đổi màu và nảy lên

@Composable
fun FavoriteButton(
    isFavorite: Boolean,
    onToggle: () -> Unit,
    modifier: Modifier = Modifier
) {
    val tint by animateColorAsState(
        targetValue = if (isFavorite) MaterialTheme.colorScheme.primary
                      else MaterialTheme.colorScheme.onSurfaceVariant,
        animationSpec = tween(durationMillis = 250),
        label = "favoriteTint"
    )
    val scale by animateFloatAsState(
        targetValue = if (isFavorite) 1.25f else 1f,
        animationSpec = spring(
            dampingRatio = Spring.DampingRatioMediumBouncy,
            stiffness = Spring.StiffnessLow
        ),
        label = "favoriteScale"
    )

    IconButton(onClick = onToggle, modifier = modifier) {
        Icon(
            painter = painterResource(
                if (isFavorite) R.drawable.ic_favorite_filled else R.drawable.ic_favorite_border
            ),
            contentDescription = if (isFavorite) "Bỏ yêu thích" else "Yêu thích",
            tint = tint,
            // Đọc scale trong graphicsLayer: chỉ vẽ lại lớp, không đo/xếp lại bố cục
            modifier = Modifier.graphicsLayer {
                scaleX = scale
                scaleY = scale
            }
        )
    }
}

@Preview
@Composable
private fun FavoriteButtonPreview() {
    var liked by remember { mutableStateOf(false) }
    MaterialTheme {
        FavoriteButton(isFavorite = liked, onToggle = { liked = !liked })
    }
}

Kết quả: Bấm vào trái tim viền xám, nó chuyển dần sang màu chủ đạo, phóng to lên 1.25 lần với một cú nảy nhẹ như lò xo. Bấm lần nữa thì nó co về và xám lại. Nếu bấm liên tục thật nhanh, animation đổi hướng mượt mà, không bị giật.

Ví dụ 2: Thẻ ghi chú "Xem thêm"

@Composable
fun ExpandableNoteCard(title: String, body: String, modifier: Modifier = Modifier) {
    var expanded by rememberSaveable { mutableStateOf(false) }
    val arrowRotation by animateFloatAsState(
        targetValue = if (expanded) 180f else 0f,
        label = "arrowRotation"
    )

    Card(modifier = modifier.fillMaxWidth()) {
        Column(
            modifier = Modifier
                .clickable { expanded = !expanded }
                .animateContentSize()
                .padding(16.dp)
        ) {
            Row(verticalAlignment = Alignment.CenterVertically) {
                Text(
                    text = title,
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.weight(1f)
                )
                Icon(
                    painter = painterResource(R.drawable.ic_expand_more),
                    contentDescription = if (expanded) "Thu gọn" else "Xem thêm",
                    modifier = Modifier.rotate(arrowRotation)
                )
            }
            Spacer(Modifier.height(8.dp))
            Text(
                text = body,
                style = MaterialTheme.typography.bodyMedium,
                maxLines = if (expanded) Int.MAX_VALUE else 2,
                overflow = TextOverflow.Ellipsis
            )
        }
    }
}

Kết quả: Ban đầu thẻ chỉ hiện 2 dòng nội dung, cuối dòng có dấu "…". Chạm vào thẻ thì thẻ dài ra mượt mà để hiện toàn bộ ghi chú, mũi tên xoay ngược lên. Chạm lần nữa thì thẻ co lại về 2 dòng.

Ví dụ 3: Bộ đếm số lượng trong giỏ hàng, số trượt lên/xuống

@Composable
fun QuantityStepper(modifier: Modifier = Modifier) {
    var quantity by rememberSaveable { mutableIntStateOf(1) }

    Row(modifier = modifier, verticalAlignment = Alignment.CenterVertically) {
        IconButton(onClick = { if (quantity > 0) quantity-- }) {
            Icon(painterResource(R.drawable.ic_remove), contentDescription = "Bớt một")
        }

        AnimatedContent(
            targetState = quantity,
            transitionSpec = {
                // Tăng: số mới đi lên từ dưới. Giảm: số mới rơi xuống từ trên.
                val direction = if (targetState > initialState) 1 else -1
                (slideInVertically { fullHeight -> fullHeight * direction } + fadeIn())
                    .togetherWith(slideOutVertically { fullHeight -> -fullHeight * direction } + fadeOut())
            },
            contentAlignment = Alignment.Center,
            label = "quantity"
        ) { value ->
            // Dùng "value" của lambda, KHÔNG dùng biến quantity bên ngoài
            Text(
                text = "$value",
                style = MaterialTheme.typography.headlineMedium,
                modifier = Modifier.widthIn(min = 48.dp),
                textAlign = TextAlign.Center
            )
        }

        IconButton(onClick = { quantity++ }) {
            Icon(painterResource(R.drawable.ic_add), contentDescription = "Thêm một")
        }
    }
}

Kết quả: Ở giữa hai nút trừ và cộng là con số. Bấm "+" thì số cũ trượt lên và mờ đi, số mới trồi lên từ bên dưới. Bấm "−" thì hướng ngược lại. Giống đồng hồ cơ, người dùng thấy ngay số đang tăng hay giảm.

Chú ý

  • Dùng tham số của lambda: trong AnimatedContent và Crossfade, phải vẽ theo giá trị mà lambda nhận được (value, current). Nếu dùng biến state bên ngoài, nội dung cũ đang mờ đi cũng sẽ hiện giá trị mới, và hiệu ứng trông sai.
  • Thứ tự modifier: đặt animateContentSize() trước các modifier quy định kích thước như size, height, defaultMinSize. Nếu đặt sau, kích thước đã bị chốt cứng từ bên ngoài, nên thường bạn sẽ không thấy hiệu ứng.
  • Hiệu năng: với phóng to, xoay, mờ hay dịch chuyển, hãy đọc giá trị animation bên trong Modifier.graphicsLayer { … }. Như vậy mỗi khung hình chỉ vẽ lại lớp hiển thị. Ngược lại, đổi size/padding bằng animateDpAsState sẽ buộc đo và xếp lại bố cục ở mỗi khung hình (xem Hiệu năng).
  • AnimatedVisibility gỡ hẳn nội dung khỏi cây giao diện sau khi ẩn xong, nên state bên trong (ví dụ chữ đang nhập) sẽ mất. Nếu chỉ muốn làm mờ mà vẫn giữ chỗ và giữ state, hãy animate alpha.
  • Luôn đặt label cho mọi animation. Không đặt thì code vẫn chạy, nhưng trong Animation Preview và Layout Inspector bạn sẽ chỉ thấy những cái tên chung chung, khó phân biệt.
  • Giữ animation ngắn và có mục đích: chuyển động trên giao diện thường chỉ nên dài khoảng 150–400ms. Animation quá dài hoặc quá nhiều khiến app có cảm giác chậm.
Mẹo: Muốn một phần tử có hiệu ứng xuất hiện ngay lần đầu màn hình hiện ra, hãy dùng AnimatedVisibility(visibleState = remember { MutableTransitionState(false).apply { targetState = true } }). Bản dùng visible = true sẽ không có animation vì giá trị không hề đổi.
