Image, Icon và tải ảnh từ mạng

Ảnh đại diện, ảnh sản phẩm, icon trên nút: hình ảnh làm giao diện dễ hiểu và hấp dẫn hơn. Phần này hướng dẫn hiển thị ảnh có sẵn trong app, dùng icon đúng chuẩn và tải ảnh từ Internet một cách hiệu quả.

Định nghĩa

Image là composable vẽ một hình (ảnh chụp, hình minh họa) lên màn hình, tương đương ImageView trong hệ View. Icon là composable chuyên cho biểu tượng nhỏ, đơn sắc: nó tự tô màu theo màu nội dung hiện tại và có kích thước mặc định chuẩn Material.

Compose có ba cách biểu diễn hình ảnh:

KiểuBản chấtTạo từ đâu
ImageBitmapẢnh dạng điểm ảnh (raster) như PNG, JPG, WebPImageBitmap.imageResource(R.drawable.x), hoặc bitmap.asImageBitmap() từ Bitmap Android
ImageVectorẢnh vector (đường nét, hình học), phóng to không vỡImageVector.vectorResource(R.drawable.x) từ file vector XML
PainterLớp trừu tượng "thứ gì đó vẽ được"; bọc được cả hai loại trênpainterResource(R.drawable.x) – tự nhận biết file là bitmap hay vector

Trong đa số trường hợp bạn chỉ cần painterResource(). Ảnh từ mạng thì Compose không tự tải; bạn dùng thư viện Coil (Coroutine Image Loader), thư viện tải ảnh viết bằng Kotlin, hỗ trợ Compose sẵn.

Cách dùng

Hiển thị ảnh trong app

Đặt file vào res/drawable rồi gọi:

Image(
    painter = painterResource(R.drawable.banner_sale),
    contentDescription = "Khuyến mãi mùa hè giảm đến 50%",
    contentScale = ContentScale.Crop,
    modifier = Modifier
        .fillMaxWidth()
        .aspectRatio(16f / 9f)
)

contentDescription là câu mô tả ảnh cho trình đọc màn hình (TalkBack). Ảnh mang thông tin thì mô tả ngắn gọn nội dung; ảnh chỉ để trang trí (hoa văn nền, hình minh họa lặp lại ý của chữ bên cạnh) thì truyền null để TalkBack bỏ qua.

ContentScale: ảnh co giãn thế nào trong khung

Giá trịCách hoạt độngHợp với
ContentScale.Fit (mặc định)Thu/phóng giữ tỉ lệ để thấy trọn ảnh; có thể chừa khoảng trốngẢnh sản phẩm cần thấy đầy đủ
ContentScale.CropGiữ tỉ lệ, phủ kín khung, cắt phần thừaAvatar, ảnh bìa, ảnh trong thẻ
ContentScale.FillBoundsKéo giãn cho khít khung, không giữ tỉ lệ (ảnh có thể méo)Hình nền dạng họa tiết, gradient
ContentScale.FillWidthGiữ tỉ lệ, chiều rộng ảnh bằng khung (chiều cao có thể tràn và bị cắt)Banner rộng hết màn hình
ContentScale.FillHeightGiữ tỉ lệ, chiều cao ảnh bằng khungẢnh trong hàng ngang cố định chiều cao
ContentScale.InsideGiống Fit nhưng chỉ thu nhỏ, không bao giờ phóng to ảnh nhỏLogo nhỏ, tránh bị mờ vì phóng to
ContentScale.NoneGiữ nguyên kích thước gốc, chỉ căn theo alignmentTrường hợp đặc biệt, ít dùng

Bo tròn, viền, tỉ lệ khung, màu và độ mờ

  • Modifier.clip(CircleShape) hoặc clip(RoundedCornerShape(12.dp)): cắt ảnh theo hình tròn / bo góc.
  • Modifier.border(2.dp, color, CircleShape): viền ôm theo cùng hình dạng.
  • Modifier.aspectRatio(1f): giữ khung vuông (hoặc 16f / 9f…) bất kể chiều rộng.
  • colorFilter = ColorFilter.tint(color): tô một màu lên ảnh; ColorFilter.colorMatrix(ColorMatrix().apply { setToSaturation(0f) }): biến ảnh thành đen trắng (ví dụ sản phẩm hết hàng).
  • alpha = 0.5f: làm ảnh mờ một nửa.

Thứ tự modifier có ý nghĩa (xem Modifier): đặt kích thước trước, rồi clip, rồi border.

Icon

Icon(
    painter = painterResource(R.drawable.ic_favorite), // icon tải về, tên giả định
    contentDescription = "Yêu thích",
    tint = MaterialTheme.colorScheme.error,
    modifier = Modifier.size(20.dp)
)
  • Màu (tint) mặc định lấy từ LocalContentColor, tức màu nội dung của vùng chứa: đặt icon trong Button thì icon tự có màu chữ của nút. Muốn giữ màu gốc của hình nhiều màu (logo), dùng tint = Color.Unspecified.
  • Kích thước: icon Material có kích thước gốc 24dp; hình không có kích thước gốc thì Icon cũng mặc định 24dp. Đổi bằng Modifier.size(…).

Lấy icon: dùng Material Symbols dạng XML

Nhiều hướng dẫn cũ dùng thư viện material-icons-extended (Icons.Filled.…, Icons.Outlined.…). Thư viện này không còn được duy trì và không còn được khuyến nghị: nó chứa hàng nghìn icon bạn không dùng tới, làm thời gian build chậm đi đáng kể, và không có các icon mới. Cách nên làm:

  1. Vào trang Material Symbols trên Google Fonts (fonts.google.com/icons), chọn icon, chỉnh kiểu (Outlined/Rounded/Sharp, độ đậm, Fill).
  2. Trong khung chi tiết, chọn tab Android và tải file vector XML.
  3. Chép file vào res/drawable, đặt tên dễ nhớ như ic_favorite.xml.
  4. Dùng: Icon(painter = painterResource(R.drawable.ic_favorite), contentDescription = …).

Bạn chỉ thêm đúng những icon cần dùng, file nhỏ và vẽ sắc nét ở mọi mật độ màn hình. Trong hướng dẫn này, các tên như R.drawable.ic_search là tên giả định cho icon đã tải theo cách trên.

Tải ảnh từ mạng với Coil 3

Bước 1 – thêm thư viện. Ví dụ dùng version catalog (xem Thiết lập dự án); điền phiên bản Coil 3 mới nhất từ trang chủ Coil:

gradle/libs.versions.toml

[versions]
coil = "..." # điền phiên bản Coil 3 mới nhất

[libraries]
coil-compose = { module = "io.coil-kt.coil3:coil-compose", version.ref = "coil" }
coil-network-okhttp = { module = "io.coil-kt.coil3:coil-network-okhttp", version.ref = "coil" }

app/build.gradle.kts

dependencies {
    implementation(libs.coil.compose)
    implementation(libs.coil.network.okhttp) // cần để tải ảnh qua http/https
}

Bước 2 – khai báo quyền Internet trong AndroidManifest.xml:

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.INTERNET" />
    <application ...>
        ...
    </application>
</manifest>

Bước 3 – dùng AsyncImage. Nó tải ảnh ở luồng nền, lưu cache, và tự thu nhỏ ảnh về đúng kích thước khung hiển thị:

AsyncImage(
    model = "https://example.com/anh/san-pham-01.jpg",
    contentDescription = "Áo khoác gió màu xanh",
    placeholder = painterResource(R.drawable.img_placeholder), // hiện trong lúc tải
    error = painterResource(R.drawable.img_error),             // hiện khi tải lỗi
    contentScale = ContentScale.Crop,
    modifier = Modifier.size(120.dp)
)

Ví dụ

Ví dụ 1: Avatar tròn có chấm trạng thái trực tuyến

@Composable
fun UserAvatar(
    @DrawableRes imageRes: Int,
    userName: String,
    isOnline: Boolean,
    modifier: Modifier = Modifier,
    size: Dp = 56.dp
) {
    Box(modifier = modifier.size(size)) {
        Image(
            painter = painterResource(imageRes),
            contentDescription = "Ảnh đại diện của $userName",
            contentScale = ContentScale.Crop,
            modifier = Modifier
                .matchParentSize()
                .clip(CircleShape)
                .border(2.dp, MaterialTheme.colorScheme.primary, CircleShape)
        )
        if (isOnline) {
            Box(
                modifier = Modifier
                    .align(Alignment.BottomEnd)
                    .size(size / 4)
                    .clip(CircleShape)
                    .background(Color(0xFF2E7D32))
                    .border(2.dp, MaterialTheme.colorScheme.surface, CircleShape)
            )
        }
    }
}

@Preview(showBackground = true)
@Composable
fun UserAvatarPreview() {
    MaterialTheme {
        UserAvatar(imageRes = R.drawable.avatar_lan, userName = "Lan", isOnline = true)
    }
}

Kết quả: Ảnh đại diện hình tròn 56dp, được cắt kín khung (không méo), có viền màu chủ đạo. Ở góc dưới phải có một chấm tròn xanh lá với viền cùng màu nền, báo hiệu người dùng đang trực tuyến.

Ví dụ 2: Hàng thông tin thời tiết dùng Icon

@Composable
fun WeatherStat(@DrawableRes iconRes: Int, label: String, value: String) {
    Row(verticalAlignment = Alignment.CenterVertically) {
        Icon(
            painter = painterResource(iconRes),
            contentDescription = null, // chữ bên cạnh đã mô tả đủ
            tint = MaterialTheme.colorScheme.primary,
            modifier = Modifier.size(20.dp)
        )
        Spacer(Modifier.width(8.dp))
        Text("$label: ", style = MaterialTheme.typography.bodyMedium)
        Text(value, style = MaterialTheme.typography.bodyMedium, fontWeight = FontWeight.SemiBold)
    }
}

@Composable
fun WeatherDetails(modifier: Modifier = Modifier) {
    // Các icon Material Symbols tải về res/drawable (tên giả định)
    Column(modifier = modifier.padding(16.dp), verticalArrangement = Arrangement.spacedBy(8.dp)) {
        WeatherStat(R.drawable.ic_humidity, "Độ ẩm", "78%")
        WeatherStat(R.drawable.ic_air, "Gió", "12 km/h")
        WeatherStat(R.drawable.ic_sunny, "Chỉ số UV", "6 (Cao)")
    }
}

Kết quả: Ba dòng xếp dọc, mỗi dòng có icon nhỏ 20dp màu chủ đạo, theo sau là nhãn thường và giá trị in đậm: "Độ ẩm: 78%", "Gió: 12 km/h", "Chỉ số UV: 6 (Cao)". Ở chế độ tối, icon tự đổi sang tông màu primary của theme tối.

Ví dụ 3: Thẻ bài viết với ảnh bìa tải từ mạng

import coil3.compose.AsyncImage

@Composable
fun ArticleCard(
    title: String,
    author: String,
    coverUrl: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    Card(onClick = onClick, modifier = modifier.fillMaxWidth()) {
        AsyncImage(
            model = coverUrl,
            contentDescription = null, // tiêu đề bên dưới đã nói nội dung bài
            placeholder = painterResource(R.drawable.img_placeholder),
            error = painterResource(R.drawable.img_error),
            contentScale = ContentScale.Crop,
            modifier = Modifier
                .fillMaxWidth()
                .aspectRatio(16f / 9f)
        )
        Column(modifier = Modifier.padding(16.dp)) {
            Text(
                text = title,
                style = MaterialTheme.typography.titleMedium,
                maxLines = 2,
                overflow = TextOverflow.Ellipsis
            )
            Spacer(Modifier.height(4.dp))
            Text(
                text = "Bởi $author",
                style = MaterialTheme.typography.bodySmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant
            )
        }
    }
}

Kết quả: Một thẻ bo góc rộng hết màn hình. Phần trên là ảnh bìa tỉ lệ 16:9: lúc đầu hiện ảnh chờ img_placeholder, tải xong thì hiện ảnh thật được cắt vừa khung; nếu mất mạng hoặc URL hỏng thì hiện img_error. Phần dưới là tiêu đề tối đa hai dòng và tên tác giả màu xám. Chạm vào thẻ sẽ gọi onClick (xem thêm Card và Chip).

Chú ý

  • Đừng nhét ảnh quá lớn vào res/drawable. painterResource giải mã ảnh ở độ phân giải đầy đủ; một ảnh 4000×3000 chiếm khoảng 48 MB bộ nhớ khi giải mã, dễ gây giật hoặc lỗi hết bộ nhớ (OOM). Hãy thu ảnh về đúng kích thước hiển thị, đặt vào thư mục mật độ phù hợp (drawable-xxhdpi…), và chuyển sang WebP (Android Studio: chuột phải vào ảnh, chọn Convert to WebP) để giảm dung lượng APK.
  • Icon và hình minh họa đơn giản nên dùng vector XML thay vì PNG: nhẹ hơn và sắc nét ở mọi màn hình.
  • painterResource chỉ hỗ trợ ảnh bitmap (PNG, JPG, WebP…) và vector drawable. Các loại drawable XML khác như shape, layer-list, selector sẽ gây lỗi; trong Compose hãy vẽ chúng bằng Modifier.background, clip hoặc Canvas (xem Đồ họa).
  • Quên thêm thư viện coil-network-okhttp hoặc quyền INTERNET là lỗi phổ biến nhất khiến AsyncImage chỉ hiện ảnh lỗi/placeholder mà không báo gì rõ ràng.
  • Ảnh mạng nên luôn có placeholder và error, và khung ảnh nên có kích thước cố định hoặc aspectRatio, để bố cục không "nhảy" khi ảnh tải xong.
  • contentDescription không phải tùy chọn cho có: ảnh mang thông tin phải được mô tả, ảnh trang trí đặt null. Không viết kiểu "ảnh", "icon" vì vô nghĩa với người dùng TalkBack (xem Accessibility).
Mẹo: Khi cần hiển thị một Bitmap bạn tự tạo (ví dụ ảnh chụp từ camera), chuyển bằng bitmap.asImageBitmap() rồi dùng Image(bitmap = …, contentDescription = …). Nhớ bọc phép chuyển hoặc giải mã trong remember để không lặp lại ở mỗi lần vẽ lại.
