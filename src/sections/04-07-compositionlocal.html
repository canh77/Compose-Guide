CompositionLocal: truyền dữ liệu ngầm qua cây UI

CompositionLocal cho phép một giá trị "chảy" xuống mọi composable bên dưới mà không phải truyền qua tham số ở từng tầng. Đây chính là cơ chế giúp MaterialTheme, LocalContext hoạt động.

Định nghĩa

Trong Compose, dữ liệu thường đi từ trên xuống qua tham số. Cách này rõ ràng, nhưng với những giá trị mà gần như mọi composable đều cần (màu chữ, kiểu chữ, mật độ điểm ảnh, Context), việc truyền qua mười tầng hàm chỉ để tầng cuối dùng sẽ rất rườm rà. Hiện tượng này thường được gọi là "khoan tham số" (prop drilling).

CompositionLocal là một "khe" dữ liệu gắn với một nhánh của cây UI. Một composable ở trên cung cấp giá trị, mọi composable bên trong nhánh đó có thể đọc bằng .current mà không cần tham số. Khi đọc, Compose tìm nơi cung cấp gần nhất phía trên; nếu không có thì dùng giá trị mặc định.

Nếu bạn quen hệ View, hãy nghĩ tới thuộc tính theme như ?attr/colorPrimary: View không nhận màu qua tham số mà tự tra theme đang áp dụng. CompositionLocal là phiên bản tổng quát hơn của ý tưởng đó, và có thể đổi giá trị cho từng vùng nhỏ của màn hình.

Cách dùng

Đọc giá trị có sẵn

Gọi .current trong thân composable, ví dụ val context = LocalContext.current. Các CompositionLocal hay dùng:

Cung cấp giá trị cho một vùng

CompositionLocalProvider(LocalContentColor provides Color(0xFF2E7D32)) {
    Text("Đã giao hàng")   // chữ màu xanh lá
    CompositionLocalProvider(LocalContentColor provides Color.Gray) {
        Text("Lúc 14:30")   // nhà cung cấp bên trong ghi đè: chữ xám
    }
}

Có thể cung cấp nhiều giá trị cùng lúc: CompositionLocalProvider(LocalA provides a, LocalB provides b) { … }. Giá trị chỉ có hiệu lực bên trong lambda nội dung.

Tạo CompositionLocal của riêng bạn

Khai báo ở cấp cao nhất của file, đặt tên bắt đầu bằng Local, kèm giá trị mặc định (hoặc error(…) nếu bắt buộc phải được cung cấp). Có hai hàm tạo:

MaterialTheme cũng là CompositionLocal

MaterialTheme(colorScheme = …, typography = …) { … } thực chất cung cấp các CompositionLocal nội bộ. Khi bạn viết MaterialTheme.colorScheme.primary, getter này đọc .current của CompositionLocal tương ứng. Vì vậy có thể bọc một phần màn hình trong MaterialTheme khác để đổi màu riêng vùng đó (xem Tùy biến theme).

Khi nào KHÔNG nên dùng

CompositionLocal làm phụ thuộc trở nên "vô hình": nhìn chữ ký hàm không biết nó cần gì. Chỉ dùng cho giá trị mang tính hạ tầng/giao diện, có giá trị mặc định hợp lý và được nhiều nơi dùng. Dữ liệu nghiệp vụ (danh sách sản phẩm, người dùng đang đăng nhập) và ViewModel nên được truyền rõ ràng qua tham số (xem State hoisting, ViewModel).

Ví dụ

1. Đổi màu nội dung một vùng cảnh báo

@Composable
fun LowBatteryBanner() {
    Column(Modifier.fillMaxWidth().padding(16.dp)) {
        Text("Thiết bị")
        CompositionLocalProvider(LocalContentColor provides MaterialTheme.colorScheme.error) {
            Text("Pin còn 5%", style = MaterialTheme.typography.titleMedium)
            Text("Hãy cắm sạc để tránh mất dữ liệu")
        }
    }
}

@Preview(showBackground = true)
@Composable
fun LowBatteryBannerPreview() {
    MaterialTheme { LowBatteryBanner() }
}

Kết quả: Dòng "Thiết bị" có màu chữ mặc định; hai dòng bên trong provider hiển thị màu đỏ báo lỗi của theme mà không cần truyền color cho từng Text. Một Icon đặt trong vùng này cũng tự lấy màu đó.

2. Tự tạo LocalSpacing cho khoảng cách thiết kế

@Immutable
data class Spacing(
    val small: Dp = 4.dp,
    val medium: Dp = 8.dp,
    val large: Dp = 16.dp
)

// Gần như không đổi khi chạy nên dùng bản static
val LocalSpacing = staticCompositionLocalOf { Spacing() }

@Composable
fun ShopTheme(compact: Boolean = false, content: @Composable () -> Unit) {
    val spacing = if (compact) Spacing(small = 2.dp, medium = 4.dp, large = 8.dp) else Spacing()
    MaterialTheme {
        CompositionLocalProvider(LocalSpacing provides spacing, content = content)
    }
}

@Composable
fun ProductCard(name: String, price: String) {
    val spacing = LocalSpacing.current
    Card(Modifier.fillMaxWidth().padding(spacing.medium)) {
        Column(Modifier.padding(spacing.large)) {
            Text(name, style = MaterialTheme.typography.titleMedium)
            Spacer(Modifier.height(spacing.small))
            Text(price, color = MaterialTheme.colorScheme.primary)
        }
    }
}

@Preview
@Composable
fun ProductCardPreview() {
    ShopTheme(compact = true) { ProductCard("Áo khoác gió", "450.000 đ") }
}

Kết quả: Thẻ sản phẩm dùng khoảng cách lấy từ LocalSpacing. Đổi compact = true ở ShopTheme làm mọi thẻ bên trong gọn lại mà không phải sửa từng composable.

3. Ẩn bàn phím khi bấm Tìm kiếm

@Composable
fun SearchBox(onSearch: (String) -> Unit) {
    var query by rememberSaveable { mutableStateOf("") }
    val focusManager = LocalFocusManager.current
    val keyboard = LocalSoftwareKeyboardController.current

    OutlinedTextField(
        value = query,
        onValueChange = { query = it },
        label = { Text("Tìm sản phẩm") },
        singleLine = true,
        keyboardOptions = KeyboardOptions(imeAction = ImeAction.Search),
        keyboardActions = KeyboardActions(onSearch = {
            keyboard?.hide()
            focusManager.clearFocus()
            onSearch(query)
        }),
        modifier = Modifier.fillMaxWidth()
    )
}

Kết quả: Khi người dùng bấm phím Tìm trên bàn phím, bàn phím đóng lại, ô nhập mất focus và hàm onSearch nhận từ khóa.

Chú ý

  • .current chỉ gọi được trong composable. Muốn dùng trong onClick, hãy đọc ra biến trước (val context = LocalContext.current) rồi dùng biến đó trong lambda.
  • Không dùng CompositionLocal để truyền ViewModel, repository hay dữ liệu màn hình. Phụ thuộc ẩn khiến composable khó hiểu, khó Preview và khó test.
  • Dùng staticCompositionLocalOf cho giá trị đổi thường xuyên sẽ recompose cả nhánh bên dưới mỗi lần đổi. Giá trị hay đổi thì chọn compositionLocalOf.
  • Đặt giá trị mặc định có ý nghĩa. Nếu không có mặc định hợp lý, dùng error("Chưa cung cấp LocalX") để phát hiện sớm việc quên provider, kể cả trong Preview.
  • LocalContext.current không phải lúc nào cũng là Activity (có thể là ContextWrapper); đừng ép kiểu thẳng sang Activity.
Mẹo: Dùng LocalInspectionMode.current để thay thành phần cần thiết bị thật (bản đồ, camera) bằng một khung giả khi chạy Preview.
