Column, Row và Box

Column, Row và Box là ba "khung xương" để sắp xếp mọi giao diện trong Compose: xếp dọc, xếp ngang và xếp chồng. Nắm chắc ba layout này là bạn đã dựng được phần lớn các màn hình thường gặp.

Định nghĩa

Nếu một hàm @Composable phát ra nhiều phần tử mà không đặt chúng trong layout nào, Compose sẽ vẽ tất cả chồng lên nhau ở góc trên bên trái. Để kiểm soát vị trí, bạn bọc các phần tử trong một layout chuẩn (standard layout):

  • Column – xếp các con theo chiều dọc, từ trên xuống dưới. Tương đương LinearLayout với android:orientation="vertical".
  • Row – xếp các con theo chiều ngang, từ đầu dòng đến cuối dòng. Tương đương LinearLayout nằm ngang.
  • Box – đặt các con chồng lên nhau, con viết sau nằm trên con viết trước. Tương đương FrameLayout.

Mỗi layout có một trục chính (main axis – hướng mà các con được xếp nối tiếp nhau) và một trục phụ (cross axis – hướng vuông góc). Cách phân bố các con dọc theo trục chính gọi là arrangement, còn cách căn chúng trên trục phụ gọi là alignment.

Khác với hệ thống View, lồng nhiều layout trong Compose không làm hiệu năng giảm mạnh, vì Compose chỉ đo mỗi phần tử một lần trong một lượt layout (xem Kích thước và ràng buộc). Vì vậy bạn cứ thoải mái lồng Row trong Column, Box trong Row… miễn là code dễ đọc.

Cách dùng

Tham số sắp xếp của từng layout

LayoutTrục chính (arrangement)Trục phụ (alignment)Mặc định
ColumnverticalArrangementhorizontalAlignmentArrangement.Top, Alignment.Start
RowhorizontalArrangementverticalAlignmentArrangement.Start, Alignment.Top
Box(không có, các con chồng lên nhau)contentAlignmentAlignment.TopStart

Mẹo nhớ: tên tham số arrangement luôn trùng với hướng của layout (Column dọc → verticalArrangement), còn alignment là hướng còn lại.

Các giá trị Arrangement

Giá trịDùng choÝ nghĩa
Arrangement.TopColumnDồn tất cả các con lên phía trên (mặc định của Column).
Arrangement.BottomColumnDồn tất cả các con xuống đáy.
Arrangement.Start / EndRowDồn về đầu dòng / cuối dòng; tự đảo chiều khi ngôn ngữ viết từ phải sang trái (RTL).
Arrangement.CenterCả haiGom các con vào giữa trục chính.
Arrangement.SpaceBetweenCả haiCon đầu sát mép đầu, con cuối sát mép cuối, phần trống chia đều vào giữa các con.
Arrangement.SpaceAroundCả haiMỗi con có khoảng trống bằng nhau ở hai bên, nên khoảng ở hai mép chỉ bằng một nửa khoảng giữa hai con.
Arrangement.SpaceEvenlyCả haiMọi khoảng trống, kể cả hai mép, đều bằng nhau.
Arrangement.spacedBy(8.dp)Cả haiChèn khoảng cách cố định giữa các con. Có biến thể nhận thêm alignment, ví dụ spacedBy(8.dp, Alignment.CenterVertically) để vừa giãn cách vừa căn giữa cả khối.

Các giá trị Alignment

  • Trục ngang (Alignment.Horizontal, dùng cho Column): Start, CenterHorizontally, End.
  • Trục dọc (Alignment.Vertical, dùng cho Row): Top, CenterVertically, Bottom.
  • Hai chiều (Alignment, dùng cho Box): TopStart, TopCenter, TopEnd, CenterStart, Center, CenterEnd, BottomStart, BottomCenter, BottomEnd.

Modifier chỉ có trong scope

Nội dung của Column, Row, Box được viết trong một scope (phạm vi) riêng: ColumnScope, RowScope, BoxScope. Mỗi scope mở khóa vài modifier đặc biệt mà bên ngoài không gọi được:

  • Modifier.weight(1f) (Row, Column): chia phần không gian còn lại theo tỉ lệ, giống layout_weight.
  • Modifier.align(...): căn riêng một con, ghi đè alignment chung. Trong Column nhận Alignment.Horizontal, trong Row nhận Alignment.Vertical, trong Box nhận Alignment hai chiều.
  • Modifier.matchParentSize() (Box): con có kích thước đúng bằng Box, nhưng không tham gia quyết định kích thước của Box.
  • Modifier.alignByBaseline() (Row): căn các Text cỡ chữ khác nhau theo cùng đường chân chữ.

Spacer – khoảng trống có chủ đích

Spacer là một composable rỗng chỉ chiếm chỗ. Dùng Spacer(Modifier.height(16.dp)) trong Column hoặc Spacer(Modifier.width(8.dp)) trong Row để tạo khoảng cách. Đặc biệt, Spacer(Modifier.weight(1f)) trong Row sẽ "đẩy" các phần tử phía sau về cuối dòng.

Row(modifier = Modifier.fillMaxWidth()) {
    Text("Tổng cộng")
    Spacer(Modifier.weight(1f))   // chiếm hết phần trống ở giữa
    Text("250.000 đ")
}

Ví dụ

1. Hàng liên hệ: avatar + tên + nút gọi

Row chứa một Box tròn, một Column chiếm phần còn lại nhờ weight, và một nút ở cuối.

@Composable
fun ContactRow(
    name: String,
    phone: String,
    onCallClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    Row(
        modifier = modifier
            .fillMaxWidth()
            .padding(horizontal = 16.dp, vertical = 12.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        // Avatar: hình tròn với chữ cái đầu
        Box(
            modifier = Modifier
                .size(48.dp)
                .clip(CircleShape)
                .background(MaterialTheme.colorScheme.primaryContainer),
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = name.take(1).uppercase(),
                style = MaterialTheme.typography.titleMedium,
                color = MaterialTheme.colorScheme.onPrimaryContainer
            )
        }
        Spacer(Modifier.width(16.dp))
        // Tên và số điện thoại chiếm toàn bộ phần còn lại
        Column(modifier = Modifier.weight(1f)) {
            Text(
                text = name,
                style = MaterialTheme.typography.bodyLarge,
                maxLines = 1,
                overflow = TextOverflow.Ellipsis
            )
            Text(
                text = phone,
                style = MaterialTheme.typography.bodyMedium,
                color = MaterialTheme.colorScheme.onSurfaceVariant
            )
        }
        IconButton(onClick = onCallClick) {
            Icon(
                painter = painterResource(R.drawable.ic_call),
                contentDescription = "Gọi $name"
            )
        }
    }
}

2. Huy hiệu chồng lên ảnh sản phẩm bằng Box

@Composable
fun ProductThumbnail(
    discountPercent: Int,
    modifier: Modifier = Modifier
) {
    Box(
        modifier = modifier
            .size(160.dp)
            .clip(RoundedCornerShape(12.dp))
    ) {
        // Lớp dưới cùng: ảnh phủ kín Box
        Image(
            painter = painterResource(R.drawable.product_sneaker),
            contentDescription = "Giày thể thao",
            contentScale = ContentScale.Crop,
            modifier = Modifier.matchParentSize()
        )
        // Lớp trên: nhãn giảm giá ở góc trên trái
        Text(
            text = "-$discountPercent%",
            style = MaterialTheme.typography.labelMedium,
            color = MaterialTheme.colorScheme.onError,
            modifier = Modifier
                .align(Alignment.TopStart)
                .padding(8.dp)
                .background(MaterialTheme.colorScheme.error, RoundedCornerShape(6.dp))
                .padding(horizontal = 6.dp, vertical = 2.dp)
        )
        // Lớp trên cùng: biểu tượng yêu thích ở góc trên phải
        Icon(
            painter = painterResource(R.drawable.ic_favorite),
            contentDescription = "Thêm vào yêu thích",
            tint = Color.White,
            modifier = Modifier
                .align(Alignment.TopEnd)
                .padding(8.dp)
                .size(24.dp)
        )
    }
}

Kết quả: Ảnh vuông 160dp bo góc; nhãn đỏ "-20%" nằm ở góc trên trái, biểu tượng trái tim trắng ở góc trên phải, cả hai đè lên ảnh.

3. Màn hình đăng nhập căn giữa

@Composable
fun LoginScreen(
    onLoginClick: (email: String, password: String) -> Unit,
    modifier: Modifier = Modifier
) {
    var email by remember { mutableStateOf("") }
    var password by remember { mutableStateOf("") }

    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(horizontal = 24.dp),
        // Cách nhau 12dp và cả khối nằm giữa màn hình theo chiều dọc
        verticalArrangement = Arrangement.spacedBy(12.dp, Alignment.CenterVertically),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(text = "Đăng nhập", style = MaterialTheme.typography.headlineMedium)
        OutlinedTextField(
            value = email,
            onValueChange = { email = it },
            label = { Text("Email") },
            singleLine = true,
            modifier = Modifier.fillMaxWidth()
        )
        OutlinedTextField(
            value = password,
            onValueChange = { password = it },
            label = { Text("Mật khẩu") },
            singleLine = true,
            visualTransformation = PasswordVisualTransformation(),
            modifier = Modifier.fillMaxWidth()
        )
        Button(
            onClick = { onLoginClick(email, password) },
            modifier = Modifier.fillMaxWidth()
        ) {
            Text("Đăng nhập")
        }
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            TextButton(onClick = { /* mở màn quên mật khẩu */ }) { Text("Quên mật khẩu?") }
            TextButton(onClick = { /* mở màn đăng ký */ }) { Text("Tạo tài khoản") }
        }
    }
}

Kết quả: Tiêu đề, hai ô nhập, nút "Đăng nhập" rộng hết chiều ngang và hàng hai nút chữ được gom thành một khối nằm chính giữa màn hình; hai nút chữ bị đẩy về hai mép trái phải. Phần trạng thái remember được giải thích ở State và remember.

Chú ý

  • Arrangement chỉ có tác dụng khi còn chỗ trống. Một Column không có fillMaxSize()/fillMaxHeight() sẽ chỉ cao vừa đủ nội dung, nên Arrangement.Center hay SpaceBetween trông như không làm gì cả.
  • Đừng nhầm trục. Column không có tham số verticalAlignment, Row không có verticalArrangement; viết nhầm sẽ báo lỗi biên dịch. Hãy nhớ: arrangement theo hướng của layout, alignment theo hướng còn lại.
  • Modifier theo scope không dùng được ở ngoài. Gọi Modifier.weight() trong một hàm con không nằm trong RowScope/ColumnScope sẽ lỗi biên dịch. Cách đúng: để layout cha truyền modifier đã có weight vào tham số modifier của hàm con.
  • Thứ tự vẽ trong Box là thứ tự viết code. Phần tử viết sau nằm trên. Nếu cần thay đổi mà không đảo code, dùng Modifier.zIndex(1f).
  • Column và Row không tự cuộn. Nội dung vượt quá màn hình sẽ bị cắt mất. Thêm Modifier.verticalScroll(rememberScrollState()) cho nội dung ngắn, hoặc dùng LazyColumn cho danh sách dài.
  • Ưu tiên Start/End thay cho Left/Right. Alignment.Start, Arrangement.End… tự đảo chiều với ngôn ngữ RTL như tiếng Ả Rập. Chỉ dùng Arrangement.Absolute.Left khi thật sự muốn cố định theo mép trái.
Mẹo: Khi một màn hình bắt đầu lồng quá ba, bốn tầng, hãy tách từng khối thành hàm @Composable riêng (như ContactRow ở trên). Code dễ đọc hơn, dễ xem trước bằng @Preview và dễ tái sử dụng.
