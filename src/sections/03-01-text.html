Text và kiểu chữ

Gần như màn hình nào cũng có chữ: tiêu đề, giá tiền, mô tả, điều khoản. Text là composable dùng để hiển thị chữ, kèm cả một bộ công cụ để định dạng, đa ngôn ngữ và tạo liên kết bấm được.

Định nghĩa

Text là hàm composable của Material 3 (gói androidx.compose.material3) dùng để vẽ một đoạn chữ lên màn hình. Nó tương đương với TextView trong hệ thống View cũ, nhưng thay vì đặt thuộc tính trong XML rồi gọi setText(), bạn chỉ cần gọi Text("Xin chào") và truyền tham số. Khi dữ liệu đổi, Compose gọi lại hàm và chữ tự cập nhật.

Bên dưới, Text của Material dựa trên BasicText (tầng foundation, không có giao diện Material). Khác biệt quan trọng: Text tự lấy màu và kiểu chữ từ theme (MaterialTheme, LocalContentColor) nên chữ luôn hợp với giao diện sáng/tối mà bạn không cần chỉnh tay.

Để định dạng một phần đoạn chữ (in đậm vài từ, gạch ngang giá cũ, gắn link), Compose dùng AnnotatedString – chuỗi có "chú thích" kiểu dáng cho từng khoảng ký tự, thay cho SpannableString trong View.

Quy tắc ưu tiên: tham số truyền trực tiếp (fontWeight, color…) sẽ ghi đè giá trị tương ứng trong style. Cách làm tốt là chọn một style từ theme rồi chỉ chỉnh vài chỗ khác biệt.

Dùng thang chữ của Material 3

MaterialTheme.typography có 15 kiểu chia thành 5 nhóm, mỗi nhóm 3 cỡ Large/Medium/Small: display… (số/chữ rất to), headline… (tiêu đề màn hình), title… (tiêu đề thẻ, mục), body… (nội dung), label… (nhãn nút, chú thích nhỏ). Ưu tiên dùng các kiểu này thay vì tự đặt fontSize khắp nơi, để sau này đổi theme là cả app đổi theo (xem Tùy biến theme).

Text("Đơn hàng của bạn", style = MaterialTheme.typography.headlineSmall)
Text(
    text = "Giao trong 2 giờ",
    style = MaterialTheme.typography.bodyMedium.copy(fontWeight = FontWeight.SemiBold)
)

Chuỗi từ tài nguyên: stringResource và pluralStringResource

Đừng viết cứng chữ trong code nếu app cần đa ngôn ngữ. Đặt chuỗi vào res/values/strings.xml rồi đọc bằng stringResource(). Chuỗi có tham số dùng ký hiệu %1$s (chuỗi), %1$d (số nguyên). Với chuỗi phụ thuộc số lượng, dùng thẻ <plurals> và pluralStringResource().

res/values/strings.xml

<resources>
    <string name="cart_title">Giỏ hàng</string>
    <string name="greeting">Xin chào, %1$s!</string>
    <plurals name="cart_items">
        <item quantity="one">%d sản phẩm</item>
        <item quantity="other">%d sản phẩm</item>
    </plurals>
</resources>
@Composable
fun CartHeader(userName: String, itemCount: Int) {
    Column {
        Text(stringResource(R.string.cart_title), style = MaterialTheme.typography.titleLarge)
        Text(stringResource(R.string.greeting, userName))
        // Tham số thứ 2 chọn dạng số ít/nhiều, tham số thứ 3 điền vào %d
        Text(pluralStringResource(R.plurals.cart_items, itemCount, itemCount))
    }
}

Định dạng từng phần với buildAnnotatedString

buildAnnotatedString { … } cho phép nối nhiều đoạn chữ, mỗi đoạn một kiểu. Có hai loại kiểu:

  • SpanStyle: áp cho một khoảng ký tự – màu, cỡ, độ đậm, nghiêng, gạch ngang, nền chữ…
  • ParagraphStyle: áp cho cả đoạn văn – căn lề (textAlign), lineHeight, thụt đầu dòng. Mỗi ParagraphStyle tự tách thành một đoạn riêng.
val note = buildAnnotatedString {
    withStyle(ParagraphStyle(lineHeight = 22.sp)) {
        withStyle(SpanStyle(fontWeight = FontWeight.Bold)) {
            append("Lưu ý: ")
        }
        append("Đơn hàng trên 300.000 đ được ")
        withStyle(SpanStyle(fontStyle = FontStyle.Italic, color = Color(0xFF2E7D32))) {
            append("miễn phí giao hàng")
        }
        append(".")
    }
}
Text(note)

Link bấm được: LinkAnnotation.Url và withLink

Từ Compose 1.7, bạn bọc phần chữ cần làm link trong withLink(LinkAnnotation.Url("https://…")) { … }. Khi người dùng chạm vào, Compose tự mở trình duyệt; không cần tự bắt sự kiện chạm. Muốn tô màu, gạch chân link thì truyền styles = TextLinkStyles(style = SpanStyle(…)).

Cho phép chọn và sao chép chữ

Mặc định chữ trong Text không chọn được. Bọc vùng cần chọn trong SelectionContainer { … }; phần nào bên trong không muốn cho chọn thì bọc tiếp bằng DisableSelection { … }.

SelectionContainer {
    Column {
        Text("Mã đơn hàng: DH-2026-08812")
        DisableSelection {
            Text("Nhấn giữ mã ở trên để sao chép", style = MaterialTheme.typography.labelSmall)
        }
    }
}

Phông chữ tùy chỉnh

  1. Tạo thư mục res/font, chép file .ttf/.otf vào. Tên file chỉ gồm chữ thường, số và dấu gạch dưới, ví dụ be_vietnam_pro_regular.ttf.
  2. Khai báo một FontFamily gom các độ đậm lại.
  3. Dùng trực tiếp qua fontFamily, hoặc tốt hơn là gắn vào Typography của theme.
val BeVietnamPro = FontFamily(
    Font(R.font.be_vietnam_pro_regular, FontWeight.Normal),
    Font(R.font.be_vietnam_pro_medium, FontWeight.Medium),
    Font(R.font.be_vietnam_pro_bold, FontWeight.Bold)
)

Text("Thời tiết hôm nay", fontFamily = BeVietnamPro, fontWeight = FontWeight.Bold)

Khi bạn yêu cầu FontWeight.Bold, Compose tự chọn file phông có độ đậm khớp trong FontFamily. Nhớ chọn phông hỗ trợ đầy đủ dấu tiếng Việt.

Ví dụ

Ví dụ 1: Tên và mô tả sản phẩm, cắt bớt bằng dấu "…"

@Composable
fun ProductInfo(name: String, description: String, modifier: Modifier = Modifier) {
    Column(modifier = modifier.padding(16.dp)) {
        Text(
            text = name,
            style = MaterialTheme.typography.titleMedium,
            maxLines = 1,
            overflow = TextOverflow.Ellipsis
        )
        Spacer(Modifier.height(4.dp))
        Text(
            text = description,
            style = MaterialTheme.typography.bodyMedium,
            color = MaterialTheme.colorScheme.onSurfaceVariant,
            maxLines = 2,
            overflow = TextOverflow.Ellipsis
        )
    }
}

@Preview(showBackground = true, widthDp = 300)
@Composable
fun ProductInfoPreview() {
    MaterialTheme {
        ProductInfo(
            name = "Tai nghe không dây Sóng Âm Pro phiên bản đặc biệt",
            description = "Chống ồn chủ động, pin 30 giờ, sạc 10 phút nghe 3 giờ, kết nối ổn định với hai thiết bị cùng lúc."
        )
    }
}

Kết quả: Tên sản phẩm in đậm vừa, nằm trên một dòng và kết thúc bằng "…" vì quá dài; phần mô tả màu xám nhạt hơn, hiển thị tối đa hai dòng rồi cũng bị cắt bằng "…".

Ví dụ 2: Dòng giá có giá cũ gạch ngang

@Composable
fun PriceLine(newPrice: String, oldPrice: String, discountPercent: Int) {
    val colors = MaterialTheme.colorScheme
    val priceText = buildAnnotatedString {
        withStyle(SpanStyle(color = colors.error, fontWeight = FontWeight.Bold, fontSize = 20.sp)) {
            append(newPrice)
        }
        append("  ")
        withStyle(
            SpanStyle(
                color = colors.onSurfaceVariant,
                textDecoration = TextDecoration.LineThrough
            )
        ) {
            append(oldPrice)
        }
        append("  ")
        withStyle(SpanStyle(color = colors.primary, fontWeight = FontWeight.SemiBold)) {
            append("-$discountPercent%")
        }
    }
    Text(text = priceText, style = MaterialTheme.typography.bodyMedium)
}

@Preview(showBackground = true)
@Composable
fun PriceLinePreview() {
    MaterialTheme {
        PriceLine(newPrice = "349.000 đ", oldPrice = "499.000 đ", discountPercent = 30)
    }
}

Kết quả: Một dòng duy nhất: "349.000 đ" to, đậm, màu đỏ; tiếp theo là "499.000 đ" màu xám có gạch ngang; cuối cùng là "-30%" màu chủ đạo của theme.

Ví dụ 3: Đoạn điều khoản có link bấm được

@Composable
fun TermsNotice(modifier: Modifier = Modifier) {
    val linkStyles = TextLinkStyles(
        style = SpanStyle(
            color = MaterialTheme.colorScheme.primary,
            fontWeight = FontWeight.Medium,
            textDecoration = TextDecoration.Underline
        )
    )
    val text = buildAnnotatedString {
        append("Khi bấm Đăng ký, bạn đồng ý với ")
        withLink(LinkAnnotation.Url("https://example.com/dieu-khoan", styles = linkStyles)) {
            append("Điều khoản sử dụng")
        }
        append(" và ")
        withLink(LinkAnnotation.Url("https://example.com/bao-mat", styles = linkStyles)) {
            append("Chính sách quyền riêng tư")
        }
        append(" của cửa hàng.")
    }
    Text(
        text = text,
        style = MaterialTheme.typography.bodySmall,
        textAlign = TextAlign.Center,
        modifier = modifier.padding(horizontal = 24.dp)
    )
}

Kết quả: Đoạn chữ nhỏ căn giữa; hai cụm "Điều khoản sử dụng" và "Chính sách quyền riêng tư" có màu chủ đạo, gạch chân. Chạm vào cụm nào thì trình duyệt mở đúng trang tương ứng.

Chú ý

  • Cỡ chữ luôn dùng sp, không dùng dp. sp co giãn theo cài đặt cỡ chữ của người dùng (Android 14 trở lên cho phóng tới 200%), còn dp thì không. Người lớn tuổi hoặc người nhìn kém rất cần điều này.
  • Vì chữ có thể phóng to, đừng đặt chiều cao cố định (Modifier.height(20.dp)) cho vùng chứa chữ; chữ sẽ bị cắt mất. Dùng heightIn(min = …) hoặc để nội dung tự quyết định chiều cao (xem Kích thước và ràng buộc).
  • textAlign chỉ có tác dụng khi Text rộng hơn nội dung chữ. Nếu Text chỉ rộng vừa chữ, căn giữa sẽ "không ăn"; hãy thêm Modifier.fillMaxWidth().
  • Muốn overflow = TextOverflow.Ellipsis hoạt động thì phải giới hạn chiều rộng và số dòng (maxLines); nếu không chữ chỉ đơn giản xuống dòng.
  • Tiếng Việt chỉ có một dạng số nhiều (other), nhưng khi app có thêm bản tiếng Anh thì bản đó cần cả one và other. Luôn dùng pluralStringResource thay vì tự viết if (count == 1). Ở các bản Compose rất cũ, hàm này từng là API thử nghiệm.
  • Hạn chế tự đặt color = Color.Black: chữ sẽ "biến mất" trên nền tối ở chế độ Dark. Dùng màu từ MaterialTheme.colorScheme (ví dụ onSurface, onSurfaceVariant).
  • Trong SelectionContainer, chữ chọn được nhưng không sửa được; nếu cần nhập liệu hãy dùng TextField.
Mẹo: Gom các kiểu chữ lặp lại (ví dụ "giá khuyến mãi") vào một hàm composable nhỏ như PriceLine ở trên. Cả app sẽ hiển thị giá đồng nhất và khi cần đổi màu bạn chỉ sửa một chỗ.
