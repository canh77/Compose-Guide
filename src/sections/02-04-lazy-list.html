Danh sách: LazyColumn và LazyRow

LazyColumn và LazyRow hiển thị danh sách dài (hàng trăm, hàng nghìn mục) mà vẫn mượt, vì chỉ tạo những mục đang nhìn thấy. Đây là phiên bản Compose của RecyclerView, nhưng gọn hơn rất nhiều.

Định nghĩa

Một Column kèm Modifier.verticalScroll vẫn cuộn được, nhưng nó tạo và đo tất cả phần tử con ngay từ đầu, kể cả những phần tử còn nằm rất xa ngoài màn hình. Với 20 mục thì không sao; với 2.000 mục thì app sẽ chậm và tốn bộ nhớ.

Các lazy layout (layout "lười") giải quyết vấn đề này: LazyColumn (cuộn dọc) và LazyRow (cuộn ngang) chỉ tạo các mục đang hiển thị cùng một ít mục sắp xuất hiện. Khi bạn cuộn, mục ra khỏi màn hình được giải phóng hoặc tái sử dụng cho mục mới.

So với RecyclerView, bạn không cần Adapter, ViewHolder, LayoutManager hay file XML cho từng dòng. Bạn chỉ mô tả nội dung bằng một DSL (ngôn ngữ nhỏ trong Kotlin) gồm các hàm item, items… và Compose lo phần còn lại. Khi dữ liệu đổi, danh sách tự cập nhật, không cần notifyDataSetChanged.

Cách dùng

Các hàm DSL trong LazyListScope

Bên trong lambda của LazyColumn { } không phải là composable thông thường mà là LazyListScope: bạn gọi các hàm sau để khai báo mục, còn giao diện của từng mục nằm trong lambda của chúng.

HàmDùng khi
item { }Thêm một mục lẻ: tiêu đề, banner, chân trang.
items(count) { index -> }Thêm count mục, chỉ biết vị trí.
items(list) { element -> }Thêm một mục cho mỗi phần tử của danh sách. Đây là cách dùng phổ biến nhất.
itemsIndexed(list) { index, element -> }Như trên nhưng cần cả vị trí, ví dụ đánh số thứ tự hay tô màu xen kẽ.
stickyHeader { }Tiêu đề nhóm "dính" ở đầu màn hình khi cuộn qua nhóm đó.
 
LazyColumn {
    item { Text("Bảng xếp hạng") }
    itemsIndexed(players) { index, player ->
        Text("${index + 1}. ${player.name} – ${player.score} điểm")
    }
    item { Text("Hết danh sách") }
}

key và contentType

  • key: định danh ổn định cho mỗi mục, thường là id từ dữ liệu: items(notes, key = { it.id }) { … }. Mặc định Compose nhận diện mục theo vị trí; khi thêm, xóa hay đổi thứ tự, trạng thái remember bên trong mục có thể "dính" sang mục khác. Có key, trạng thái đi theo đúng dữ liệu. key phải duy nhất trong cả danh sách.
  • contentType: cho Compose biết mục thuộc loại giao diện nào (tiêu đề, sản phẩm, quảng cáo…). Compose chỉ tái sử dụng mục cũ cho mục mới cùng loại, giúp cuộn mượt hơn khi danh sách có nhiều kiểu dòng.

Tham số quan trọng của LazyColumn

Tham sốÝ nghĩa
stateĐối tượng LazyListState để đọc và điều khiển vị trí cuộn.
contentPaddingKhoảng đệm quanh nội dung, ví dụ PaddingValues(16.dp). Khác Modifier.padding: mục vẫn cuộn xuyên qua vùng đệm thay vì bị cắt ở mép.
verticalArrangementThường dùng Arrangement.spacedBy(8.dp) để tạo khoảng cách đều giữa các mục. LazyRow dùng horizontalArrangement.
horizontalAlignmentCăn các mục theo chiều ngang (LazyRow dùng verticalAlignment).
reverseLayoutĐảo chiều: mục đầu tiên nằm ở đáy, hợp với màn hình chat.
userScrollEnabledĐặt false để chặn người dùng tự cuộn.

LazyListState: đọc và điều khiển vị trí cuộn

  • Tạo bằng val listState = rememberLazyListState() rồi truyền vào LazyColumn(state = listState).
  • Đọc: firstVisibleItemIndex (chỉ số mục đầu tiên đang thấy), firstVisibleItemScrollOffset, isScrollInProgress, layoutInfo.
  • Điều khiển: scrollToItem(index) (nhảy ngay) và animateScrollToItem(index) (cuộn có hiệu ứng). Cả hai là hàm suspend, nên gọi trong coroutine lấy từ rememberCoroutineScope().
  • Khi suy ra một giá trị từ vị trí cuộn (ví dụ "có hiện nút lên đầu trang không"), bọc trong remember { derivedStateOf { … } } để giao diện chỉ cập nhật khi kết quả thật sự đổi, thay vì theo từng pixel cuộn.

Hiệu ứng thêm, xóa, đổi chỗ mục

Gắn Modifier.animateItem() lên phần tử gốc của mỗi mục, Compose sẽ tự làm mờ dần khi mục xuất hiện/biến mất và trượt mượt khi mục đổi vị trí. Có thể tùy chỉnh qua fadeInSpec, placementSpec, fadeOutSpec. Hiệu ứng chỉ hoạt động khi mục có key.

Ví dụ

1. Danh sách ghi chú cơ bản

data class Note(val id: Long, val title: String, val updatedAt: String)

@Composable
fun NoteList(
    notes: List<Note>,
    onNoteClick: (Note) -> Unit,
    modifier: Modifier = Modifier
) {
    LazyColumn(
        modifier = modifier.fillMaxSize(),
        contentPadding = PaddingValues(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        item {
            Text(
                text = "Ghi chú của tôi (${notes.size})",
                style = MaterialTheme.typography.titleLarge
            )
        }
        items(items = notes, key = { it.id }) { note ->
            Column(
                modifier = Modifier
                    .fillMaxWidth()
                    .clip(RoundedCornerShape(12.dp))
                    .background(MaterialTheme.colorScheme.surfaceVariant)
                    .clickable { onNoteClick(note) }
                    .padding(16.dp)
            ) {
                Text(text = note.title, style = MaterialTheme.typography.titleMedium)
                Text(
                    text = note.updatedAt,
                    style = MaterialTheme.typography.bodySmall,
                    color = MaterialTheme.colorScheme.onSurfaceVariant
                )
            }
        }
    }
}

@Preview(showBackground = true)
@Composable
fun NoteListPreview() {
    val sample = List(50) { i ->
        Note(id = i.toLong(), title = "Ghi chú số ${i + 1}", updatedAt = "Cập nhật ${i + 1} giờ trước")
    }
    NoteList(notes = sample, onNoteClick = {})
}

Kết quả: Tiêu đề "Ghi chú của tôi (50)" ở trên, bên dưới là 50 thẻ bo góc cách nhau 8dp. Khi cuộn, các thẻ trượt qua vùng đệm 16dp ở mép trên và dưới chứ không bị cắt cụt.

2. Trang chủ cửa hàng: LazyRow danh mục nằm trong LazyColumn

data class Product(val id: Int, val name: String, val price: String, val category: String)

private val shopCategories = listOf("Tất cả", "Áo", "Quần", "Giày", "Phụ kiện", "Túi xách")

@Composable
fun CategoryChips(
    selected: String,
    onSelect: (String) -> Unit,
    modifier: Modifier = Modifier
) {
    LazyRow(
        modifier = modifier,
        contentPadding = PaddingValues(horizontal = 16.dp),
        horizontalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        items(items = shopCategories, key = { it }) { category ->
            val isSelected = category == selected
            Text(
                text = category,
                style = MaterialTheme.typography.labelLarge,
                color = if (isSelected) MaterialTheme.colorScheme.onPrimary
                        else MaterialTheme.colorScheme.onSurfaceVariant,
                modifier = Modifier
                    .clip(CircleShape)
                    .background(
                        if (isSelected) MaterialTheme.colorScheme.primary
                        else MaterialTheme.colorScheme.surfaceVariant
                    )
                    .clickable { onSelect(category) }
                    .padding(horizontal = 16.dp, vertical = 8.dp)
            )
        }
    }
}

@Composable
fun ShopHome(products: List<Product>, modifier: Modifier = Modifier) {
    var selected by rememberSaveable { mutableStateOf("Tất cả") }
    val visibleProducts = remember(products, selected) {
        if (selected == "Tất cả") products else products.filter { it.category == selected }
    }

    LazyColumn(modifier = modifier.fillMaxSize()) {
        item(contentType = "title") {
            Text(
                text = "Danh mục",
                style = MaterialTheme.typography.titleMedium,
                modifier = Modifier.padding(16.dp)
            )
        }
        item(contentType = "categories") {
            CategoryChips(selected = selected, onSelect = { selected = it })
        }
        items(
            items = visibleProducts,
            key = { it.id },
            contentType = { "product" }
        ) { product ->
            Column {
                ListItem(
                    headlineContent = { Text(product.name) },
                    supportingContent = { Text(product.price) }
                )
                HorizontalDivider()
            }
        }
    }
}

Kết quả: Dưới chữ "Danh mục" là một dải nút hình viên thuốc cuộn ngang được; nút đang chọn có nền màu chủ đạo. Chạm vào "Giày" thì danh sách sản phẩm cuộn dọc bên dưới chỉ còn các đôi giày. Lồng LazyRow trong LazyColumn là hợp lệ vì hai danh sách cuộn theo hai hướng khác nhau.

3. Danh bạ có tiêu đề theo chữ cái, nút "lên đầu" và hiệu ứng xóa

data class Contact(val id: Long, val name: String, val phone: String)

@Composable
fun ContactBook(
    contacts: List<Contact>,
    onDelete: (Contact) -> Unit,
    modifier: Modifier = Modifier
) {
    // Nhóm theo chữ cái đầu; chỉ tính lại khi danh sách đổi
    val grouped = remember(contacts) {
        contacts
            .sortedBy { it.name }
            .groupBy { it.name.first().uppercaseChar() }
    }
    val listState = rememberLazyListState()
    val scope = rememberCoroutineScope()
    val showScrollToTop by remember {
        derivedStateOf { listState.firstVisibleItemIndex > 3 }
    }

    Box(modifier = modifier.fillMaxSize()) {
        LazyColumn(
            state = listState,
            contentPadding = PaddingValues(bottom = 88.dp)
        ) {
            grouped.forEach { (letter, group) ->
                stickyHeader(key = "header-$letter", contentType = "header") {
                    Text(
                        text = letter.toString(),
                        style = MaterialTheme.typography.titleSmall,
                        color = MaterialTheme.colorScheme.primary,
                        modifier = Modifier
                            .fillMaxWidth()
                            .background(MaterialTheme.colorScheme.surfaceContainer)
                            .padding(horizontal = 16.dp, vertical = 6.dp)
                    )
                }
                items(
                    items = group,
                    key = { it.id },
                    contentType = { "contact" }
                ) { contact ->
                    ListItem(
                        headlineContent = { Text(contact.name) },
                        supportingContent = { Text(contact.phone) },
                        trailingContent = {
                            IconButton(onClick = { onDelete(contact) }) {
                                Icon(
                                    painter = painterResource(R.drawable.ic_delete),
                                    contentDescription = "Xóa ${contact.name}"
                                )
                            }
                        },
                        modifier = Modifier.animateItem()
                    )
                }
            }
        }

        if (showScrollToTop) {
            SmallFloatingActionButton(
                onClick = { scope.launch { listState.animateScrollToItem(0) } },
                modifier = Modifier
                    .align(Alignment.BottomEnd)
                    .padding(16.dp)
            ) {
                Icon(
                    painter = painterResource(R.drawable.ic_arrow_upward),
                    contentDescription = "Lên đầu danh sách"
                )
            }
        }
    }
}

@Preview(showBackground = true, heightDp = 640)
@Composable
fun ContactBookPreview() {
    val names = listOf(
        "An", "Anh", "Bảo", "Bình", "Chi", "Cường", "Dũng", "Giang", "Hà", "Hải",
        "Hùng", "Khoa", "Lan", "Linh", "Minh", "Nam", "Phương", "Quân", "Thảo", "Vy"
    )
    var contacts by remember {
        mutableStateOf(names.mapIndexed { i, name -> Contact(i.toLong(), name, "09${i}0 123 456") })
    }
    ContactBook(contacts = contacts, onDelete = { removed -> contacts = contacts - removed })
}

Kết quả: Danh bạ chia nhóm A, B, C…; khi cuộn, chữ cái của nhóm hiện tại dính ở mép trên cho tới khi nhóm sau đẩy nó đi. Cuộn quá vài mục, nút tròn nhỏ có mũi tên hiện ở góc dưới phải; bấm vào thì danh sách cuộn mượt về đầu. Bấm biểu tượng thùng rác, dòng đó mờ dần và các dòng bên dưới trượt lên lấp chỗ.

Chú ý

  • Không lồng danh sách cuộn cùng hướng. Đặt LazyColumn trong Column có verticalScroll (hoặc trong một LazyColumn khác) sẽ gây lỗi lúc chạy, vì LazyColumn nhận chiều cao tối đa vô cực và không biết nên dừng ở đâu. Cách đúng: dùng một LazyColumn duy nhất và ghép nhiều khối item/items như ví dụ 2. Lồng khác hướng (LazyRow trong LazyColumn) thì không sao.
  • Tránh mục có kích thước 0. Ví dụ ảnh tải từ mạng ban đầu cao 0px: LazyColumn tưởng rằng rất nhiều mục vừa màn hình và tạo hết chúng một lúc, rồi phải sắp xếp lại khi ảnh về. Hãy đặt kích thước cố định hoặc aspectRatio cho vùng ảnh.
  • Mục có trạng thái thì phải có key. Nếu mục dùng remember (ô đánh dấu, trạng thái mở rộng…) mà không có key, trạng thái sẽ bám theo vị trí và nhảy sang mục khác khi danh sách thay đổi. Dùng chỉ số làm key cũng sai y như vậy; hãy dùng id thật. Muốn dùng rememberSaveable trong mục thì key phải là kiểu lưu được vào Bundle (Int, Long, String…).
  • Key trùng gây crash. Mọi key trong cùng một LazyColumn, kể cả key của tiêu đề, phải khác nhau. Ví dụ 3 dùng tiền tố "header-" để tránh trùng với id liên hệ.
  • Không xử lý dữ liệu nặng trong thân composable. Sắp xếp, lọc, nhóm nên đặt trong remember(…) như trên hoặc tốt hơn là trong ViewModel, để không bị chạy lại ở mỗi lần recompose.
  • Mỗi phần tử độc lập nên là một mục riêng. Gom nhiều thẻ vào chung một item { } khiến chúng luôn được tạo, cuộn và tái sử dụng cùng nhau. Chỉ gộp khi chúng là một khối, như dòng sản phẩm kèm đường kẻ ở ví dụ 2.
  • Tiêu đề dính cần có nền. Nếu không đặt background cho stickyHeader, các mục cuộn bên dưới sẽ lộ qua chữ. Ở một số phiên bản Compose cũ, stickyHeader còn là API thử nghiệm và cần @OptIn(ExperimentalFoundationApi::class).
Mẹo: Cần lưới nhiều cột thì xem LazyVerticalGrid; cần lật từng trang (onboarding, ảnh sản phẩm) thì xem Pager. Cả hai dùng chung tư duy DSL item/items và key như ở đây.
