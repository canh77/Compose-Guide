Checkbox, Switch, RadioButton và Slider

Các control chọn cho phép người dùng bật/tắt một tùy chọn, chọn một phương án trong nhóm hoặc kéo để chọn một giá trị số. Chúng là "nguyên liệu" chính của màn hình cài đặt, biểu mẫu và danh sách việc cần làm.

Định nghĩa

Material 3 trong Compose cung cấp bốn nhóm control chọn: Checkbox (ô đánh dấu, chọn nhiều mục độc lập), Switch (công tắc bật/tắt), RadioButton (nút chọn đúng một phương án trong nhóm) và Slider (thanh trượt chọn giá trị trong một khoảng). Đi kèm còn có TriStateCheckbox — ô đánh dấu ba trạng thái dùng cho ô "Chọn tất cả" — và RangeSlider để chọn một khoảng từ–đến.

Điều quan trọng nhất cần nhớ: tất cả các control này đều stateless (không tự giữ trạng thái). Chúng chỉ nhận giá trị hiện tại (checked, selected, value) và một callback báo rằng "người dùng muốn đổi giá trị". Cập nhật state là việc của bạn. Ở hệ View cũ, CheckBox tự đổi dấu tích khi bấm rồi bạn mới lắng nghe để đồng bộ dữ liệu; trong Compose thì ngược lại — nếu bạn không cập nhật state, control đứng yên như chưa từng được bấm.

Cách thiết kế này đảm bảo giao diện luôn là bản phản chiếu của dữ liệu: chỉ có một nguồn sự thật (single source of truth), dễ đưa lên ViewModel, dễ kiểm thử và không bao giờ có chuyện UI hiện "đã bật" trong khi dữ liệu là "tắt". Xem thêm State và remember và State hoisting.

Cách dùng

1. Checkbox và TriStateCheckbox

Truyền giá trị vào checked và cập nhật state trong onCheckedChange:

var agreed by remember { mutableStateOf(false) }

Checkbox(
    checked = agreed,
    onCheckedChange = { agreed = it }
)

TriStateCheckbox nhận state: ToggleableState với ba giá trị On (tích), Off (trống) và Indeterminate (gạch ngang, nghĩa là "chỉ một phần được chọn"). Thay cho onCheckedChange, nó có onClick: bạn tự quyết định trạng thái tiếp theo khi người dùng bấm.

2. Switch

Switch có chữ ký giống Checkbox. Tham số thumbContent cho phép vẽ một icon nhỏ bên trong núm gạt, ví dụ dấu tích khi đang bật:

var wifiOn by remember { mutableStateOf(true) }

Switch(
    checked = wifiOn,
    onCheckedChange = { wifiOn = it },
    thumbContent = if (wifiOn) {
        {
            Icon(
                painter = painterResource(R.drawable.ic_check),
                contentDescription = null,
                modifier = Modifier.size(SwitchDefaults.IconSize)
            )
        }
    } else {
        null
    }
)

3. Nhóm RadioButton

Compose không có "RadioGroup" như XML. RadioButton chỉ có selected và onClick; bạn tự lưu phương án đang chọn rồi vẽ từng nút bằng vòng lặp. Hai modifier giúp nhóm hoạt động đúng:

  • Modifier.selectableGroup() đặt trên container (Column/Row) chứa các nút, để trình đọc màn hình hiểu đây là một nhóm chọn-một.
  • Modifier.selectable(selected, onClick, role = Role.RadioButton) đặt trên mỗi hàng, để bấm vào chữ cũng chọn được. Khi đó truyền onClick = null cho RadioButton bên trong.

4. Cả hàng bấm được cho Checkbox và Switch

Khi Checkbox/Switch đi kèm một nhãn chữ, hãy gắn Modifier.toggleable(value, role = Role.Checkbox, onValueChange) (hoặc Role.Switch) lên cả hàng và đặt onCheckedChange = null cho control con. Lý do:

  • Vùng chạm lớn: bấm vào chữ cũng được, không phải nhắm đúng ô vuông nhỏ xíu.
  • Hỗ trợ tiếp cận: TalkBack đọc cả hàng như một phần tử duy nhất, ví dụ "Nhận thông báo, công tắc, đang bật", thay vì hai điểm dừng rời rạc (một cho chữ, một cho ô). Xem Hỗ trợ tiếp cận.
  • Một nơi xử lý duy nhất: khi control con có null, nó chỉ còn là phần hiển thị; mọi thao tác đi qua hàng cha.

Với TriStateCheckbox, modifier tương ứng là Modifier.triStateToggleable(state, role = Role.Checkbox, onClick).

Các import không hiển nhiên cho phần này:

import androidx.compose.foundation.selection.selectable
import androidx.compose.foundation.selection.selectableGroup
import androidx.compose.foundation.selection.toggleable
import androidx.compose.foundation.selection.triStateToggleable
import androidx.compose.ui.semantics.Role
import androidx.compose.ui.state.ToggleableState

5. Slider và RangeSlider

Tham sốÝ nghĩa
valueGiá trị hiện tại, kiểu Float.
onValueChangeĐược gọi liên tục trong lúc kéo, mỗi lần nhận giá trị mới.
valueRangeKhoảng giá trị, mặc định 0f..1f. Ví dụ 12f..24f.
stepsSố mốc dừng nằm giữa hai đầu (không tính hai đầu). 0 = trượt liên tục.
onValueChangeFinishedGọi một lần khi người dùng thả tay — nơi phù hợp để lưu giá trị.
enabledfalse thì làm mờ và không cho kéo.

Công thức cho steps: muốn có N mức có thể chọn thì steps = N - 2. Ví dụ cỡ chữ 12, 14, 16, …, 24 là 7 mức nên steps = 5.

RangeSlider có hai núm; value là một khoảng kiểu ClosedFloatingPointRange<Float>:

var priceRange by remember { mutableStateOf(200f..600f) }

RangeSlider(
    value = priceRange,
    onValueChange = { priceRange = it },
    valueRange = 0f..1000f,
    steps = 9 // 11 mức: 0, 100, 200, ..., 1000
)
Text("Giá từ ${priceRange.start.toInt()}k đến ${priceRange.endInclusive.toInt()}k")

6. Khi nào dùng control nào?

ControlDùng khiVí dụ
CheckboxChọn nhiều mục độc lập, hoặc xác nhận một điều kiện; thường đi kèm nút "Lưu"/"Gửi".Đồng ý điều khoản, đánh dấu việc đã làm
TriStateCheckboxMột mục cha đại diện cho cả nhóm checkbox con."Chọn tất cả" email
SwitchBật/tắt một cài đặt có hiệu lực ngay lập tức.Wi-Fi, thông báo, chế độ tiết kiệm pin
RadioButtonChọn đúng một trong khoảng 2–5 phương án và muốn người dùng thấy hết các phương án.Giao diện Sáng/Tối/Theo hệ thống
SliderChọn giá trị số trong khoảng, không cần gõ con số chính xác.Âm lượng, độ sáng, cỡ chữ
RangeSliderChọn một khoảng tối thiểu–tối đa.Lọc giá sản phẩm

Nếu có nhiều phương án hơn (ví dụ chọn 1 trong 20 tỉnh), dùng menu thả xuống thay vì RadioButton — xem Dialog, Bottom sheet và Menu.

Ví dụ

Ví dụ 1: Màn hình cài đặt

Switch bật thông báo, nhóm Radio chọn giao diện và Slider chỉnh cỡ chữ có xem trước.

import kotlin.math.roundToInt

enum class ThemeOption(val label: String) {
    LIGHT("Sáng"), DARK("Tối"), SYSTEM("Theo hệ thống")
}

@Composable
fun SettingsScreen() {
    var notificationsOn by remember { mutableStateOf(true) }
    var theme by remember { mutableStateOf(ThemeOption.SYSTEM) }
    var fontSize by remember { mutableFloatStateOf(16f) }

    Column(Modifier.fillMaxSize().padding(vertical = 16.dp)) {
        // Switch: cả hàng là một công tắc
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .toggleable(
                    value = notificationsOn,
                    role = Role.Switch,
                    onValueChange = { notificationsOn = it }
                )
                .padding(horizontal = 16.dp, vertical = 12.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text("Nhận thông báo", modifier = Modifier.weight(1f))
            Switch(checked = notificationsOn, onCheckedChange = null)
        }

        HorizontalDivider()

        // RadioButton: một nhóm, mỗi hàng chọn được
        Text(
            "Giao diện",
            style = MaterialTheme.typography.titleSmall,
            modifier = Modifier.padding(start = 16.dp, top = 16.dp, bottom = 4.dp)
        )
        Column(Modifier.selectableGroup()) {
            ThemeOption.entries.forEach { option ->
                Row(
                    modifier = Modifier
                        .fillMaxWidth()
                        .selectable(
                            selected = theme == option,
                            onClick = { theme = option },
                            role = Role.RadioButton
                        )
                        .padding(horizontal = 16.dp, vertical = 8.dp),
                    verticalAlignment = Alignment.CenterVertically
                ) {
                    RadioButton(selected = theme == option, onClick = null)
                    Text(option.label, modifier = Modifier.padding(start = 16.dp))
                }
            }
        }

        HorizontalDivider()

        // Slider: 12..24 sp, bước 2 => 7 mức => steps = 5
        Text(
            "Cỡ chữ: ${fontSize.roundToInt()} sp",
            style = MaterialTheme.typography.titleSmall,
            modifier = Modifier.padding(start = 16.dp, top = 16.dp)
        )
        Slider(
            value = fontSize,
            onValueChange = { fontSize = it },
            valueRange = 12f..24f,
            steps = 5,
            modifier = Modifier.padding(horizontal = 16.dp)
        )
        Text(
            "Xem trước: Hôm nay trời Đà Lạt se lạnh.",
            fontSize = fontSize.sp,
            modifier = Modifier.padding(horizontal = 16.dp)
        )
    }
}

@Preview(showBackground = true)
@Composable
private fun SettingsScreenPreview() {
    MaterialTheme { SettingsScreen() }
}

Kết quả: Màn hình có ba phần ngăn cách bằng đường kẻ: hàng "Nhận thông báo" với công tắc bên phải; nhóm ba lựa chọn Sáng/Tối/Theo hệ thống (luôn chỉ một nút được chọn); thanh trượt cỡ chữ dừng đúng ở 12, 14, …, 24 và dòng xem trước to/nhỏ theo khi kéo.

Ví dụ 2: Danh sách việc cần làm có "Chọn tất cả"

data class TodoItem(val id: Int, val title: String, val done: Boolean = false)

@Composable
fun TodoChecklist() {
    var todos by remember {
        mutableStateOf(
            listOf(
                TodoItem(1, "Mua rau và trứng"),
                TodoItem(2, "Trả sách thư viện"),
                TodoItem(3, "Tập thể dục 30 phút", done = true)
            )
        )
    }

    // Trạng thái ô cha được TÍNH từ các ô con, không lưu riêng
    val parentState = when {
        todos.all { it.done } -> ToggleableState.On
        todos.none { it.done } -> ToggleableState.Off
        else -> ToggleableState.Indeterminate
    }

    Column(Modifier.padding(vertical = 8.dp)) {
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .triStateToggleable(
                    state = parentState,
                    role = Role.Checkbox,
                    onClick = {
                        val markAll = parentState != ToggleableState.On
                        todos = todos.map { it.copy(done = markAll) }
                    }
                )
                .padding(horizontal = 16.dp, vertical = 8.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            TriStateCheckbox(state = parentState, onClick = null)
            Text(
                "Chọn tất cả (${todos.count { it.done }}/${todos.size})",
                style = MaterialTheme.typography.titleMedium,
                modifier = Modifier.padding(start = 16.dp)
            )
        }

        HorizontalDivider()

        todos.forEach { todo ->
            Row(
                modifier = Modifier
                    .fillMaxWidth()
                    .toggleable(
                        value = todo.done,
                        role = Role.Checkbox,
                        onValueChange = { checked ->
                            todos = todos.map {
                                if (it.id == todo.id) it.copy(done = checked) else it
                            }
                        }
                    )
                    .padding(start = 32.dp, end = 16.dp, top = 8.dp, bottom = 8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                Checkbox(checked = todo.done, onCheckedChange = null)
                Text(
                    todo.title,
                    modifier = Modifier.padding(start = 16.dp),
                    textDecoration = if (todo.done) TextDecoration.LineThrough else null
                )
            }
        }
    }
}

Kết quả: Ô "Chọn tất cả (1/3)" ban đầu hiện dấu gạch ngang vì chỉ một việc đã xong. Bấm vào nó thì cả ba việc được tích và bị gạch chữ; bấm lần nữa thì bỏ tích hết. Tích từng việc con thì ô cha tự chuyển giữa trống, gạch ngang và tích.

Chú ý

  • Bấm mà không thấy gì thay đổi? Gần như chắc chắn bạn quên cập nhật state trong callback, hoặc truyền một giá trị cố định như checked = true. Control chỉ hiển thị đúng thứ bạn đưa vào.
  • Đừng để cả hàng lẫn control con cùng xử lý chạm. Khi hàng đã có toggleable/selectable, hãy đặt onCheckedChange = null (hoặc onClick = null) cho control con; nếu không, TalkBack sẽ thấy hai phần tử bấm được chồng lên nhau.
  • Slider gọi onValueChange rất dày (mỗi khung hình khi kéo). Đừng ghi cơ sở dữ liệu hay gọi mạng ở đó; chỉ cập nhật state hiển thị, còn việc lưu thì làm trong onValueChangeFinished.
  • Giá trị Slider là Float: viết 16f, 12f..24f chứ không phải 16, 12..24. Khi hiển thị, dùng roundToInt() thay vì toInt() để tránh 15,9999 bị cắt thành 15.
  • Switch nghĩa là "có hiệu lực ngay". Nếu thay đổi chỉ áp dụng sau khi bấm "Lưu", dùng Checkbox sẽ đúng quy ước hơn.
  • State tạo bằng remember sẽ mất khi xoay màn hình; với lựa chọn của người dùng, dùng rememberSaveable hoặc đưa lên ViewModel — xem Lưu trạng thái.
  • Muốn đổi màu, dùng CheckboxDefaults.colors(...), SwitchDefaults.colors(...), SliderDefaults.colors(...); nhưng ưu tiên chỉnh colorScheme của theme để mọi control đồng bộ — xem Tùy biến theme.
